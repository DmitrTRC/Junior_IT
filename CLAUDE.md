# CLAUDE.md · Junior_IT

Память проекта для Claude CLI. Читается в начале каждой сессии. Держим коротко и
по делу — глубину выносим в `meta/`.

## TL;DR

**Junior_IT** — курс углублённой информатики и программирования для 7–8 классов:
подготовка к учебнику Босовой с опережением программы.
Основной язык — **Python**, вокруг него треки `book` (по учебнику), `pascal`,
`devops`, `cs` («компьютер изнутри») и `web` (HTML/CSS/JS, пройден первым).
Ведёт Димас — senior-разработчик (`ASM C C++ Python JS Pascal Dart C# Java`),
[@DmitrTRC](https://github.com/DmitrTRC).

Материалы — статические **HTML/CSS/JS** + Markdown. Деплой — **GitHub Pages**
на каждый push в `main` → https://dmitrtrc.github.io/Junior_IT/

Формат: 1:1 через Zoom, два занятия в неделю (среда и воскресенье, 20:00),
работа руками — ребёнок пишет код и шарит экран, а не смотрит запись.

## ⛔ Жёсткие запреты (не нарушать никогда)

Это материалы для детей и публичный репозиторий с записями, которые живут годами.

**В материалах и в кадре:**
- НЕ использовать символику СССР, ФСБ, силовых ведомств, советских органов, любые
  политически нагруженные принты/знаки.
- НЕ писать слово **«дружина»** (взрослые → ассоциации с СССР, дети не понимают).

**В коммуникации с родителями:**
- НЕ употреблять «контроль», «проверки», «инспекции».
- НЕ использовать «дружина» / «отряд» в рассылках.
- НЕ предлагать «кружковую методику как в школе».

**В работе с кодом и правками:**
- НЕ вываливать слишком много за раз — Димас сам остановит и попросит развёрнуто.
- НЕ навязывать альтернативы выбранному стеку (HTML→CSS→JS, vanilla, без фреймворков)
  без явного запроса.
- Правки — **хирургические**: не переписывать окружающий контекст ради одной строки.

## 🎓 Методология (почему так, а не иначе)

- Занятие — **1:1**, ребёнок **делает вживую и шарит экран** — не смотрит, как код
  пишет Димас, а пишет сам, с подсказками по ходу.
- Теория — не дольше **2 минут** подряд. Каждые 3–5 мин — переключение внимания
  (вопрос, реакция, снова руки на клавиатуру).
- 75 минут — потолок (дальше внимание мертво). Можем сократить до 60.
- Основной язык курса — **Python**. Трек `web` (HTML/CSS/JS) пройден первым и держит
  собственные конвенции, которые не переносятся на весь курс: CSS как кульминация
  первого урока, отложенные до 3–4-го урока термины («семантика», «DOCTYPE»,
  «валидация», «парсинг», «DOM»), резервный финальный файл `index-final.html` на
  случай слома живого кодинга, демки в трёх эстетиках (геймер / спорт / арт) — это
  правила трека `web`, а не всего курса.

**Главный урок из практики:** `getElementById` оказался стеной (слишком много магии
сразу — объект, метод, свойство, цепочка через точку). Поэтому между «оживляем сайт»
и «события/анимация» вставлен мост — **урок 2.5 «Сам язык: консоль-калькулятор»**
(чистый JS в консоли, без DOM). Подробности — `meta/lesson-01-postmortem.md`.

**Консоль (подсветка кода):** в консольных блоках уроков — Dracula-палитра:
`#8be9fd` (kw), `#f1fa8c` (str), `#ffb86c` (num), `#ff79c6` (bool), `#6272a4` (com),
`#7fd0ff` (вывод), фоны `#15151c`/`#0c0c11`. Это функциональный слой, не декор —
в токены не входит, но единообразен по всей линейке. Не «чинить» в отдельном уроке.

**Шрифты:** Headings — Rubik 700; Body — Manrope 400/500/600; Code/labels —
JetBrains Mono 400/700. Эстетики демок: спорт — `Arial Black` (под Bebas-вайб),
арт — `Georgia` (под Fraunces-вайб), геймер — `Press Start 2P` + Manrope.
⚠️ **Новый шрифт с Google Fonts — сперва проверить сабсет `cyrillic`**, и только потом
ставить на русский текст. Без кириллических глифов браузер молча подставляет системный:
латиница и кириллица рисуются разными гарнитурами в одной строке, и это не tofu — заметно
не сразу. Проверено: **без кириллицы** — Space Grotesk, Bebas Neue, Fraunces, Rajdhani
(все заменены); **с кириллицей** — Rubik, Manrope, JetBrains Mono, Inter, Press Start 2P.
Замены зафиксированы комментарием в шапке демок — не свопить назад.

**Принципы дизайна:**
- Градиенты, мягкие тени, плавные hover, скруглённые карточки.
- Минимум комментариев в коде (только для неочевидного).
- Никаких хрупких `position:absolute` декораций в hero — ломаются на широких экранах.
- Кастомные SVG-баннеры, не генераторы вроде capsule-render.
- В Markdown — эмодзи-заголовки, бейджи через `img.shields.io`.

## ✅ Рабочие конвенции

- Язык материалов и общения — **русский**. С детьми — на «ты».
- Идентификаторы (папки, файлы, id в `module.yml`) — только английские, без транслитерации.
- Имена папок модулей: `tracks/<track>/m-NN-slug` (NN — порядок создания внутри
  трека, с ведущим нулём, не порядок прохождения).
- Термины учебника — двуязычной парой: «Ветвление (branching)».
- Перед `/deploy` — всегда показывать diff и резюме, не пушить молча.
- Новые/переписанные материалы прогонять через `/brand-check` (или brand-guardian)
  до коммита.
- `students/` и `graphify-out/` — приватное/генерируемое, не коммитим.
- Анатомия модуля (набор файлов, роли `shared/student/teacher`, блок `cs`) —
  `meta/module-anatomy.md`. Читать перед созданием или ревью модуля.

- Карта курса на лендинге собирается из `module.yml` и `session.yml` генератором
  `tools/build_course_map.py` — руками её не редактировать; после занятия при

- Глубокий контекст: `meta/project-instructions.md` (полные инструкции проекта) и
  `meta/lesson-01-postmortem.md` (что сработало, что нет, открытые вопросы).

## graphify

This project has a knowledge graph at graphify-out/ with god nodes, community structure, and cross-file relationships.

Rules:
- For codebase questions, first run `graphify query "<question>"` when graphify-out/graph.json exists. Use `graphify path "<A>" "<B>"` for relationships and `graphify explain "<concept>"` for focused concepts. These return a scoped subgraph, usually much smaller than GRAPH_REPORT.md or raw grep output.
- If graphify-out/wiki/index.md exists, use it for broad navigation instead of raw source browsing.
- Read graphify-out/GRAPH_REPORT.md only for broad architecture review or when query/path/explain do not surface enough context.
- After modifying code, run `graphify update .` to keep the graph current (AST-only, no API cost).
