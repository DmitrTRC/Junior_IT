S1–S2 (титул «Компьютер изнутри» и «зачем заглядывать внутрь») идут по сценарию до старта схемы. Ниже — 8 шагов сборки: одна деталь на слайде, между шагами — пинг, теория ≤2 минут.

1S3Пустая материнка

// с чего начинается любой компьютер [ материнская плата ] — пустой стол сама не считает и не думает → на ней будут жить все детали, как дома на одной улице
Реплики: плата — платформа, а не сам компьютер и не процессор. Пока пустая — детали появятся дальше.
Пинг: «Как думаете, что появится на плате первым?»
Грабля: дети думают, что материнка — это и есть весь компьютер. Сними сразу: «плата — стол, а не мозг».

2S4CPU и часики

[ CPU · процессор ] ⏱ тик → команда, тик → следующая частота = сколько тиков в секунду 3,5 ГГц = 3,5 млрд тиков каждую секунду
Реплики: первый и главный жилец — процессор. Выполняет команды по тикам-«часикам». ГГц — это только про скорость тиков.
Пинг: «Сколько ГГц у твоего компьютера?»
Грабля: ГГц путают с объёмом памяти. «Гигагерцы — про скорость, не про то, сколько влезет».

3S5Нули и единицы

провод с напряжением = 1 провод без напряжения = 0 вся речь компьютера, любая программа = только 0 и 1
Реплики: главный секрет всего компьютера. Есть ток — 1, нет — 0. Больше процессор ничего не понимает.
Пинг: «А буквы и картинки — тоже из нулей и единиц?» (да, просто закодированы)
Грабля: 0 и 1 «написаны» на проводе. Сними: это не цифры, а состояние — ток есть или нет.

4S6–S7RAM-полка (и SSD рядом)

[ RAM ] = полка ячеек с адресами 0 1 2 3 … (с нуля!) RAM: быстрая, но при выключении забывает всё SSD: медленнее, зато помнит всё после выключения
Реплики: адреса «как дома на улице, только с нуля». Программа во время работы живёт в RAM, на SSD лежит выключенной.
Пинг: «У кого сколько RAM? 8, 16, 32 ГБ?»
Грабля: RAM и SSD путают. «Фотку хранишь на SSD, а редактируешь — в RAM. Выключил без сохранения → RAM забыла».

5S8Шина и Instruction Pointer

CPU ←──── шина ×64 ────→ RAM 64 проводочка, по каждому в один момент: 0 или 1 = разрядность IP (Instruction Pointer) = палец на строке: держит адрес текущей команды, потом шагает дальше
Реплики: шина — дорога из проводов. IP помнит, какой «дом на улице» открыть следующим, и после тика идёт к следующему адресу.
Пинг: «Что будет, если проводов сделать 8 вместо 64?» (данные в несколько заходов, медленнее)
Грабля: 64 бита путают с 64 ГБ. И IP — это НЕ «IP-адрес» из интернета, буквы те же — смысл разный.

6S9Полная схема с пользователем

[ CPU · RAM · шина · SSD ] ──→ [ ввод-вывод ] ──→ 🧑 ты через I/O подключены: клавиатура, монитор, USB монитор и клава = окна и двери, НЕ сам компьютер
Реплики: процессор с диском напрямую не говорит — только через ввод-вывод. Тут появляется пользователь. Схема собрана целиком.
Пинг: «Какое устройство ввода-вывода у тебя самое необычное?»
Грабля: монитор считают «самим компьютером». «Настоящий компьютер — то, что мы собрали внутри».

7S10–S11Включение: POST и эстафета

Power → POST (самопроверка: CPU, память, диск) → BIOS/UEFI из ROM → загрузочная запись на диске → загрузчик → ОС в RAM // POST есть даже в микроволновке и стиралке
Реплики: нажали Power → самопроверка → BIOS/UEFI передаёт эстафету загрузочной записи, та — загрузчику, он поднимает ОС.
Демка: переключись на demos/boot.html — нажми Power вживую, пройди ленту до рабочего стола. Потом тумблер «вытащить RAM» → POST останавливается с ошибкой.
Пинг: «Кто видел чёрный экран BIOS?»
Грабля: BIOS/UEFI путают с самой ОС. «Это отдельная программа-проверяющая, она просто передаёт эстафету Windows/macOS/Linux».

8S12–S14Карта ОС и итог

MS-DOS → Windows Unix → Linux → Android Unix → macOS / iOS 85% всех устройств планеты = Unix или Linux · даже Windows встроил Linux (WSL)
Реплики: ОС — родственники. Итог: полная схема компьютера и путь загрузки теперь в голове. Дальше — слои и язык машины.
Пинг: «Какая ОС на твоём телефоне?»
Грабля: Linux считают «редким, для программистов». Сними цифрой: 85% устройств вокруг уже на Linux/Unix.
