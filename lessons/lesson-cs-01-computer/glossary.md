# 📖 Словарик урока cs-01 — «Компьютер изнутри»

> Объясняем простыми словами, без «архитектуры», «контроллеров» и прочей глубины. Эти слова — на будущее. Сегодня только то, что нужно, чтобы понять путь от кнопки Power до рабочего стола.

| Слово | Простыми словами | Пример |
|---|---|---|
| **процессор (CPU)** | Главная «думающая» деталь компьютера. Выполняет команды одну за другой, по тикам-«часикам». | 3,5 ГГц |
| **частота** | Сколько тиков (тактов) процессор делает за секунду. Чем больше — тем быстрее работает. | 3,5 ГГц = 3,5 млрд тиков в секунду |
| **регистр** | Крошечная ячейка памяти прямо внутри процессора — для команды, которая выполняется прямо сейчас. Самая быстрая память в компьютере, но её очень мало. | Instruction Pointer — один из регистров |
| **Instruction Pointer (IP)** | Регистр-указатель внутри процессора: держит адрес команды, которую процессор выполняет прямо сейчас, — как палец на строке. После каждой команды сам переходит к следующему адресу. Не путать с «IP-адресом» из интернета — сокращение то же, а смысл совсем другой. | IP держит адрес 0, потом 1, потом 2… |
| **оперативная память (RAM/ОЗУ)** | «Рабочий стол» компьютера: тут лежит всё, с чем прямо сейчас работает процессор. Быстрая, но при выключении питания забывает всё. | 8, 16, 32 ГБ RAM |
| **постоянная память (ROM/ПЗУ)** | Маленькая память, которая не забывает данные при выключении. В ней хранится программа, которая запускается первой при включении компьютера. | в ROM живёт BIOS/UEFI |
| **SSD/жёсткий диск** | Основное хранилище компьютера — файлы, фото, программы. Медленнее RAM, зато помнит всё и после выключения. | 256, 512 ГБ, 1 ТБ |
| **VRAM** | Память видеокарты. Работает как RAM, только хранит то, что нужно для картинки на экране. | 8, 12, 16 ГБ VRAM |
| **шина** | «Дорога» из проводов между процессором и памятью, по которой бегут нули и единицы. | шина CPU↔RAM |
| **разрядность** | Сколько нулей и единиц шина или процессор передают одновременно, за один раз. | 64-разрядная шина — 64 «проводочка» сразу |
| **бит** | Самая маленькая единица информации в компьютере. Либо 0, либо 1: есть напряжение на проводе или нет. | 0 или 1 |
| **ввод-вывод** | Система, через которую компьютер обменивается данными с внешним миром: клавиатура, монитор, USB, диск. | клавиатура → ввод, монитор → вывод |
| **POST** | Power-On Self-Test — самопроверка сразу после включения: процессор на месте, память отвечает, диск виден. Такая же есть в микроволновке и стиральной машине. | пикнула, проверила, поехали |
| **BIOS** | Basic Input/Output System — маленькая программа из ROM, которая запускается первой и готовит компьютер к загрузке. | чёрный экран при включении старого компьютера |
| **UEFI** | Современная замена BIOS. Задачи те же — проверить компьютер и подготовить его к загрузке, только устроена по-другому и удобнее. | стоит почти на всех новых компьютерах |
| **загрузчик** | Маленькая программа, которая переносит операционную систему с диска в оперативную память и запускает её. | последний шаг перед рабочим столом |
| **операционная система** | Программа, которая берёт на себя нули и единицы и даёт пользователю рабочий стол, файлы, окна. | Windows, macOS, Linux, Android |
| **WSL** | Windows Subsystem for Linux — «Linux внутри Windows»: способ запускать программы для Linux прямо на компьютере с Windows. | доступен в Windows одной командой |

---

## Главная мысль урока одной строкой

Компьютер — это не магия, а стопка простых деталей на одной плате: CPU считает по тикам, RAM и SSD хранят данные (одна быстро, другой — надолго), а вся их «речь» — это всего два состояния, есть напряжение или нет.
