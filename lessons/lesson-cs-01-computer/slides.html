// шаг 1 · платформа

Материнская плата

Все детали живут на одной плате — как дома на одной улице.

// шаг 2 · процессор

CPU и «часики»

Тик — одна команда. Частота — сколько тиков в секунду: 3,5 ГГц = 3,5 млрд тиков.

// вся речь компьютера

Есть напряжение — 1. Нет — 0.

Больше процессор ничего не понимает — только эти два состояния.

// шаг 3 · оперативная память

RAM — полка с ячейками

Адреса как дома на улице, только счёт с нуля: 0, 1, 2, 3 …

// быстрая память против запоминающей

RAM или SSD?

RAM

Быстрая, но забывчивая

Дорогая и очень быстрая. При выключении питания забывает всё. Пока программа работает — она живёт здесь.

SSD

Медленнее, зато помнит

Дешевле и медленнее. Помнит всё, пока не сотрут. Пока компьютер выключен — программы и файлы лежат тут.

А у видеокарты своя память — VRAM, по тем же правилам, только для картинки.

// шаг 4 · шина

Шина — дорога из проводов

По каждому проводу бежит 0 или 1. У современных машин их 64 — это и есть разрядность.

// шаг 5 · ввод-вывод и пользователь

Вся схема собрана

Процессор говорит с диском только через ввод-вывод. Там же — клавиатура, монитор и ты.
