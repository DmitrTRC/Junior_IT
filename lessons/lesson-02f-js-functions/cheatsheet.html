01Функция: своя команда с именем

Функция — это свой кусок кода с именем. Упаковал один раз — зовёшь по имени, когда надо. Не нужно копировать одни и те же строки в разные места.

// без функции — копипаста в каждом местеconsole.log("============")console.log(" Привет!")// …а нужно ещё и ещё? дай этому куску имя

02Объявить ≠ запустить

Сначала объявляем команду словом function — описываем, что она делает. Сама по себе она пока не работает (как записать рецепт). Чтобы сработала — её надо вызвать: имя и круглые скобки.

// объявили — ничего не напечаталосьfunction privet() {  console.log("Привет!")}// вызвали — теперь работаетprivet()Привет!
function privet() {…}
Объявить — описать команду. Само по себе не печатает.
privet()
Вызвать — запустить. Скобки () значат «выполни».

⚠️Главная ловушка: вызов без скобок

Запускает команду только имя со скобками. Если написать privet без () — браузер не выполнит её, а просто покажет её тело.

// без скобок — показал «рецепт», не приготовилprivetƒ privet() { console.log("Привет!") }// со скобками — выполнилprivet()Привет!
🔑
Зовёшь команду — всегда со скобками: privet(). Без скобок — увидишь текст функции вместо работы. И помни: объявил, но не вызвал → ничего не вывелось, это нормально.

03Параметр — дырка-настройка

Чтобы команда работала по-разному, делаем в ней дырку — её заполняем при вызове. Дырка в скобках называется параметр.

function privet(imya) {  console.log("Привет, " + imya + "!")}privet("Саня")Привет, Саня!privet("Лиза")Привет, Лиза!
function privet(imya)
Дырка imya — коробочка, в которую приедет настройка.
privet("Саня")
Что в скобках при вызове — тем дырку заполнили. Текст — в кавычках.

04А ты это уже умел!

console.log, prompt, Number — это тоже функции, просто их написали создатели браузера. Имя, скобки «вызови», в скобках настройка — всё то же самое.

console.log("я функция")prompt("я тоже")Number("42")// чужие команды — зовём со скобками с первого урока
🤯
Никакой новой магии: ты звал функции всё это время. Сегодня научился делать свои.

05Упакуй цикл в команду

Внутри команды может жить что угодно — даже цикл с прошлого урока. Спрятал работу внутрь — снаружи просто зовёшь по имени с числом.

function ryad(n) {  let uzor = ""  for (let i = 1; i <= n; i++) {    uzor = uzor + "⭐"  }  console.log(uzor)}ryad(3)⭐⭐⭐ryad(5)⭐⭐⭐⭐⭐

06Две дырки + тизер (для сильных)

Параметров может быть несколько — через запятую. Заполняются по порядку.

function ploshad(a, b) {  console.log("Площадь: " + (a * b))}ploshad(3, 4)Площадь: 12
🔮
На будущее: команда умеет не только печатать, но и отдавать результат обратно — словом return. Про него — на следующих уроках.

07Топ-5 ошибок новичка

1. Вызвал без скобок. privet показывает тело функции. Запускает только privet().
2. Объявил, но не вызвал. function сам не печатает — нужен вызов. Это не ошибка, просто ничего не вывелось.
3. Имя в скобках без кавычек. privet(Саня) → ошибка. Текст — в кавычках: privet("Саня").
4. Кавычки-«ёлочки». Только английские " или ', не « и не ».
5. Русская раскладка. function — английскими буквами. Забытая { / } — тоже частая.
🛠
Если «ничего не происходит» — почти всегда забыты скобки вызова. Допиши () к имени команды.

08Что дальше

Теперь у тебя весь чистый язык: программа хранит (переменные), выбирает (if), повторяет (циклы) и зовёт свои команды (функции). Но пока всё это живёт в консоли и пропадает вместе с вкладкой. На следующем уроке дадим коду свой дом — настоящий редактор и файл. А потом вернём кнопки, и команда оживёт на клике.
