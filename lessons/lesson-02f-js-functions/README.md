# Урок 2.9 — Своя команда: функции

**Тема:** Функция — своя команда с именем. `function имя() { ... }`, вызов `имя()`, параметр-«дырка». Без `return`, без файлов и без DOM.
**Длительность:** 60–75 минут
**Возраст:** 11–14 лет
**Место в курсе:** четвёртый и **последний** шаг «чистого языка». Закрывает четвёрку **переменные (2.5) → условия (2.6) → повторы (2.7) → команды (2.9)**. После него урок 2.10 — переезд в редактор, а на уроке 3 возвращаем кнопки, и функция ложится на клик.

## Зачем этот урок

На уроке 2.7 программа научилась **повторять** один и тот же кусок. Но часто нужно не повторить подряд, а **переиспользовать** свой кусок кода в разных местах — поздороваться тут, посчитать там. Копировать строки руками — скучно и ломуче. Сегодня учим **упаковывать код в команду со своим именем** и вызывать её, когда надо. Главный мостик: `console.log()`, `prompt()`, `Number()` — это команды, которые **кто-то написал**. Сегодня делаем **свою** такую команду. Всё ещё чистый язык в консоли, без единой кнопки.

## Что ребёнок умеет к концу урока

- Понимает идею функции: «упаковал код в команду с именем — вызываю, когда надо»
- Объявляет свою команду: `function privet() { ... }`
- Помнит, что **объявить ≠ запустить**: после объявления надо **вызвать** — `privet()`
- Вызывает свою команду много раз, не копируя код
- Понимает **параметр** как «дырку-настройку»: `function privet(imya) { ... }`, вызов `privet("Саня")`
- Узнаёт, что `console.log`, `prompt`, `Number` — тоже функции, просто их написали другие; скобки = «вызови»
- Упаковывает в функцию знакомый цикл из урока 2.7
- Помнит главную граблю: **забыл скобки при вызове** (`privet` вместо `privet()`) → команда не выполнилась
- Может дома собрать свою команду по шпаргалке

## Методическая заметка

Намеренно держим **одно** новое концепт-ядро: объявить → вызвать → параметр. `return` НЕ вводим — функция печатает сама через `console.log`. Это прямая защита от стены `getElementById` (см. `meta/lesson-01-postmortem.md`): если в один урок свалить параметры + `return` + область видимости, получится четыре магии разом. `return` уходит в тизер «для сильных» и в следующий урок.

Главный приём против магии — не подавать `function` как новое заклинание. Дети **уже вызывают** функции: `console.log(...)`, `prompt(...)`, `Number(...)`. Скобки = «вызови», аргумент в скобках = настройка. Сегодня просто делаем **свою** такую команду. Кульминация — упаковать в функцию знакомый цикл из 2.7: «дал команде число — она сама нарисовала ряд».

Главная грабля урока (аналог `=`/`===` из 2.6 и бесконечного цикла из 2.7) — **вызов без скобок**: `privet` вместо `privet()`. Браузер показывает само тело функции, а не выполняет её. Рядом — «объявил, но не вызвал → ничего не вывелось». Вынесено в шпаргалку и в чек-лист «не работает». Демки запускают мини-программу через `console.log`/`prompt` сами при открытии (для «вау» на вебинаре) — это всё ещё чистый язык, никакого DOM.
