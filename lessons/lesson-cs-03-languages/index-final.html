Дети начнут спорить, какой язык лучше. Сними сразу: лучшего нет, есть подходящий для задачи.

2S3–S4 Код — просто текст. Среда исполнения

файл hello.py = обычные буквы ✕ процессор понимает только 0 и 1
рецепт = твой код · повар = среда исполнения
// взрослые называют среду исполнения «рантайм» — это то же самое слово
Между текстом и процессором обязан стоять кто-то ещё. Весь урок — про этого «кого-то».
«Если открыть файл с программой в блокноте и нажать Enter — программа запустится?»
Среду исполнения путают с редактором. Редактор — блокнот, где пишешь; среда исполнения — кто выполняет.

// меняться будет только середина — три переводчика по очереди
Не заполняй середину раньше времени: весь эффект следующих слайдов в том, что края остаются прежними.

4S6–S7 Компилятор, ассемблер, линкер

C, C++ → компилятор → линкер → готовый файл → CPU
// перевод ДО запуска, один раз, дальше исходник не нужен

asm → ассемблер (почти один-в-один) → линкер (сшивает куски) → файл → CPU
Поэтому игру качают гигабайтами готового файла, а не текстом программы. На ассемблере пишут драйверы и куски операционных систем.
«Почему игру качают гигабайтами, а не текстом программы?»

5S8 Интерпретатор

Python → интерпретатор: строку прочитал — выполнил → CPU
// перевод ВО ВРЕМЯ работы, каждый запуск заново
Плюс — поменял строчку и сразу запустил. Минус — нужен установленный Python, и переводить приходится каждый раз.
«У кого установлен Python?»
Спросят про байткод — короткая честная реплика: питон немножко компилирует, но в свой внутренний код, не в машинный.

6S9 JIT

JS → движок: интерпретирует, горячий кусок компилирует на лету → CPU
// и так, и так: начинаем быстро, самое частое доводим до машинного кода
Браузер не может ждать: страница должна открыться сейчас, но и тормозить не имеет права.
«Что откроется быстрее — страница, которую надо сначала целиком скомпилировать, или та, что начинает работать сразу?»

7S10–S11 Пять языков, одна задача

asm x86-64 14 строк
section .data
  msg db "Привет, мир!", 10
  len equ $ - msg

section .text
  global _start
_start:
  mov rax, 1          ; системный вызов write
  mov rdi, 1          ; куда: на экран
  mov rsi, msg        ; что: адрес текста
  mov rdx, len        ; сколько байт
  syscall
  mov rax, 60         ; системный вызов exit
  xor rdi, rdi
  syscall
C 5 строк
#include <stdio.h>

int main(void) {
  printf("Привет, мир!\n");
  return 0;
}
C++ 5 строк
#include <iostream>

int main() {
  std::cout << "Привет, мир!" << std::endl;
  return 0;
}
Python 1 строка
print("Привет, мир!")
JavaScript 1 строка
console.log("Привет, мир!");
Результат одинаковый — разница в том, сколько ты обязан объяснить машине сам. Число с клавиатуры приходит текстом: на асме превращаешь его в число руками, в Python это int(), в JS — Number().
«Угадай: сколько строк займёт «посчитай до пяти» на ассемблере?»
Не разбирай ассемблерные команды построчно — съест всё время. Задача блока: контраст объёма.
