# 📖 Словарик урока cs-02 — «Слои: от железа до твоей программы»

> Объясняем простыми словами, без «архитектуры», «компилятора», «системных вызовов». Эти слова — на будущее. Сегодня только то, что нужно, чтобы понять слои компьютера и язык машины.

| Слово | Простыми словами | Пример |
|---|---|---|
| **слой (уровень)** | Этаж в пирамиде компьютера. Каждый этаж разговаривает только с соседним: снизу — железо, сверху — твоя программа. | железо → BIOS/UEFI → ОС → приложение |
| **программа** | Код, который ты пишешь, — набор команд для компьютера. | код в консоли |
| **приложение** | Готовая штука, которую запускает пользователь, — то, во что превращается программа после сборки. | браузер, игра |
| **бит** | Самая маленькая единица информации в компьютере. Либо 0, либо 1 — одна лампочка, горит или нет. | 0 или 1 |
| **байт** | 8 битов подряд. В него помещается число от 0 до 255. | 00101010 = 42 |
| **двоичная система** | Система счисления только из двух цифр — 0 и 1. Родной язык железа. | 101010 |
| **десятичная система** | Привычная система из десяти цифр — 0–9. Та, которой считаешь каждый день. | 42 |
| **шестнадцатеричная система** | Система из 16 цифр: 0–9, а дальше буквы A, B, C, D, E, F. Компактнее двоичной — программисты используют её постоянно. | `#ffd60a` |
| **перфокарта** | Картонная карточка с дырочками — так записывали самые первые программы. Есть дырочка — 1, нет дырочки — 0. | ранние компьютеры |
| **машинный код** | Самый нижний язык программирования — команды процессору прямо нулями и единицами, без единой буквы. | 0/1 |
| **ассемблер** | Язык программирования на ступень выше машинного кода: те же команды процессору, но словами вместо голых нулей и единиц. | `mov`, `syscall` |
| **драйвер** | Маленькая программа-переводчик между операционной системой и конкретным устройством — видеокартой, принтером. Без неё ОС не знает, как с устройством разговаривать. | поставил видеокарту → поставил драйвер |

---

## Главная мысль урока одной строкой

Компьютер живёт слоями: железо понимает только 0 и 1, а каждый следующий уровень — BIOS/UEFI, ОС, твоё приложение — переводит эти нули-единицы во всё более человеческий язык; 16-ричная система и hex-цвета из CSS — просто удобная запись того же самого.
