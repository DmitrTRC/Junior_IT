// повтор одной картинкой, не новая тема Power → POST → BIOS/UEFI → загрузчик → ОС сегодня идём выше: что между «включился» и «твоя программа заработала»
Реплики: в прошлый раз собрали железо и включили компьютер. Сегодня поднимаемся от железа до собственной программы и разбираем, на каком языке всё это говорит.

2S3–S4Пирамида + программа vs приложение

// 4 этажа снизу вверх, каждый говорит только с соседним [ приложение ] запускаешь двойным кликом [ ОС ] окна, файлы, берёт 0/1 на себя [ BIOS/UEFI ] будит железо, передаёт эстафету [ железо ] понимает только 0 и 1 // программа = код, что ты пишешь · приложение = готовое после сборки
Реплики: каждый этаж говорит только с соседним. Поэтому одна Windows не встанет на любое железо без разбора — под каждую деталь нужен свой переводчик.
Пинг: «Что на дне пирамиды?»
Грабля: программу и приложение путают как синонимы. Сними: «программа — то, что печатаешь; приложение — то, что получается после сборки и запускается двойным кликом».

3S5Перфокарта и 0/1

// самый нижний этаж — железо, понимает только 0 и 1 есть дырочка = 1 · нет дырочки = 0 первые программы писали буквально дырками в картоне
Реплики: внутри современного процессора те же 0 и 1 — просто сейчас их вводит клавиатура и компилятор, а не рука с дыроколом.
Пинг: «Как думаете, долго собирать программу таким способом?»
Грабля: перфокарты кажутся далёкой фантастикой, не связанной с их кодом. Сними: «внутри процессора те же самые 0 и 1».

4S6Лампочки: бит и байт

1 лампочка = 1 бит (горит — 1, не горит — 0) 8 лампочек подряд = 1 байт → число от 0 до 255 // 8 лампочек = 256 разных комбинаций
Реплики: переключись на demos/bits.html, вкладка «Лампочки» — кликай лампочки вживую, под ними меняются двоичное, десятичное и 16-ричное значения.
Пинг: «Сколько влезет в 8 лампочек?»
Грабля: думают, что в байт влезает «до 8» или «до 100». Сними числом: «256 комбинаций — от 0 до 255».

5S7Двоичный счёт на демке

0, 1 // цифры кончились — перенос разряда 10, 11 // снова перенос 100, 101 … 111 → 1000 (после 111 — снова перенос)
Реплики: продолжай щёлкать лампочки на bits.html, считая вслух. Перенос — тот же, что 9 + 1 = 10, просто в двоичной «девятка» наступает уже после единицы.
Пинг: «Какое двоичное идёт сразу после 111?» (ответ: 1000 — снова перенос разряда)
Грабля: перенос кажется уникальной штукой двоичной. Сними: «это тот же перенос, что 9 + 1 = 10».

7S9Hex-цвет: вкладка «Собери цвет»

#ffd60a = три пары 16-ричных цифр подряд ff = 255 красного · d6 = 214 зелёного · 0a = 10 синего // каждая пара — число от 0 до 255
Реплики: сюрприз — 16-ричные числа вы уже писали в CSS. Переключись на demos/bits.html, вкладка «Собери цвет» — двигай ползунки R/G/B, показывай, как меняются hex-код и образец.
Пинг: «Какого цвета #ff0000?»
Грабля: hex-цвет кажется случайным набором букв. Сними: «это ровно три числа от 0 до 255, просто записанные в 16-ричной, чтобы короче».
