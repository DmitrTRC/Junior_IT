### 🟡 [0:09 – 0:15] Кирпич первый: коробочки

🎤 «Разомнём пальцы. Коробочка — помним?»

```js
let imya = "Саня"
```

🎤 «А теперь ловушка, на которую после каникул наступают все. Что напечатает?»

### 🟡 [0:15 – 0:21] Кирпич второй: спросить у человека

🎤 «`prompt` — окошко с вопросом. Но отдаёт он всегда текст, даже если ввели цифры. Поэтому оборачиваем в `Number`.»

```js
let otvet = Number(prompt("Сколько будет 7 × 3?"))
console.log(otvet)
```

🎬 Вводишь `21` → в консоли `21` другим цветом (число, а не текст).

💬 **В чат:** «🔢 если помните, зачем тут Number.»

### 🟡 [0:21 – 0:28] Кирпич третий: проверить

🎤 «Есть ответ человека — сравним с правильным.»

```js
let otvet = Number(prompt("Сколько будет 7 × 3?"))
if (otvet === 21) {
  console.log("✅ Верно!")
} else {
  console.log("❌ Мимо. Правильно: 21")
}
```

🎬 Запускаешь дважды: с верным ответом и с неверным.

🎤 «Три равно `===` — это вопрос «равно ли?». Один `=` — положить в коробочку. Внутри `if` почти всегда нужны три.»

🎬 На секунду пишешь `if (otvet = 21)` — срабатывает всегда — и стираешь.

💬 **В чат:** «⚡ у кого «Верно», 💀 у кого «Мимо».»

> ⚠️ Грабля №2. Не проскакивай: после перерыва `=` / `===` путают заново.

### 🟡 [0:28 – 0:33] Одна попытка целиком

🎤 «Вопрос плюс проверка — это уже готовая одна попытка тренажёра. Только `21` мы вписали руками. Пусть программа считает сама.»

```js
let chislo = 7
let i = 3
let otvet = Number(prompt(chislo + " × " + i + " = ?"))
if (otvet === chislo * i) {
  console.log("✅ Верно!")
} else {
  console.log("❌ Мимо. Правильно: " + (chislo * i))
}
```

🎤 «Теперь и вопрос, и правильный ответ берутся из коробочек. Меняю `i` на 4 — весь пример другой, больше ничего не трогаю.»

💬 **В чат:** «Какое `i` поставить? Кидайте, поменяю вживую.»

---

### 🟡 [0:33 – 0:42] Пять вопросов подряд (кульминация)

🎤 «Главное за урок. Есть кусок, который надо повторить пять раз с разным `i`. Чем повторяют?»

🎬 Ждёшь ответа из чата — «циклом». Дождись, не подсказывай сразу.

```js
let chislo = 7
for (let i = 1; i <= 5; i++) {
  let otvet = Number(prompt(chislo + " × " + i + " = ?"))
  if (otvet === chislo * i) {
    console.log("✅ Верно!")
  } else {
    console.log("❌ Мимо. Правильно: " + (chislo * i))
  }
}
```

🎬 Пять вопросов подряд. Отвечай вживую, один-два раза намеренно неправильно.

🎤 «Ничего не изменилось — мы просто обернули попытку в `for` и убрали `let i = 3`: теперь `i` заводит сам цикл, и на каждом повторе оно новое. Счётчик тут не только «сколько раз», но и данные для вопроса.»

💬 **В чат:** «🔥 если видно, что мы просто обернули прошлый кусок в цикл.»

> ⚠️ Дети теряются в скобках. Покажи пальцем: фигурные скобки `for` — большие, внутри них скобки `if`. Коробка в коробке.

### 🟡 [0:42 – 0:48] Копилка очков

🎤 «Тренажёр без счёта — не тренажёр. Заводим копилку. Внутри цикла или снаружи?»

🎬 Ждёшь ответа. Скажут «внутри» — покажи, что она обнуляется каждый раз.

```js
let ochki = 0
// … внутри ветки «верно»:
ochki = ochki + 1
// … после цикла:
console.log("Очки: " + ochki + " из 5")
```

🎬 В конце печатается, например, `Очки: 4 из 5`.

🎤 «До цикла завели, внутри растим, после цикла печатаем. Ровно так же мы копили сумму на прошлом уроке.»

💬 **В чат:** «Сколько бы очков вышло у вас? 5, 4, 3?»

### 🟡 [0:48 – 0:52] Оценка + сделай своим

🎤 «Последний штрих — пусть программа оценит. Три ветки, `else if` знаем.»

```js
if (ochki === 5) {
  console.log("🏆 Идеально!")
} else if (ochki >= 3) {
  console.log("👍 Неплохо после каникул")
} else {
  console.log("Ещё разок — станет легче")
}
```

🎤 «И сделайте его своим: `chislo` — любимое число, `5` вопросов на `10`, а `×` поменяйте на `+` — получится тренажёр сложения.»

💬 **В чат:** «На какое число запустить? Наберу вживую.»

### 🟡 [0:52 – 0:56] Итог + мостик вперёд

🎤 «Полчаса назад была пустая консоль. Сейчас — программа, которая спрашивает, проверяет, считает и оценивает. И ни одного нового слова:»
1. Коробочка хранит, `+` склеивает, `Number(prompt(...))` спрашивает число.
2. `if / else if / else` выбирает ветку, сравниваем через `===`.
3. `for` повторяет, а счётчик `i` заодно даёт данные для каждого шага.
4. Копилка: завести до цикла, растить внутри.

🎤 «Теперь посмотрите на программу ещё раз. Видите кусок «задать вопрос и проверить»? Он один, а пользоваться им хочется в разных местах. Копировать руками — скучно. На следующем уроке научимся упаковывать такой кусок в **свою команду с именем** — как `console.log`, только твою.»

## 🆘 ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

- **Всегда «Мимо»:** забыт `Number(...)` вокруг `prompt` — текст `"21"` не равен числу `21`.
- **Всегда «Верно»:** в `if` один `=` вместо `===`.
- **Вкладка зависла:** в `for` пропал шаг `i++`. Закрой вкладку.
- **«Красная ошибка»:** потерялась `{` или `}` — сегодня скобки в скобках. Ещё — кавычки-ёлочки, русская раскладка.
- **Совсем сломалось:** открой `index-final.html`, веди по нему — там все строки с ответами.
- **«Мы это уже проходили, скучно»:** задача — вторая копилка: считать отдельно верные и ошибки, вывести обе в конце.
- **Группа плывёт, всё забыли:** не гони. Убери шаг 7 (оценка) и мостик сократи — важнее, чтобы тренажёр собрался и заработал.
