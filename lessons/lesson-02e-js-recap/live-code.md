# 💻 LIVE-CODE: «Разминка — собираем тренажёр» (урок 2.8)

**Стартовая точка:** НИКАКИХ файлов. Открываешь браузер → консоль (F12 → Console). Всё пишем прямо там.
**Зачем этот урок:** после перерыва. Ничего нового не вводим — но три знакомых кирпича (коробочка, `if`, цикл) впервые складываем в одну настоящую программу: тренажёр устного счёта со счётом очков.
**Принцип:** одна строка = один ответ браузера. Между шагами — пинг в чат. Теории не дольше 2 минут подряд.

> 🎯 Главное правило урока: **ни одного нового слова**. Всё, что звучит, дети уже видели. Новое — только то, что кирпичи стоят друг на друге.

---

## ШАГ 0 · Возвращение

🎬 Открываешь вкладку → `F12` → вкладка **Console**. Курсор после `>`. Печатаешь `2 + 2` → `4`.

🎤 «С возвращением! Пока вас не было, браузер ничего не забыл — вот, считает. И вы не забыли, сейчас проверим. Сегодня ноль новых слов: берём то, что уже умеем, и собираем из этого настоящую программу — тренажёр устного счёта. К концу урока он будет задавать вам вопросы и ставить оценку.»

💬 **В чат:** «Кто открыл консоль — плюс в чат. Кто забыл, где она — F12, вкладка Console.»

> ⚠️ После перерыва снова покажи, КУДА печатать (вкладка Console, не Elements). Это главный «не работает» дома.

## ШАГ 1 · Коробочки — помним?

🎤 «Кирпич первый: коробочка. Кладём в неё значение и достаём по имени.»

```js
let imya = "Саня"
let ochki = 0
console.log("Привет, " + imya + "! Очков: " + ochki)
```

🎬 Ответ: `Привет, Саня! Очков: 0`.

🎤 «`let` — завести коробочку, `+` между текстами — склеить. Всё как было.»

🎤 «А теперь ловушка, на которую после каникул наступают все. Что напечатает вот это?»

```js
console.log("7" + 1)
```

🎬 Ответ: `71`.

🎤 «Не восемь! В кавычках `"7"` — это **текст**, а к тексту `+` не прибавляет, а приклеивает. Запомнили: цифра в кавычках — не число.»

💬 **В чат:** «Почему получилось 71, а не 8? Кто скажет своими словами?»

---

## ШАГ 2 · Спросить у человека

🎤 «Кирпич второй: спросить. `prompt` — окошко с вопросом. Но он всегда отдаёт **текст**, даже если ввели цифры.»

```js
let otvet = Number(prompt("Сколько будет 7 × 3?"))
console.log(otvet)
```

🎬 Вводишь `21` → в консоли `21`, оранжевым (это число, а не текст).

🎤 «`Number(...)` превращает текст в число. Без него мы бы получили `"21"` — и дальше всё сломалось бы, как в шаге 1.»

💬 **В чат:** «🔢 если помните, зачем тут Number.»

> ⚠️ Забытый `Number` — грабля №1 сегодняшнего урока. Покажи разницу цветом: текст в консоли одного цвета, число — другого.

---

## ШАГ 3 · Проверить ответ

🎤 «Кирпич третий: выбор. У нас есть ответ человека — сравним его с правильным.»

```js
let otvet = Number(prompt("Сколько будет 7 × 3?"))
if (otvet === 21) {
  console.log("✅ Верно!")
} else {
  console.log("❌ Мимо. Правильно: 21")
}
```

🎬 Вводишь `21` → «Верно!». Запускаешь ещё раз, вводишь `20` → «Мимо».

🎤 «Три равно `===` — это **вопрос** «равно ли?». Один `=` — это положить в коробочку. Внутри `if` почти всегда нужны три.»

💬 **В чат:** «⚡ у кого сработало «Верно», 💀 у кого «Мимо» — не стесняемся.»

> ⚠️ Грабля №2. Напиши на секунду `if (otvet = 21)` и покажи, что сработает всегда — потом сотри.

---

## ШАГ 4 · Одна попытка целиком

🎤 «Смотрите: вопрос + проверка — это уже готовая **одна попытка** тренажёра. Только правильный ответ мы вписали руками. Пусть программа посчитает его сама.»

```js
let chislo = 7
let i = 3
let otvet = Number(prompt(chislo + " × " + i + " = ?"))
if (otvet === chislo * i) {
  console.log("✅ Верно!")
} else {
  console.log("❌ Мимо. Правильно: " + (chislo * i))
}
```

🎬 То же самое, но `21` нигде не написано — программа считает `7 * 3` сама.

🎤 «Теперь вопрос и правильный ответ берутся из коробочек. Поменяем `i` на 4 — и весь пример поменяется, ничего больше трогать не надо.»

💬 **В чат:** «Какое `i` поставить? Кидайте число — поменяю вживую.»

> ⚠️ Скобки вокруг `(chislo * i)` нужны: сначала посчитай, потом приклеивай к тексту. Без них склеит по кусочкам.

---

## ШАГ 5 · Пять вопросов подряд (кульминация)

🎤 «А теперь главное. У нас есть кусок, который надо повторить пять раз с разным `i`. Чем повторяют?»

🎬 Ждёшь ответа из чата — «циклом».

```js
let chislo = 7
for (let i = 1; i <= 5; i++) {
  let otvet = Number(prompt(chislo + " × " + i + " = ?"))
  if (otvet === chislo * i) {
    console.log("✅ Верно!")
  } else {
    console.log("❌ Мимо. Правильно: " + (chislo * i))
  }
}
```

🎬 Программа задаёт пять вопросов подряд: `7 × 1`, `7 × 2`, … `7 × 5`. Отвечаешь вживую, часть — намеренно неправильно.

🎤 «Всё, что было — на месте. Мы только обернули попытку в `for` и убрали строку `let i = 3`: теперь `i` заводит сам цикл, и на каждом повторе оно новое. Счётчик здесь не просто «сколько раз» — он ещё и **данные для вопроса**.»

💬 **В чат:** «🔥 если видно, что мы просто обернули вчерашний кусок в цикл.»

> ⚠️ Тут дети теряются в скобках. Покажи пальцем: фигурные скобки `for` — большие, внутри них фигурные скобки `if`. Одни внутри других, как коробка в коробке.

## ШАГ 6 · Копилка очков

🎤 «Тренажёр без счёта — не тренажёр. Заведём копилку. Где её заводить — внутри цикла или снаружи?»

🎬 Ждёшь ответа. Если скажут «внутри» — покажи, что тогда она обнуляется каждый раз.

```js
let chislo = 7
let ochki = 0
for (let i = 1; i <= 5; i++) {
  let otvet = Number(prompt(chislo + " × " + i + " = ?"))
  if (otvet === chislo * i) {
    console.log("✅ Верно!")
    ochki = ochki + 1
  } else {
    console.log("❌ Мимо. Правильно: " + (chislo * i))
  }
}
console.log("Очки: " + ochki + " из 5")
```

🎬 В конце печатается, например: `Очки: 4 из 5`.

🎤 «Копилка заводится **до** цикла — иначе обнулялась бы на каждом повторе. А растёт **внутри**, и только в ветке «верно». Точно так же мы копили сумму на прошлом уроке.»

💬 **В чат:** «Сколько очков у вас бы вышло? Кидайте — 5, 4, 3?»

## ШАГ 7 · Оценка и «сделай своим»

🎤 «Последний штрих — пусть программа скажет, как ты справился. Тут нужны три ветки, `else if` мы знаем.»

```js
if (ochki === 5) {
  console.log("🏆 Идеально!")
} else if (ochki >= 3) {
  console.log("👍 Неплохо после каникул")
} else {
  console.log("Ещё разок — станет легче")
}
```

🎬 Печатается оценка. Тренажёр готов целиком.

🎤 «Тридцать минут назад у нас была пустая консоль. Сейчас — программа, которая спрашивает, проверяет, считает и оценивает. И ни одного нового слова: коробочка, `if`, цикл — всё это вы уже умели.»

🎤 «А теперь сделайте его своим: поменяйте `chislo` на любимое число, `5` на `10` вопросов, а `×` на `+` — получится тренажёр сложения.»

💬 **В чат:** «На какое число запустить тренажёр? Наберу вживую.»

> 💡 Скучающему («я всё помню») — задача: «сделай, чтобы при неверном ответе вопрос **не** засчитывался, но и не заканчивал цикл; выведи в конце и верные, и ошибки» (вторая копилка).

## ИТОГ на экране (что прозвучало)

- Коробочка `let` хранит, `+` склеивает текст, `Number(prompt(...))` спрашивает число
- `if / else if / else` — выбирает ветку, сравнение всегда через `===`
- `for (let i = 1; i <= 5; i++)` — повторяет, а счётчик `i` заодно даёт данные для каждого шага
- Копилка: завести **до** цикла (`let ochki = 0`), увеличивать **внутри** (`ochki = ochki + 1`)
- Три кирпича вместе = настоящая программа, а не пример из учебника

Резерв — открой `index-final.html`, там все строки этого урока с ответами.

## 🆘 Если живой кодинг встал

1. **Сравнение всегда «Мимо»** → забыт `Number(...)` вокруг `prompt`. Текст `"21"` не равен числу `21`.
2. **Всегда «Верно»** → в `if` один `=` вместо `===`.
3. **Вкладка зависла** → в `for` пропал шаг `i++`. Закрой вкладку.
4. **«Красная ошибка»** → потерялась `{` или `}`: у нас скобки в скобках. Считай пары сверху вниз. Ещё частое — кавычки-ёлочки и русская раскладка.
5. **Совсем сломалось** → открой `index-final.html`, дальше веди по нему: там готовые строки с ответами.
