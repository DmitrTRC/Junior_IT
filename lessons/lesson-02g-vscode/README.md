# Урок 2.10 — Свой дом для кода: VS Code

**Тема:** Переезд из консоли в настоящий редактор. Установка VS Code, папка проекта, первый файл `.js`, перенос тренажёра из урока 2.8. Запуск — копированием в консоль. Без HTML и без DOM.
**Длительность:** 60–75 минут
**Возраст:** 11–14 лет
**Место в курсе:** финал блока «чистого языка». Язык выучен (2.5–2.9) — теперь у кода появляется место, где он живёт. После этого урок 3 возвращает кнопки.

## Зачем этот урок

Дети сами начали спрашивать: «а как сохранить то, что я написал в консоли?». Это правильный вопрос в правильный момент — значит, кода стало достаточно много, чтобы его стало жалко терять.

До сих пор весь курс жил в консоли, и это было честно: ноль установки, мгновенный визуальный результат. Но у консоли есть потолок. Закрыл вкладку — код исчез. Программа на пятнадцать строк не редактируется: хочешь поменять одно число — перенабирай всё заново. Ошибку видно только после запуска. Показать свою работу нельзя: показывать нечего, это не файл.

Сегодня у кода появляется **свой дом**: папка, файл с именем, редактор, который подсвечивает ошибку до запуска. Ничего нового про язык — только про то, где язык живёт.

## Что ребёнок умеет к концу урока

- Ставит VS Code сам (Windows; Mac — сноской) и понимает, что это просто «умный блокнот для кода»
- Заводит **папку проекта** и открывает её через `File → Open Folder` (не отдельный файл!)
- Создаёт файл `trenajer.js` и сохраняет его — `Ctrl + S`
- Понимает, зачем расширение `.js`: по нему редактор понимает язык и включает подсветку с подсказками
- Переносит в файл свой тренажёр из урока 2.8 — программу целиком, а не обрывок
- Видит три вещи, которых не умела консоль: ошибка подчёркивается **до** запуска, скобки подсвечиваются парами, код не пропадает
- Правит одно число в файле и перезапускает — вместо того чтобы перенабирать всю программу
- Запускает свой файл: `Ctrl+A` → `Ctrl+C` → консоль браузера → `Ctrl+V` → Enter
- Знает пять горячих клавиш и понимает, что такое «несохранённый файл» (точка на вкладке)

## Методическая заметка

Урок сознательно **не вводит ни одной новой строчки языка**. Весь код на экране — тренажёр, который дети уже собрали на разминке (урок 2.8). Новое только окружение. Это защита от перегруза: установка редактора сама по себе съедает внимание, и класть сверху новый синтаксис нельзя.

**Почему именно тренажёр, а не команды из 2.9.** Тренажёр — самая длинная программа курса: пятнадцать строк, цикл со вложенным `if`, копилка очков. Ровно из-за длины он и работает как аргумент. Три коротких функции в консоли перенабрать не жалко, а тренажёр — жалко, и это чувствуется физически. Второй довод сильнее первого: чтобы поменять в тренажёре `chislo` с 7 на 9, в консоли надо перенабрать **всю программу**, а в файле — одну цифру и `Ctrl+S`. Этот момент на уроке показывается руками и обычно и есть «ага».

**Запуск через копирование в консоль — намеренное решение, а не костыль от бедности.** Подключение файла к странице требует HTML, `<script>` и разговора о том, как страница находит скрипт — это отдельный урок (3). Здесь важнее другое: код теперь **живёт в файле**, а браузер остаётся просто мотором, который его крутит. Копипаст на третьем запуске начинает раздражать — и это ровно тот зуд, который на уроке 3 снимается подключением файла к кнопке. Боль создаётся здесь намеренно и проговаривается вслух, а не прячется.

Тренажёр спрашивает через `prompt`, поэтому при каждом запуске выскакивают пять окошек. Это не баг показа, а плюс: видно, что программа живая, а перезапуск ощущается как настоящий прогон.

Главная грабля урока — **забыл сохранить** (`Ctrl + S`): «я поменял, а работает по-старому». Лечится приметой: точка вместо крестика на вкладке файла. Вторая по частоте — открыли файл вместо папки, и Проводник пустой. Обе вынесены в шпаргалку и в чек-лист «не работает».

Демки показывают не программу, а **файл**: тот самый тренажёр из 2.8 в трёх эстетиках, но уже с вкладкой редактора и точкой «не сохранено». Ребёнок узнаёт программу, которую сам писал, — и видит её в новом доме.
