01Зачем вообще файл

Консоль ничего не помнит: закрыл вкладку — код исчез. У файла есть имя, он лежит на компьютере и никуда не денется. Его можно открыть завтра, показать другу, продолжить с того же места.

🏠
Консоль — это поговорить. Файл — это записать. Сегодня язык не меняется, меняется только место, где он живёт.

02Ставим VS Code

Бесплатно, без ключей и регистрации. Это тот же редактор, в котором пишут взрослые программисты.

  1. Открой code.visualstudio.com
  2. Синяя кнопка Download for Windows
  3. Запусти скачанный файл, прими лицензию, дальше Далее до конца
  4. Галочки Add to PATH и Open with Code — оставь включёнными
  5. Установить → Запустить
🍏
На Mac: тот же сайт, кнопка Download for Mac, скачанное приложение перетащи в папку Программы. Дальше всё одинаково.

03Папку, а не файл!

Код живёт в папке проекта. Сделай на Рабочем столе папку Junior_IT — и открой в редакторе её.

File → Open Folder
Правильно. Слева в Проводнике появится название папки — туда складываем файлы.
File → Open File
Не то. Редактор увидит один файл, слева будет пусто, новые файлы делать некуда.

04Первый файл и точка js

В Проводнике слева — кнопка «новый файл». Имя любое, но обязательно с .js на конце.

trenajer.js
Так. По расширению редактор понял язык — включились цвета и подсказки.
trenajer
Так не надо. Серый текст как в блокноте, без подсветки и без помощи.
💾
Сохранить — Ctrl + S. Посмотри на вкладку файла: точка вместо крестика значит «не сохранено». Это ошибка №1 у всех новичков.

05Твой тренажёр — в файле

Переносим тренажёр из урока 2.8 целиком. Ничего нового, тот же язык — просто теперь он живёт в файле, а не в памяти вкладки.

● trenajer.js
// мой тренажёр · урок 2.8 let chislo = 7let ochki = 0 for (let i = 1; i <= 5; i++) {  let otvet = Number(prompt(chislo + " × " + i + " = ?"))  if (otvet === chislo * i) {    console.log("✅ Верно!")    ochki = ochki + 1  } else {    console.log("❌ Мимо. Правильно: " + (chislo * i))  }} console.log("Очки: " + ochki + " из 5")
💬
Строка с двумя косыми // — комментарий, он для человека. Компьютер его пропускает. Подписывай свои файлы — через месяц скажешь себе спасибо.

06Как запустить свой файл

Файл сам ничего не делает — это просто текст. Крутить код умеет браузер, поэтому отдаём текст ему.

  1. Сохрани файл — Ctrl + S
  2. Выдели всё — Ctrl + A
  3. Скопируй — Ctrl + C
  4. Браузер → F12 → вкладка Console
  5. Вставь — Ctrl + V — и Enter

Тренажёр задаст свои пять вопросов, как обычно, и в конце покажет очки:

✅ Верно!❌ Мимо. Правильно: 21✅ Верно!Очки: 4 из 5
🔁
Поменял что-то в файле? Заново: сохранить → выделить всё → копировать → вставить. Да, неудобно. На следующем уроке подключим файл прямо к странице, и копировать не придётся.

⭐Зачем это всё: одна цифра

Вот главный аргумент за файл. Хочешь тренажёр не на семь, а на девять.

в консоли
Перенабирай всю программу. Все пятнадцать строк, руками, заново. Один раз стерпишь, на третий — бросишь.
в файле
Поменял одну цифру в строке let chislo = 7, нажал Ctrl + S — и запускай. Всё.
🎯
Файл нужен не «потому что так правильно», а потому что менять код становится дёшево. Программу, которую легко менять, хочется доделывать.

07Три подарка, которых не было в консоли

красная волна
Ошибка видна до запуска. Забыл скобку — редактор подчеркнул сразу, ещё до того, как ты что-то запустил.
{ пара }
Скобки подсвечиваются парами. Ставишь курсор на одну — видно её пару. Больше не считаем глазами.
Ctrl + S
Код не пропадает. Закрыл редактор, выключил компьютер, вернулся через неделю — файл на месте.

⚠️Топ-5 ошибок новичка

1. Забыл сохранить. Правишь, запускаешь — работает по-старому. Точка на вкладке → Ctrl + S.
2. Открыл файл вместо папки. Слева пусто, новый файл делать негде. Нужно File → Open Folder.
3. Имя без .js. Нет цветов и подсказок. Правый клик по файлу → Rename, допиши .js.
4. Скопировал не весь файл. Окошки с вопросами не появились или красная ошибка. Жми Ctrl + A — он выделяет целиком.
5. Кавычки-«ёлочки» и русская раскладка. Как всегда: только английские ", команды английскими буквами.
🛠
Правило первой минуты: «не работает» → посмотри на вкладку. Если там точка — ты просто не сохранил.

09Что дальше

Теперь у твоего кода есть дом: папка, файл, имя. Но запускать его копированием — так себе радость, и ты это почувствуешь уже на третий раз.

🚀
На следующем уроке возвращаем кнопки и подключаем файл прямо к странице: нажал кнопку на своём сайте — тренажёр запустился. Файл, который ты сделал сегодня, там и пригодится. Не удаляй его.
