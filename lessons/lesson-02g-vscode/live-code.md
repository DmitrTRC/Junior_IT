# 💻 LIVE-CODE: «Свой дом для кода — VS Code» (урок 2.10)

**Стартовая точка:** браузер с консолью (как всегда) + скачанный установщик VS Code наготове.
**Зачем этот урок:** язык выучен. Но код живёт в консоли и пропадает вместе с вкладкой. Сегодня даём ему дом: папку, файл, редактор. Ни одной новой строчки языка — только новое место, где язык живёт.
**Принцип:** дети смотрят, дома повторяют по шпаргалке. Теории не дольше 2 минут подряд.

> ⚠️ Единственный урок курса, где что-то устанавливается. Тайминг установки самый непредсказуемый — держи запас и не паникуй, если у кого-то тормозит скачивание.

---

## ШАГ 0 · Боль, которую все знают

🎬 Открываешь консоль и **медленно, вручную** набираешь тренажёр с разминки — весь, все пятнадцать строк:

```js
let chislo = 7
let ochki = 0
for (let i = 1; i <= 5; i++) {
  let otvet = Number(prompt(chislo + " × " + i + " = ?"))
  if (otvet === chislo * i) {
    console.log("✅ Верно!")
    ochki = ochki + 1
  } else {
    console.log("❌ Мимо. Правильно: " + (chislo * i))
  }
}
console.log("Очки: " + ochki + " из 5")
```

🎬 Работает — пять вопросов, очки в конце. А теперь **закрываешь вкладку**. Открываешь заново.

🎤 «Всё. Тренажёр, который вы собирали целый урок, исчез. Чтобы запустить его снова — набирать заново, все пятнадцать строк. Многие уже спрашивали, как сохранить. Сегодня отвечаю.»

💬 **В чат:** «У кого пропадал код, который жалко? Ставьте 😭»

> ⚠️ Не торопись на этом шаге. Именно медленный набор длинной программы вживую создаёт нужное чувство: «я не хочу делать это каждый раз».

## ШАГ 1 · Что вообще такое редактор

🎤 «Программисты не пишут код в консоли. Консоль — это как поговорить: сказал, услышали, забыли. А код надо **записать**, чтобы он остался. Записывают в файлы, а файлы делают в редакторе.»

🎤 «Редактор — это умный блокнот для кода. Мы поставим VS Code: бесплатный, самый популярный в мире, на нём пишут и школьники, и в больших компаниях. Тот же самый, что стоит у меня.»

💬 **В чат:** «Кто уже слышал слово VS Code? А кто ставил?»

> ⚠️ Не называй его «средой разработки» и не рассказывай про расширения, git и терминал. Сегодня VS Code — блокнот, который умеет три полезные штуки. Всё.

## ШАГ 2 · Ставим (Windows)

🎬 Показываешь на экране по шагам, дети смотрят:

1. Открыть **code.visualstudio.com**
2. Большая синяя кнопка **Download for Windows**
3. Запустить скачанный файл
4. Принять лицензию → **Далее** до конца
5. На экране с галочками — включить **«Add to PATH»** и **«Open with Code»** (обе стоят по умолчанию, просто не снимай)
6. Установить → Запустить

🎤 «Всё. Никаких ключей, никакой оплаты, ничего вводить не надо.»

> 💡 **Mac:** тот же сайт, кнопка **Download for Mac**, скачанное приложение перетащить в папку **Программы (Applications)**. Дальше всё одинаково.

💬 **В чат:** «Ставим дома по шпаргалке. Сейчас просто смотрите, как это выглядит.»

## ШАГ 3 · Первый взгляд: не пугаемся

🎬 Открываешь VS Code. На экране приветственная вкладка.

🎤 «Тёмный экран, слева полоска иконок. Выглядит серьёзно, но нам нужна ровно одна иконка — самая верхняя, два листочка. Это **Проводник**: тут будут наши файлы.»

🎬 Закрываешь приветственную вкладку. Показываешь пальцем на иконку Проводника.

🎤 «Всё остальное — на будущее. Сегодня не трогаем.»

> ⚠️ Не запускай установку русского языка в эфире. Английские `File`, `Open Folder` — это ещё и полезно: дети привыкают к тем же словам, что во всех инструкциях в интернете.

## ШАГ 4 · Папка проекта (тут все ошибаются)

🎤 «Код живёт не сам по себе, а в папке. Сделаем её.»

🎬 На Рабочем столе создаёшь папку **`Junior_IT`**. Возвращаешься в VS Code:

**`File` → `Open Folder…` → выбираешь `Junior_IT` → `Выбор папки`**

🎬 Слева в Проводнике появилось название папки. Пусто — файлов пока нет.

🎤 «Запомните: открываем **папку**, а не файл. `Open Folder`, не `Open File`. Если открыть файл — редактор увидит только его одного, и слева будет пусто.»

💬 **В чат:** «📁 если видно, что VS Code теперь смотрит в вашу папку.»

> ⚠️ Грабля №2 урока. Дома половина откроет `Open File` и напишет «у меня слева пусто». Проговори дважды.

## ШАГ 5 · Первый файл и почему `.js`

🎬 В Проводнике наводишь на название папки → кнопка **новый файл** (листочек с плюсом). Печатаешь имя:

```
trenajer.js
```

🎬 Файл открылся. Пустой тёмный лист.

🎤 «Имя — какое хочешь, но **точка js** в конце обязательна. Это расширение: по нему редактор понимает, что внутри JavaScript. Сейчас покажу, что это даёт.»

🎬 Печатаешь одну строку:

```js
console.log("Привет из файла!")
```

🎬 Слова окрасились: `console.log` одним цветом, текст в кавычках — другим.

🎤 «Видите? Цвета появились сами. Редактор понял язык по расширению. Если бы файл назывался просто `trenajer` — был бы серый текст, как в блокноте.»

🎬 **`Ctrl + S`** — сохранить.

🎤 «Смотрите на вкладку сверху. До сохранения там была **точка** вместо крестика — значит "есть несохранённые изменения". Нажал `Ctrl+S` — точка пропала. Это главная примета урока.»

💬 **В чат:** «💾 если видно, где точка на вкладке.»

## ШАГ 6 · Заселяем тренажёр

🎤 «А теперь заселяем дом. Тот самый тренажёр с разминки — переезжает сюда целиком.»

🎬 Набираешь вживую, не торопясь:

```js
// мой тренажёр · урок 2.8

let chislo = 7
let ochki = 0

for (let i = 1; i <= 5; i++) {
  let otvet = Number(prompt(chislo + " × " + i + " = ?"))
  if (otvet === chislo * i) {
    console.log("✅ Верно!")
    ochki = ochki + 1
  } else {
    console.log("❌ Мимо. Правильно: " + (chislo * i))
  }
}

console.log("Очки: " + ochki + " из 5")
```

🎤 По ходу набора проговаривай, что происходит само:
— «поставил `(` — вторая скобка появилась сама»;
— «начал писать `cons` — редактор предложил `console.log`, жму Tab»;
— «нажал Enter внутри фигурных скобок — отступ сделался сам»;
— «пустые строки между кусками — можно, и так читается легче. В консоли пустая строка запускала команду, а тут просто воздух».

🎤 «Первая строка с двумя косыми — это **комментарий**. Редактор его не выполняет, он для человека. Подписывай свои файлы, через месяц спасибо себе скажешь.»

💬 **В чат:** «✍️ кто заметил, что скобки закрываются сами?»

> ⚠️ Не гонись. Набор длинной программы вживую — это и есть ценность шага: в редакторе видно всю программу целиком, а в консоли она не помещалась в голову.

## ШАГ 7 · Три подарка, которых не было в консоли

🎤 «Теперь главное. Зачем всё это было.»

**Подарок 1 — ошибку видно ДО запуска.**

🎬 Стираешь одну закрывающую фигурную скобку. Под кодом сразу появляется красная волнистая линия.

🎤 «Ничего не запускали — а редактор уже говорит: тут беда. Консоль так не умела: она ругалась только после Enter.»

🎬 Возвращаешь скобку — волна пропала.

**Подарок 2 — скобки парами.**

🎬 Ставишь курсор на `{` — подсвечивается её пара `}`.

🎤 «Помните, как мы считали скобки глазами на разминке? У нас же тут `if` внутри `for`. Теперь их считает редактор.»

**Подарок 3 — код никуда не денется.**

🎬 `Ctrl + S`. Закрываешь VS Code целиком. Открываешь снова — файл на месте, со всем содержимым.

🎤 «Вот ради этого мы всё и затеяли.»

💬 **В чат:** «🎁 какой подарок самый полезный — 1, 2 или 3?»

## ШАГ 8 · Запускаем (кульминация)

🎤 «Файл есть. Но файл сам по себе ничего не делает — это просто текст. Крутить код умеет браузер. Значит, отдадим текст браузеру.»

🎬 По шагам:

1. **`Ctrl + S`** — сохранить
2. **`Ctrl + A`** — выделить весь файл
3. **`Ctrl + C`** — скопировать
4. Переключиться в браузер → `F12` → вкладка **Console**
5. **`Ctrl + V`** — вставить
6. **Enter**

🎬 Выскакивают пять окошек с вопросами. Отвечаешь вживую, часть — намеренно неправильно. В консоли печатается:

```
✅ Верно!
✅ Верно!
❌ Мимо. Правильно: 21
✅ Верно!
✅ Верно!
Очки: 4 из 5
```

🎤 «Работает. Ровно тот тренажёр, что и на разминке.»

**А теперь — самое важное за урок:**

🎤 «Хочу таблицу не на семь, а на девять. В консоли пришлось бы перенабрать всю программу заново — все пятнадцать строк. А в файле…»

🎬 Меняешь `let chislo = 7` на `let chislo = 9`. `Ctrl+S`. `Ctrl+A`, `Ctrl+C`, вставляешь в консоль. Тренажёр спрашивает про девятку.

🎤 «Одна цифра. Вот зачем нужен файл.»

💬 **В чат:** «На какое число запустить? Кидайте — поменяю вживую.»

> ⚠️ Это кульминация урока, а не запуск сам по себе. Дай почувствовать разницу: пятнадцать строк заново против одной цифры.

## ИТОГ на экране (что прозвучало)

- Консоль ничего не помнит; код живёт в **файле**, файл лежит в **папке**
- VS Code — умный блокнот для кода: бесплатный, тот же, что у взрослых
- Открываем **папку** (`File → Open Folder`), а не отдельный файл
- Расширение `.js` включает подсветку и подсказки — без него серый текст
- `Ctrl + S` — сохранить. Точка на вкладке = не сохранено
- Три подарка: ошибка видна до запуска · скобки подсвечены парами · код не пропадает
- Поменять число в файле — одна цифра. В консоли — вся программа заново
- Запуск сегодня: `Ctrl+A` → `Ctrl+C` → консоль → `Ctrl+V` → Enter

Резерв — открой `index-final.html`, там все шаги и файл целиком.

## 🆘 Если живой кодинг встал

1. **Слева в Проводнике пусто** → открыли файл вместо папки. `File → Open Folder`, выбрать папку.
2. **Нет цветов, всё серое** → в имени файла нет `.js`. Переименуй: правый клик по файлу → `Rename`.
3. **«Поменял, а работает по-старому»** → не сохранил. Смотри на вкладку: точка вместо крестика → `Ctrl + S`.
4. **Окошки с вопросами не появились** → вставили не весь файл (или забыли Enter). `Ctrl+A` выделяет всё целиком.
5. **Тренажёр на всё отвечает «Мимо»** → это старая грабля из 2.8: потерялся `Number(...)` вокруг `prompt`. Сверься с файлом.
6. **Установка не идёт / нет прав** → пусть смотрит сегодня, ставит дома с родителями по шпаргалке. Урок от этого не ломается.
7. **Совсем сломалось** → открой `index-final.html`, дальше веди по нему: там весь файл готовым.
