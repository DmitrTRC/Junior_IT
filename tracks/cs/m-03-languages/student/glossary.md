# 📖 Словарик урока cs-03 — «Языки программирования: кто переводит твой код»

> Объясняем простыми словами. Слова «байт-код», «виртуальная машина», «оптимизация» сегодня не нужны — они на будущее. Здесь только то, без чего не понять, кто выполняет твою программу.

| Слово | Простыми словами | Пример |
|---|---|---|
| **исходный код** | Текст программы, который написал человек. Обычные буквы в обычном файле. | `hello.py`, `index.js` |
| **среда исполнения** | Тот, кто читает твой код и заставляет его работать. Код — рецепт, среда исполнения — повар. Взрослые называют её рантаймом. | браузер, Python, Node |
| **компилятор** | Переводчик, который переводит всю программу заранее, до запуска, и делает готовый файл. Исходник после этого не нужен. | gcc для C, g++ для C++ |
| **интерпретатор** | Переводчик, который читает строку — выполняет, читает следующую — выполняет. И так каждый запуск заново. | Python |
| **JIT** | Хитрый способ: сначала работаем как интерпретатор, а куски, которые выполняются часто, переводим в машинный код прямо на ходу. | движок JavaScript |
| **линкер** | Программа, которая сшивает переведённые куски в один готовый файл. Без неё вместо программы — набор запчастей. | `ld` |
| **машинный код** | Команды процессору нулями и единицами, без единой буквы. Единственное, что процессор понимает сам. | 0/1 |
| **движок** | Мотор внутри браузера, который выполняет JavaScript. В браузере он уже встроен — поэтому JS не надо ставить отдельно. | движок в Chrome |
| **Node.js** | Среда, в которой JavaScript работает без браузера — прямо в консоли, как обычная программа. | `node script.js` |
| **кроссплатформенность** | Свойство программы работать на разных системах. Питон и JS переносятся легко, а готовый файл из компилятора собран под одну систему. | скрипт работает и на Mac, и на Windows |

---

## Главная мысль урока одной строкой

Код — это просто текст, и сам он не делает ничего: чтобы программа заработала, кто-то обязан её перевести — компилятор делает это заранее и один раз, интерпретатор на ходу и каждый раз, а JIT совмещает оба способа; JavaScript в браузере и в консоли — один и тот же язык, просто среды дают ему разные возможности.
