1 Три способа перевода

Код — это просто текст. Сам по себе он не делает ничего: процессор понимает только 0 и 1. Между текстом и процессором всегда кто-то стоит.

Компилятор — C, C++
исходник → компилятор → линкер → готовый файл → CPU
Переводит до запуска и один раз. Дальше исходник не нужен — работает готовый файл.
Интерпретатор — Python
исходник → интерпретатор: строку прочитал — выполнил → CPU
Переводит во время работы и каждый запуск заново. Нужен установленный Python.
JIT — JavaScript
исходник → движок: интерпретирует, горячее компилирует на лету → CPU
Делает и так, и так: начинает быстро, а кусок, который выполняется часто, доводит до машинного кода прямо на ходу.

3 «Привет, мир» на пяти языках

Одна и та же задача. Результат одинаковый — разница в том, сколько ты обязан объяснить машине сам.

asm x86-6414 строк
section .data
  msg db "Привет, мир!", 10
  len equ $ - msg

section .text
  global _start
_start:
  mov rax, 1          ; системный вызов write
  mov rdi, 1          ; куда: на экран
  mov rsi, msg        ; что: адрес текста
  mov rdx, len        ; сколько байт
  syscall
  mov rax, 60         ; системный вызов exit
  xor rdi, rdi
  syscall
C5 строк
#include <stdio.h>

int main(void) {
  printf("Привет, мир!\n");
  return 0;
}
C++5 строк
#include <iostream>

int main() {
  std::cout << "Привет, мир!" << std::endl;
  return 0;
}
Python1 строка
print("Привет, мир!")
JavaScript1 строка
console.log("Привет, мир!");

5 Запомни

Код — это текстБез того, кто его переведёт и выполнит, он остаётся буквами в файле.
Один раз или каждый разКомпилятор переводит заранее и один раз, интерпретатор — на ходу и каждый раз.
Один язык, две средыJS в браузере и в консоли — один язык. Разные среды дают ему разные возможности.
