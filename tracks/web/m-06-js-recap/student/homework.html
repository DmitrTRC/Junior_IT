Тренажёр,
который твой

Сегодня легко: запусти готовый тренажёр и переделай его под себя. Ничего нового — только то, что мы уже умеем.

1Открой консоль

Открой любой сайт (хоть пустую вкладку) и нажми F12 → вкладка Console. На Mac в Chrome — Cmd + Opt + J.

Печатаешь строку → Enter → браузер отвечает. Всё как до каникул.

2Запусти тренажёр

Это ровно та программа, которую мы собрали на уроке. Скопируй её в консоль целиком и нажми Enter — она задаст пять вопросов.

let chislo = 7let ochki = 0for (let i = 1; i <= 5; i++) {  let otvet = Number(prompt(chislo + " × " + i + " = ?"))  if (otvet === chislo * i) {    console.log("✅ Верно!")    ochki = ochki + 1  } else {    console.log("❌ Мимо. Правильно: " + (chislo * i))  }}console.log("Очки: " + ochki + " из 5")Очки: 4 из 5
💛
Не пугайся длины: тут нет ничего нового. Цикл задаёт вопрос, if проверяет ответ, копилка считает очки — всё это ты уже проходил, просто раньше по отдельности.

3Сделай его СВОИМ

Три маленькие правки. Каждая — одна строка. После каждой запускай заново и смотри, что изменилось.

  1. Поменяй chislo = 7 на своё любимое число
  2. Сделай не пять вопросов, а три: i <= 3. Не забудь текст "из 5" в конце
  3. Замени умножение на сложение: × в вопросе и chislo * i в проверке → chislo + i
🧩
В третьей правке chislo * i встречается дважды — в проверке и в подсказке. Поменяешь одно и забудешь другое — тренажёр начнёт врать. Найди оба.

4Оценка своими словами

Допиши в самый конец, после цикла. Фразы придумай свои — какие сам хотел бы увидеть.

if (ochki === 5) {  console.log("🏆 Идеально!")} else if (ochki >= 3) {  console.log("👍 Неплохо")} else {  console.log("Ещё разок — станет легче")}

✦ Если хочется посложнее (по желанию)

  • Заведи вторую копилку oshibki и выведи в конце обе
  • Спроси число не в коде, а у человека: let chislo = Number(prompt("Таблица на какое число?"))
  • Сделай, чтобы после неверного ответа программа печатала пример ещё раз — но без второй попытки

5Покажи и пришли

  1. Дай пройти тренажёр родителям — сколько очков наберут?
  2. Сделай скриншот консоли (Print Screen на Windows, Cmd+Shift+4 на Mac)
  3. Пришли скриншот мне в чат — посмотрю, дам совет

✓ Проверь себя

Если тренажёр спросил твоё число, на верный ответ сказал «Верно», на неверный — «Мимо», а в конце показал очки, — задача выполнена. Красава.

Не работает?

Это нормально, у всех так бывает. Проверь по порядку:

→ Всегда «Мимо»? Ответ из prompt обёрнут в Number(...)?
→ Всегда «Верно»? В if стоит ===, а не один =?
→ Очки всегда 0 или 1? let ochki = 0 должна быть до цикла, не внутри
→ «Красная ошибка»? Посчитай фигурные скобки: у каждой { есть своя }
→ Кавычки английские ", команды английскими буквами?
