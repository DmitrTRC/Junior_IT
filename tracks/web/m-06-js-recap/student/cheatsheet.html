01Три кирпича, которые уже твои

Сегодня ни одного нового слова. Всё, что нужно, ты уже проходил — просто раньше по отдельности, а теперь кладём друг на друга.

2.5

Хранит

Коробочка let, склейка текста через +, вопрос через prompt.

2.6

Выбирает

if / else — сравнил через === и пошёл по своей дороге.

2.7

Повторяет

for со счётчиком i — повторит хоть 5, хоть 500 раз.

02Кирпич 1: коробочка и текст

Коробочка хранит значение, + между текстами — склеивает, а не складывает. Цифра в кавычках — это текст, не число.

let imya = "Саня"let ochki = 0console.log("Привет, " + imya + "! Очков: " + ochki)Привет, Саня! Очков: 0// а вот ловушка:console.log("7" + 1)71
🔑
Получилось 71, а не 8: к тексту + приклеивает. Хочешь считать — сначала преврати текст в число.

03Кирпич 2: спросить и проверить

prompt отдаёт текст — оборачиваем в Number. Сравниваем всегда тремя равно ===.

let otvet = Number(prompt("Сколько будет 7 × 3?"))if (otvet === 21) {  console.log("✅ Верно!")} else {  console.log("❌ Мимо. Правильно: 21")}
Number(prompt(…))
Спросить число. Без Number в коробочке окажется текст — и сравнение всегда даст «Мимо».
===
Сравнить. Один = кладёт значение — тогда if сработает всегда.

04Кирпич 3: повторить

В круглых скобках через ; три части: старт; условие; шаг. Счётчик i — не только «какой это повтор», но и данные для каждого шага.

for (let i = 1; i <= 5; i++) {  console.log("Вопрос номер " + i)}// i будет 1, 2, 3, 4, 5

05Собираем: тренажёр целиком

Главное за урок. Цикл задаёт вопрос, if проверяет ответ, копилка считает очки. Три кирпича друг на друге.

let chislo = 7let ochki = 0for (let i = 1; i <= 5; i++) {  let otvet = Number(prompt(chislo + " × " + i + " = ?"))  if (otvet === chislo * i) {    console.log("✅ Верно!")    ochki = ochki + 1  } else {    console.log("❌ Мимо. Правильно: " + (chislo * i))  }}console.log("Очки: " + ochki + " из 5")Очки: 4 из 5
🧱
Скобки стоят в скобках: if живёт внутри for. Считай пары сверху вниз — на каждую открытую { должна найтись закрытая }.

06Копилка очков

Копилка — обычная коробочка, которая растёт. Главное — где её заводить.

let ochki = 0
До цикла. Если завести внутри — будет обнуляться на каждом повторе, и в конце останется ноль.
ochki = ochki + 1
Внутри цикла, в ветке «верно». «Возьми, что было, прибавь один, положи обратно».
console.log(ochki)
После цикла. Когда все повторы закончились — печатаем итог.

07Оценка в конце (три ветки)

Между if и else помещается сколько угодно веток else if. Проверяются сверху вниз, сработает первая подошедшая.

if (ochki === 5) {  console.log("🏆 Идеально!")} else if (ochki >= 3) {  console.log("👍 Неплохо после каникул")} else {  console.log("Ещё разок — станет легче")}

⚠️Топ-5 ошибок после перерыва

1. Забыл Number. prompt отдаёт текст, "21" не равно 21 → тренажёр всегда говорит «Мимо».
2. = вместо ===. Один = кладёт значение → тренажёр всегда говорит «Верно».
3. Потерянная скобка. Сегодня { внутри { — считай пары сверху вниз.
4. Копилка внутри цикла. let ochki = 0 должна стоять до for, иначе обнуляется.
5. Кавычки-«ёлочки» и русская раскладка. Только английские ", команды — английскими буквами.
