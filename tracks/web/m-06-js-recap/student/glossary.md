# 📖 Словарик урока 2.8 — «Разминка: собираем тренажёр»

> Сегодня **ни одного нового слова**. Это сводка того, что уже проходили на уроках 2.5, 2.6 и 2.7 — всё в одной таблице, чтобы после перерыва найти нужное за секунду.

| Слово | Простыми словами | Пример | Откуда |
|---|---|---|---|
| **`let`** | Завести коробочку с именем и положить в неё значение. | `let ochki = 0` | 2.5 |
| **`+` между текстами** | Склеить, а не сложить. Цифра в кавычках — текст! | `"7" + 1` → `71` | 2.5 |
| **`prompt(...)`** | Окошко с вопросом. Отдаёт **текст**, всегда. | `prompt("Ответ?")` | 2.5 |
| **`Number(...)`** | Превратить текст в число, чтобы можно было считать и сравнивать. | `Number(prompt(...))` | 2.5 |
| **`console.log(...)`** | Напечатать в консоли. | `console.log(ochki)` | 2.5 |
| **`===`** | «Равно ли?» — это **вопрос**, ответ `true` / `false`. | `otvet === 21` | 2.6 |
| **`=`** | Один знак равно — **положить** в коробочку. Не вопрос! | `ochki = 0` | 2.6 |
| **`if (...)`** | «Если…» — сделай то, что в фигурных скобках, только когда в круглых `true`. | `if (otvet === 21) { ... }` | 2.6 |
| **`else`** | «Иначе» — что делать, когда условие `false`. | `else { ... }` | 2.6 |
| **`else if`** | «А иначе если…» — ещё одна ветка между `if` и `else`. | `else if (ochki >= 3) { ... }` | 2.6 |
| **`for (...)`** | Повторить нужное число раз. В скобках через `;` — старт; условие; шаг. | `for (let i = 1; i <= 5; i++)` | 2.7 |
| **счётчик `i`** | Коробочка, которая считает повтор: 1, 2, 3… В тренажёре она заодно задаёт вопрос. | `chislo * i` | 2.7 |
| **`i++`** | Шаг: «увеличь на один». Короткая запись `i = i + 1`. | `for (... ; i++)` | 2.7 |
| **копилка** | Коробочка, которая копит результат: заводим **до** цикла, растим **внутри**. | `ochki = ochki + 1` | 2.7 |

## Главная мысль урока одной строкой

Три кирпича, которые мы учили по одному, впервые стоят друг на друге: **цикл** задаёт вопрос, **`if`** проверяет ответ, **коробочка** копит очки — и получается настоящая программа.

## Три ловушки, из-за которых «не работает»

1. **Забыл `Number`.** `prompt` отдаёт текст, а текст `"21"` не равен числу `21`. Тренажёр будет отвечать «Мимо» на всё подряд.
2. **`=` вместо `===`.** Один знак равно кладёт значение в коробочку, а не сравнивает — тогда тренажёр отвечает «Верно» на что угодно.
3. **Потерянная скобка `{` или `}`.** Сегодня скобки стоят в скобках: `if` живёт внутри `for`. Считай пары сверху вниз — на каждую открытую должна найтись закрытая.

## Где заводить копилку

**До цикла.** Если написать `let ochki = 0` внутри `for`, она будет обнуляться на каждом повторе, и в конце всегда останется ноль или один. Заводим снаружи — растим внутри — печатаем после.
