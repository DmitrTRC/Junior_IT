свой код

Сегодня главное — не написать новое, а поселить уже написанное. Ставим редактор и делаем свой первый настоящий файл.

1Поставь VS Code

Открой code.visualstudio.com → синяя кнопка Download for Windows → запусти скачанный файл → Далее до конца. Галочки не снимай.

На Mac — кнопка Download for Mac, скачанное приложение перетащи в папку Программы.

👨‍👩‍👧
Если компьютер просит пароль администратора — позови взрослых, это нормально и правильно. Программа бесплатная и безопасная, но ставить её должен тот, у кого есть права.

2Сделай папку и файл

На Рабочем столе создай папку Junior_IT. В VS Code: File → Open Folder… → выбери её.

Слева в Проводнике нажми кнопку «новый файл» и назови его:

trenajer.js

📁
Открывай именно папку, а не файл. Если слева пусто — ты открыл файл. Повтори: File → Open Folder.

3Посели тренажёр в файл

Это тот же тренажёр, что мы собирали на разминке. Набери его руками, не копируй — так пальцы запомнят, а редактор покажет свои подсказки.

● trenajer.js
// мой тренажёр · автор: впиши своё имя let chislo = 7let ochki = 0 for (let i = 1; i <= 5; i++) {  let otvet = Number(prompt(chislo + " × " + i + " = ?"))  if (otvet === chislo * i) {    console.log("✅ Верно!")    ochki = ochki + 1  } else {    console.log("❌ Мимо. Правильно: " + (chislo * i))  }} console.log("Очки: " + ochki + " из 5")

Сохрани: Ctrl + S. Точка на вкладке должна пропасть.

🧱
Пустые строки между кусками — можно и нужно, так читается легче. В консоли пустая строка запускала команду, а в файле это просто воздух.

4Запусти

Файл сам ничего не делает — это текст. Отдадим его браузеру:

  1. Сохрани — Ctrl + S
  2. Выдели весь файл — Ctrl + A
  3. Скопируй — Ctrl + C
  4. Браузер → F12 → вкладка Console → Ctrl + V → Enter

Выскочат пять окошек с примерами — отвечай. В конце тренажёр покажет очки:

✅ Верно!❌ Мимо. Правильно: 21✅ Верно!Очки: 4 из 5

5Почувствуй разницу

Вот ради чего всё затевалось. Каждая правка — одна цифра. После каждой: сохранить, выделить всё, копировать, вставить.

  1. Поменяй let chislo = 7 на своё любимое число
  2. Сделай не пять вопросов, а три: i <= 3 (и текст "из 5" в конце тоже поправь)
  3. В комментарии сверху впиши своё имя — это твой файл
🎯
Подумай: чтобы сделать то же самое в консоли, пришлось бы перенабрать всю программу заново. Все пятнадцать строк. Каждый раз. Вот зачем нужен файл.

✦ Если хочется посложнее (по желанию)

  • Замени умножение на сложение — chislo + i. Не забудь, что оно встречается дважды
  • Закомментируй строку через Ctrl + / и посмотри, как она перестала работать
  • Сделай второй файл igra.js в той же папке — файлов может быть сколько угодно

6Покажи и пришли

  1. Покажи родителям свой редактор — они наверняка видели такой в кино про хакеров
  2. Сделай два скриншота: VS Code с твоим файлом и консоль с очками
  3. Пришли оба мне в чат — посмотрю, дам совет

✓ Проверь себя

Закрой VS Code полностью и открой заново. Если файл на месте со всем кодом — задача выполнена. Твой код теперь живёт на компьютере, а не в памяти вкладки. Красава.

Не работает?

Это нормально, у всех так бывает. Проверь по порядку:

→ Правишь, а работает по-старому? Посмотри на вкладку: точка вместо крестика = не сохранено, жми Ctrl + S
→ Слева в Проводнике пусто? Ты открыл файл, а нужно File → Open Folder
→ Всё серое, без цветов? В имени файла нет .js — правый клик → Rename
→ Окошки с вопросами не появились? Скопировал не весь файл — жми Ctrl + A
→ Тренажёр на всё отвечает «Мимо»? Это старая грабля с разминки: потерялся Number(...) вокруг prompt
→ Кавычки английские ", команды английскими буквами?

Не смог поставить редактор — не страшно, приходи как есть, разберёмся вместе. Совсем застрял — пиши мне.
