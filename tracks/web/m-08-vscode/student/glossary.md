# 📖 Словарик урока 2.10 — «Свой дом для кода: VS Code»

> Сегодня **ни одного нового слова про язык**. Все новые слова — про то, где код живёт. Без «среды разработки», «IDE», «репозитория», «терминала» — это позже.

| Слово | Простыми словами | Пример |
|---|---|---|
| **редактор** | Умный блокнот для кода. Подсвечивает, подсказывает, показывает ошибки. Сам код не запускает. | VS Code |
| **VS Code** | Наш редактор. Бесплатный, самый популярный в мире. Тот же, что у взрослых программистов. | code.visualstudio.com |
| **файл** | Кусок текста с именем, который лежит на компьютере и никуда не пропадает. | `trenajer.js` |
| **папка проекта** | Место, где лежат файлы одной работы. Редактор открывает **папку**, а не отдельный файл. | `Junior_IT` |
| **расширение** | Хвостик имени после точки. По нему компьютер понимает, что внутри. | `.js` — JavaScript |
| **`.js`** | «Внутри JavaScript». Без него редактор не включит цвета и подсказки. | `trenajer.js` |
| **сохранить** | Записать изменения в файл. Пока не сохранил — их нет нигде, кроме экрана. | `Ctrl + S` |
| **точка на вкладке** | Примета «не сохранено»: вместо крестика на вкладке файла кружок. | ● вместо ✕ |
| **Проводник (Explorer)** | Панель слева со списком файлов твоей папки. Верхняя иконка. | 🗂 |
| **комментарий** | Строка для человека, а не для компьютера. Начинается с двух косых. | `// мой тренажёр` |
| **подсказка (автодополнение)** | Редактор угадывает, что ты печатаешь, и предлагает дописать. Согласиться — `Tab`. | `cons` → `console.log` |
| **красная волна** | Волнистая линия под кодом: редактор увидел ошибку **до** запуска. | пропущенная `}` |

## Горячие клавиши (Windows / Mac)

| Что делает | Windows | Mac |
|---|---|---|
| Сохранить файл | `Ctrl + S` | `Cmd + S` |
| Выделить весь файл | `Ctrl + A` | `Cmd + A` |
| Копировать | `Ctrl + C` | `Cmd + C` |
| Вставить | `Ctrl + V` | `Cmd + V` |
| Отменить последнее | `Ctrl + Z` | `Cmd + Z` |
| Закомментировать строку | `Ctrl + /` | `Cmd + /` |
| Крупнее шрифт | `Ctrl` + `+` | `Cmd` + `+` |

## Главная мысль урока одной строкой

Консоль ничего не помнит — а файл помнит всё. Код переезжает из разговора в свой дом: у него появляются имя, место и завтрашний день.

## Почему файл сильнее консоли (на примере тренажёра)

Хочешь, чтобы тренажёр спрашивал таблицу не на семь, а на девять. В консоли — **перенабирай всю программу**, все пятнадцать строк. В файле — поменял одну цифру, нажал `Ctrl + S`, запустил. Это и есть вся разница.

## Две ловушки, из-за которых «не работает»

1. **Забыл сохранить.** Правишь файл, запускаешь — работает по-старому. Смотри на вкладку: если вместо крестика точка, жми `Ctrl + S`. Это ошибка №1 всех, кто только переехал в редактор.
2. **Открыл файл вместо папки.** `File → Open Folder`, а не `Open File`. Откроешь файл — слева в Проводнике будет пусто, и новые файлы делать некуда.

## Как сегодня запускается код

Файл сам ничего не выполняет — он просто текст. Крутить код умеет браузер. Поэтому пока так: `Ctrl+A` (выделить всё) → `Ctrl+C` (копировать) → консоль браузера → `Ctrl+V` (вставить) → `Enter`. Дальше тренажёр задаст свои пять вопросов, как обычно.

Да, копировать каждый раз неудобно, и это нормально. На уроке 3 подключим файл прямо к странице — и копировать больше не придётся.
