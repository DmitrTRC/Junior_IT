5Три подарка редактора

  1. Стереть } → красная волна до запуска. Вернуть — волна ушла
  2. Курсор на { → подсвечивается её пара (у нас if внутри for)
  3. Ctrl+S → закрыть VS Code → открыть: файл на месте

  2. Ctrl + A — выделить всё
  3. Ctrl + C — копировать
