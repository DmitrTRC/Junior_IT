### 🟡 [0:16 – 0:24] Объявить ≠ запустить (ключевой момент)

🎤 «Заворачиваем кусок в команду с именем `privet`.»

```js
function privet() {
  console.log("============")
  console.log("  Привет!")
  console.log("============")
}
```

🎬 Enter — и **ничего не напечаталось**, только `undefined`.

🎤 «Команду только **объявили** — описали, что делает. Как записать рецепт: записать ≠ приготовить. Чтобы сработала — надо вызвать.»

💬 **В чат:** «🤔 кто заметил, что ничего не вывелось?»

> ⚠️ Половина смысла урока. Не торопись к вызову, дай паузу.

### 🟡 [0:24 – 0:32] Вызов со скобками (кульминация №1)

🎤 «Запускаем команду — имя и круглые скобки. Скобки значат "вызови".»

```js
privet()
privet()
privet()
```

🎬 Три рамки подряд — а нутро написали один раз.

🎤 «Написал один раз — зовёшь сколько угодно. Менять рамку — в одном месте.»

🎬 Покажи граблю: набери `privet` **без скобок** → браузер выводит тело функции, а не выполняет.

🎤 «Без скобок — показал рецепт. Со скобками — приготовил.»

💬 **В чат:** «🔁 если понятно, что `()` — это "запусти".»

> ⚠️ Грабля №1 урока (как `=`/`===` и бесконечный цикл раньше). Покажи спокойно и живьём.

### 🟡 [0:32 – 0:40] Параметр — дырка-настройка (кульминация №2)

🎤 «Хочу здороваться по имени. Сделаем в команде дырку — заполняем при вызове.»

```js
function privet(imya) {
  console.log("Привет, " + imya + "!")
}
privet("Саня")
privet("Лиза")
```

🎬 «Привет, Саня!», «Привет, Лиза!». Команда одна — здоровается с кем угодно.

🎤 «`imya` в скобках — параметр, дырка. Что положили при вызове (`"Саня"`), приехало внутрь в коробочку `imya`.»

💬 **В чат:** «Чьё имя подставить? Кидайте — наберу вживую.»

> ⚠️ Кавычки вокруг имени обязательны — это текст. `privet(Саня)` без кавычек → ошибка.

### 🟡 [0:40 – 0:46] Да вы уже всё это знаете!

🎤 «Сюрприз. Посмотрите на `console.log("Привет")`: имя, скобки "вызови", в скобках настройка. Это **функция**! Просто её написали создатели браузера, а не мы.»

```js

```

🎤 «`console.log`, `prompt`, `Number` — чужие команды, мы их зовём со скобками с первого урока. Сегодня научились делать свои. Никакой новой магии.»

💬 **В чат:** «🤯 если щёлкнуло, что `console.log` — такая же функция, как наша `privet`.»

### 🟡 [0:46 – 0:55] Упакуем цикл в команду (главное за урок)

🎤 «Соберём настоящее. Узор из звёздочек с прошлого урока — завернём в команду, пусть рисует ряд любой длины.»

```js
function ryad(n) {
  let uzor = ""
  for (let i = 1; i <= n; i++) {
    uzor = uzor + "⭐"
  }
  console.log(uzor)
}
ryad(3)
ryad(5)
```

🎬 `⭐⭐⭐`, потом `⭐⭐⭐⭐⭐`.

🎤 «Внутри — цикл с прошлого урока. Снаружи — команда с дыркой `n`. Дал число — она сама нарисовала. Цикл спрятан внутри: снаружи просто `ryad(5)`. Так из кирпичиков и собираются программы.»

💬 **В чат:** «Ряд из скольких звёзд? Кидайте число.»

## 🆘 ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

- **Объявил функцию — ничего не вывелось:** это норма, объявление само не печатает. Надо **вызвать** со скобками: `privet()`.
- **Браузер показал текст функции:** вызвал без скобок (`privet` вместо `privet()`). Допиши `()`.
- **«Красная ошибка»:** имя в скобках без кавычек (`privet(Саня)`); забыта `{` / `}` или круглая скобка. Ещё — кавычки-ёлочки, русская раскладка.
- **Совсем сломалось:** открой `index-final.html`, веди по нему — там все строки с ответами.
- **«Скучно, знаю»:** задача — команда `privetVsem`, что здоровается с несколькими именами.
