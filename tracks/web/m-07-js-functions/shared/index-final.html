1Один кусок — снова и снова

console.log("============")console.log(" Привет!")console.log("============")// …а нужно ещё и ещё? дай куску имя

2Объявить ≠ запустить (ключевой момент)

function privet() {  console.log("============")  console.log(" Привет!")  console.log("============")}// Enter → ничего не напечаталось (только undefined)
Команду объявили — описали. Записать рецепт ≠ приготовить. Чтобы сработала — надо вызвать.

3Вызов со скобками (кульминация №1)

privet()privet()privet()// три рамки подряд — нутро написали один раз
Грабля: privet без скобок → браузер покажет тело функции, а не выполнит. Запускает только privet().

4Параметр — дырка-настройка (кульминация №2)

function privet(imya) {  console.log("Привет, " + imya + "!")}privet("Саня")Привет, Саня!privet("Лиза")Привет, Лиза!
Что в скобках при вызове ("Саня") — приедет внутрь в коробочку imya. Текст — в кавычках.

5Да вы уже всё это знаете!

console.log("я функция")prompt("я тоже")Number("42")// чужие команды: имя + скобки «вызови» + настройка
Момент «ага»: console.log, prompt, Number — такие же функции, просто их написали другие.

6Упакуем цикл в команду (главное за урок)

function ryad(n) {  let uzor = ""  for (let i = 1; i <= n; i++) {    uzor = uzor + "⭐"  }  console.log(uzor)}ryad(3)⭐⭐⭐ryad(5)⭐⭐⭐⭐⭐
Внутри — цикл с урока 2.7. Снаружи — ryad(5). Цикл спрятан: дал число — команда сама нарисовала.

7Бонус: две дырки + тизер return

function ploshad(a, b) {  console.log("Площадь: " + (a * b))}ploshad(3, 4)Площадь: 12// «команда отдаёт результат» (return) — на следующих уроках
