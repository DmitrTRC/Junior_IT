# 💻 LIVE-CODE: «Своя команда — функции» (урок 2.9)

**Стартовая точка:** НИКАКИХ файлов. Открываешь браузер → консоль (F12 → Console). Всё пишем прямо там.
**Зачем этот урок:** на прошлых уроках мы хранили, выбирали и повторяли. Сегодня учим **упаковывать свой код в команду с именем** и вызывать её, когда надо. Всё ещё чистый язык в консоли, без страницы и кнопок. Дальше (урок 2.10) дадим коду свой дом в редакторе, а на уроке 3 вернём кнопки — и эта «команда» ляжет на клик.
**Принцип:** одна строка = один ответ браузера. Между шагами — пинг в чат. Теории не дольше 2 минут подряд.

🎬 Открываешь вкладку → `F12` → вкладка **Console**. Курсор после `>`. Печатаешь `2 + 2` → `4`.

💬 **В чат:** «Какие команды вы уже знаете? Что мы много раз писали со скобками?» (ждём `console.log`, `prompt`, `alert`)

## ШАГ 1 · Один и тот же кусок — снова и снова

🎤 «Допустим, в программе надо в трёх местах красиво поздороваться — в две строки.»

```js
console.log("============")
console.log("  Привет!")
console.log("============")
```

🎬 Печатается рамка с приветом.

🎤 «А теперь то же самое нужно ещё и ещё — внизу программы, потом снова. Копировать эти три строки каждый раз? Скучно, и если захочу поменять рамку — править придётся везде. Должен быть способ дать этому куску **имя** и звать по имени. Он есть — это функция.»

💬 **В чат:** «Сколько раз вы копипастили один и тот же кусок? Бесит?»

## ШАГ 2 · Объявляем свою команду

🎤 «Заворачиваем наш кусок в команду и даём ей имя — `privet`.»

```js
function privet() {
  console.log("============")
  console.log("  Привет!")
  console.log("============")
}
```

🎬 Нажал Enter — и… **ничего не напечаталось.** Только скромное `undefined`.

🎤 «Заметили? Мы команду только **объявили** — описали, что она делает. Но не запустили. Это как записать рецепт: записать ≠ приготовить. Чтобы команда сработала, её надо **вызвать**.»

💬 **В чат:** «🤔 кто заметил, что ничего не вывелось?»

> ⚠️ Тут — половина смысла урока. Объявить ≠ запустить. Дай паузу, не торопись к вызову.

---

## ШАГ 3 · Вызываем — по имени со скобками

🎤 «Чтобы запустить команду — пишем её имя и **круглые скобки**. Скобки значат "вызови".»

```js
privet()
```

🎬 Печатается наша рамка с приветом. А теперь — фокус:

```js
privet()
privet()
privet()
```

🎬 Три рамки подряд — а кода написали одну строчку трижды, не копируя нутро.

🎤 «Вот зачем команда: написал один раз — зовёшь сколько угодно. Захочу поменять рамку — поправлю в **одном** месте, и поменяется везде.»

💬 **В чат:** «🔁 если понятно, что скобки `()` — это "запусти команду".»

> ⚠️ Сразу покажи граблю: набери `privet` **без скобок** → браузер выведет само тело функции, а не выполнит её. «Без скобок — показал рецепт. Со скобками — приготовил.»

## ШАГ 4 · Параметр — дырка-настройка

🎤 «Пока команда всегда говорит одно и то же. А хочется здороваться по имени. Сделаем в команде **дырку** — её заполняем при вызове.»

```js
function privet(imya) {
  console.log("Привет, " + imya + "!")
}
```

🎤 «`imya` в скобках — это и есть дырка, она называется **параметр**. Теперь при вызове кладём в скобки, чем дырку заполнить.»

```js
privet("Саня")
privet("Лиза")
privet("Тигр")
```

🎬 Печатается «Привет, Саня!», «Привет, Лиза!», «Привет, Тигр!». Команда одна — а здоровается с кем угодно.

🎤 «То, что положили в скобки при вызове (`"Саня"`), приехало внутрь команды в коробочку `imya`. Одна команда — настраивается под каждый вызов.»

💬 **В чат:** «Чьё имя подставить? Кидайте — наберу вживую.»

> ⚠️ Кавычки вокруг имени обязательны — это текст. `privet(Саня)` без кавычек → красная ошибка.

## ШАГ 5 · Да вы уже всё это знаете!

🎤 «А теперь — главный сюрприз. Посмотрите на `console.log("Привет")`. Имя — `console.log`. Скобки — "вызови". В скобках — настройка. Это **функция**! Просто её написали не мы, а создатели браузера.»

```js
console.log("я функция")
prompt("я тоже")
Number("42")
```

🎤 «`console.log`, `prompt`, `Number` — это всё чужие команды. Мы их зовём со скобками с первого урока JS. А сегодня научились делать **свои** такие же. Никакой новой магии — вы это умели, просто теперь знаете, как называется.»

💬 **В чат:** «🤯 если щёлкнуло, что `console.log` — такая же функция, как наша `privet`.»

> ⚠️ Это момент «ага» всего урока. Дай ему прозвучать, не пробегай.

## ШАГ 6 · Упакуем цикл в команду (кульминация)

🎤 «Соберём настоящее. Помните узор из звёздочек с прошлого урока? Завернём его в команду — пусть рисует ряд любой длины.»

```js
function ryad(n) {
  let uzor = ""
  for (let i = 1; i <= n; i++) {
    uzor = uzor + "⭐"
  }
  console.log(uzor)
}
```

🎤 «Внутри — знакомый цикл из урока 2.7. Снаружи — наша команда с дыркой `n`: сколько звёзд.»

```js
ryad(3)
ryad(5)
ryad(10)
```

🎬 Печатается `⭐⭐⭐`, потом `⭐⭐⭐⭐⭐`, потом ряд из десяти.

🎤 «Дал команде число — она сама прогнала цикл и нарисовала ряд. Цикл спрятан внутри: снаружи просто `ryad(5)`. Вот так из кирпичиков собираются большие программы — каждая команда прячет свою работу.»

💬 **В чат:** «Ряд из скольких звёзд нарисовать? Кидайте число.»

> ⚠️ Покажи связь руками: «внутри — цикл с прошлого урока, снаружи — команда с этого». Два урока встретились.

## ШАГ 7 · Две дырки и тизер (для вариативности / сильных)

🎤 «Дырок может быть несколько. Команда, что считает площадь, — две дырки через запятую.»

```js
function ploshad(a, b) {
  console.log("Площадь: " + (a * b))
}
ploshad(3, 4)
ploshad(10, 2)
```

🎬 Печатается `Площадь: 12`, потом `Площадь: 20`.

🎤 «Два параметра `a` и `b` — заполняем по порядку: первое число уедет в `a`, второе в `b`.»

🎤 «И напоследок — на подумать до следующего раза. Сейчас наши команды сами печатают. А бывает, что команда не печатает, а **отдаёт** результат обратно — чтобы его можно было сложить, сравнить, положить в коробочку. Это слово `return`, и про него — в другой раз.»

## ИТОГ на экране (что прозвучало)

- Функция — своя команда с именем: упаковал код, зовёшь по имени
- Объявить ≠ запустить: `function privet() { ... }` только описывает; чтобы сработало — **вызвать** `privet()`
- Скобки `()` = «вызови». Без скобок браузер показывает тело, а не выполняет
- Параметр — дырка-настройка: `function privet(imya) { ... }`, вызов `privet("Саня")`
- Параметров может быть несколько: `ploshad(a, b)` → `ploshad(3, 4)`
- `console.log`, `prompt`, `Number` — тоже функции, просто чужие
- Ловушка: вызвал без скобок (`privet`) или объявил, но не вызвал → ничего не сработало

Резерв — открой `index-final.html`, там все строки этого урока с ответами.

## 🆘 Если живой кодинг встал

1. **Объявил функцию — ничего не вывелось** → это норма: объявление само не печатает. Надо **вызвать** со скобками: `privet()`.
2. **Браузер показал текст функции вместо работы** → вызвал без скобок (`privet` вместо `privet()`). Допиши `()`.
3. **«Красная ошибка»** → проверь: имя в скобках — в кавычках (`privet("Саня")`); фигурные `{ }` открыты и закрыты; круглые скобки на месте. Ещё частое — кавычки-ёлочки и русская раскладка.
4. **Совсем сломалось** → открой `index-final.html`, дальше веди по нему: там готовые строки с ответами.
