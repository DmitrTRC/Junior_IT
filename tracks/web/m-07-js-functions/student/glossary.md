# 📖 Словарик урока 2.9 — «Своя команда: функции»

> Объясняем простыми словами, без «возвращаемое значение/область видимости/аргумент vs параметр/стек вызовов». Эти слова — позже. Сегодня только: своя команда, вызов, дырка-настройка. `return` НЕ вводим.

| Слово | Простыми словами | Пример |
|---|---|---|
| **функция** | Своя команда с именем. Упаковал кусок кода — зовёшь по имени, когда надо. | `function privet() { ... }` |
| **`function`** | Слово, с которого начинается объявление команды. Дальше — имя, скобки и фигурные `{ }` с кодом. | `function privet() { ... }` |
| **объявить** | Описать команду — что она делает. Сама по себе она ещё не работает (как записать рецепт). | `function privet() { ... }` |
| **вызвать** | Запустить команду по имени со **скобками**. Только теперь код внутри выполнится. | `privet()` |
| **`()` скобки вызова** | «Запусти команду». Без скобок браузер покажет тело функции, а не выполнит. | `privet()` vs `privet` |
| **параметр** | Дырка-настройка в скобках при объявлении. Заполняется при вызове. | `function privet(imya) { ... }` |
| **`+` склейка** | Соединить текст и значение дырки в одну строку. | `"Привет, " + imya + "!"` |
| **`{ }` фигурные скобки** | «Вот это команда и делает» — код тела функции. | `{ console.log(imya) }` |

---

## Главная мысль урока одной строкой

Функция — это **своя команда с именем**: упаковал код один раз, зовёшь сколько угодно и с разной настройкой. `console.log` и `prompt` — такие же команды, просто их написали другие.

## Главная ловушка, из-за которой «не работает»

**Вызов без скобок.** Если написать `privet` без `()`, браузер не выполнит команду, а покажет её тело. Запускает команду только имя **со скобками**: `privet()`. Рядом — вторая частая: объявил функцию, но не вызвал → ничего не вывелось, и это нормально (объявление само не печатает).
