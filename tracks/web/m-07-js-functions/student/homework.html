Своя команда
с именем

Сегодня соберёшь свои команды в консоли. Главное слово — function. Шпаргалка рядом.

1Открой консоль

Открой любой сайт (хоть пустую вкладку) и нажми F12 → вкладка Console. На Mac в Chrome — Cmd + Opt + J.

Печатаешь строку → Enter → браузер отвечает. Сегодня ты научишь его своим командам.

2Команда, которая здоровается

Сначала объяви команду с дыркой-именем. Заметишь: после объявления ничего не печатается — это норма.

💛
Сначала прочитай, потом запускай. Объявление само не печатает — «ничего не вывелось» после function это не ошибка. Печать начнётся, когда вызовешь команду со скобками.
// объявили команду с дыркой imyafunction privet(imya) {  console.log("Привет, " + imya + "! Рад тебя видеть.")}// теперь вызываем — заполняем дыркуprivet("Саня")privet("Лиза")privet("мой кот")

Одна команда — а здоровается с кем угодно. Что положишь в скобки при вызове, тем и заполнится дырка imya.

3Команда, которая рисует ряд

Вторая команда прячет внутри цикл с прошлого урока. Дашь число — она сама нарисует ряд из стольких звёзд.

function ryad(n) {  let uzor = ""  for (let i = 1; i <= n; i++) {    uzor = uzor + "⭐"  }  console.log(uzor)}ryad(3)ryad(7)

Цикл спрятан внутри команды. Снаружи ты просто зовёшь ryad(7) — и не думаешь, как он работает. Так из команд собираются большие программы.

4Сделай это СВОИМ

  1. Вызови privet с тремя разными именами — каждый раз новое приветствие
  2. Поменяй текст внутри privet на свой — и все вызовы сразу изменятся
  3. Вызови ryad на 3 разных числах — ряд короче/длиннее?
  4. В ryad поменяй "⭐" на свой символ — "🔥", "#", "❤"

✦ Идеи для прокачки

  • Команда ataka(imya) — печатает «💥 Враг получил урон!»
  • Две дырки: ploshad(a, b) печатает a × b
  • Спроси имя через prompt и передай его в privet(...)
  • Команда privetVsem — здоровается сразу с несколькими именами

5Покажи и пришли

  1. Покажи родителям — пусть назовут имя, а ты вызови privet("их имя")
  2. Сделай скриншот консоли (Print Screen на Windows, Cmd+Shift+4 на Mac)
  3. Пришли скриншот мне в чат — посмотрю, дам совет

✓ Проверь себя

Если одна твоя команда работает по-разному в зависимости от того, что положил в скобки — значит функция с параметром работает и задача выполнена. Красава.

Не работает?

Это нормально, у всех так бывает. Проверь по порядку:

→ После function ничего не вывелось? Это норма — надо вызвать команду со скобками: privet("Саня")
→ Браузер показал текст функции? Вызвал без скобок — допиши ()
→ Имя в скобках обернул в кавычки? privet("Саня"), не privet(Саня)
→ Фигурные { } открыты и закрыты? Круглые скобки на месте?
→ Кавычки английские ", слово function английскими буквами?

Если «ничего не происходит» — почти всегда забыты скобки вызова. Совсем застрял — пиши мне.
