# 🛠 Живое упражнение: код маршрута

Пустой текстовый файл или бумага. Никаких установок, битов и таблиц ASCII.

1. **Слайды 1–2.** Напиши `○` и спроси, что это значит. Прими разные ответы:
   смысл ещё не оговорён. Затем договоритесь о таблице:

   ```text
   ○ = море
   △ = горы
   □ = лес
   ```

   Все знаки вместе — алфавит нашей системы. Правила: один знак — одно место,
   порядок слева направо — порядок посещения мест.

2. **Слайд 3.** Покажи уже знакомое `print("Привет")`. Не нужно заново запускать
   интерпретатор. Ученик разделяет Python-команду и русское слово в кавычках.

3. **Слайд 4.** Дай маршрут «море → лес → горы». Ученики сначала сами запишут
   `○□△`; не открывай ответ заранее. Второй участник прочитает по таблице.
   При 1:1 преподаватель передаёт ученику новый маршрут `△○□`, ученик расшифровывает.

4. **Слайд 5.** Спроси: «Текст “море” и фотографию моря видим глазами.
   Значит ли это, что форма представления одинакова?» Нет: текст — знаковая,
   фотография — образная. Если слово произнесли, воспринимаем его слухом;
   язык остаётся естественным.

Финальная реплика: «Файл хранит запись. Чтобы её прочитали другие,
нужны известные им правила. GitHub передаст файл, но смысл сам не объяснит».
