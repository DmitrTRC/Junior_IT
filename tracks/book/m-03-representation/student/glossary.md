# 📖 Представление информации — словарик

| Учебник (рус) | В проде (eng) | Что это одной строкой |
|---|---|---|
| Знак | sign | Обозначение предмета, действия, свойства или отношения. |
| Пиктограмма | pictogram | Знак, изображение которого подсказывает смысл. |
| Символ | symbol | Знак, значение которого принято по договорённости. |
| Знаковая система | sign system | Набор знаков и правила их использования. |
| Алфавит | alphabet | Все знаки, которые разрешены в данной системе. |
| Естественный язык | natural language | Язык общения людей, например русский. |
| Формальный язык | formal language | Язык с явно заданными правилами записи, например Python. |
| Представление информации | information representation | Форма, в которой выражены сведения. |
| Восприятие | perception | Получение сообщения органами чувств. |
| Кодирование | encoding | Запись сообщения по выбранному правилу. |
| Декодирование | decoding | Восстановление сообщения по правилу, которым оно записано. |
