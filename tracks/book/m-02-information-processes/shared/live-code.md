# 🛠 Живая схема: встреча и файл

Это живая схема, а не отдельный урок программирования. Ученики отвечают,
затем преподаватель дописывает схему в пустом текстовом файле или на доске.

1. **Слайды 1–2.** Спроси: «Узнал время встречи, записал и отправил другу.
   Что я сделал с информацией?» После ответов запиши:

   ```text
   расписание → узнал время       сбор
   рассчитал, когда выходить      обработка
   записал время в календарь     хранение
   отправил время другу          передача
   ```

2. **Слайд 3.** Дай два примера без ответа. Ученики называют тип обработки;
   только потом допиши «новое содержание» и «новая форма».

   ```text
   120 и 80 рублей → 200 рублей
   «восемь вечера» → «20:00»
   ```

3. **Слайд 4.** Оставь три пустых места. Один ученик называет источник,
   другой — канал, третий — приёмник. При 1:1 один заполняет всё.

   ```text
   [          ] → [          ] → [          ]
   ```

   Ответ для чата: человек → интернет и чат → друг.
   Друг ответил — стрелка идёт обратно. Уточни полную схему учебника:
   устройства по краям канала кодируют и декодируют сообщение.

4. **Слайд 5.** Не имитируй реальную поломку Zoom. Скажи:
   «Условная ситуация: шум помешал расслышать время. Как уточнить?»
   Ученик предлагает способ, затем повторяет полное сообщение «Встреча в 18:00».

5. **Слайд 6.** Покажи сохранённый файл с уже знакомой строкой
   `print("Встреча в 18:00")`. Спроси, где хранение, где вывод.
   Не называй `print()` сохранением файла. Нового Python-кода здесь не добавляем;
   ввод и вычисление будут отдельным блоком. Отправку в GitHub только связываем
   с передачей — её выполнят в блоке DevOps.
