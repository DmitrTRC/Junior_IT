# Словарик

| Учебник (рус) | В проде (eng) | Что это одной строкой |
|---|---|---|
| интерпретатор | interpreter | программа, которая читает твой код и сразу его выполняет, строка за строкой |
| командный режим | REPL | печатаешь одну строку — сразу видишь ответ, не дожидаясь запуска всего файла; в учебнике — «командный (интерактивный) режим» |
| скрипт | script | программа, записанная в файл — набор команд, которые выполняются по порядку |
| вывод | output | то, что программа печатает на экран, обычно командой `print` |
| строка | string | текст в кавычках; без кавычек Python ищет имя, а не текст |
| ошибка | traceback | сообщение о том, что пошло не так; читается снизу вверх — сначала что случилось, потом где |
