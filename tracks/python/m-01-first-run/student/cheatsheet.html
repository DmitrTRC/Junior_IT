Первый запуск Python

first run · §5.1, 8 класс

REPL (read-eval-print loop) — запуск и выход

Одна команда — сразу ответ. Пока на экране >>>, ты разговариваешь с Python напрямую.

% python3
Python 3.12.0
>>> 2 + 2
4
>>> exit()
%

print — строка (string) и число

Текст — обязательно в кавычках. Без них Python ищет имя переменной, а не текст.

print("Привет")
Привет

print(2 + 2)
4

Файл и запуск

nano — редактор текста прямо в терминале. Сохранить: Ctrl+O → Enter. Выйти: Ctrl+X.

touch hello.py
nano hello.py
# три строки с print, сохранить, выйти
python3 hello.py
в >>> ты разговариваешь — в файле пишешь письмо: он дочитывает всё и только потом отвечает

Ошибка (traceback) — читай снизу вверх

  File "/Users/имя/code/junior_it/hello.py", line 1
    print("Привет! Меня зовут Аня)
          ^
SyntaxError: unterminated string literal (detected at line 1)
1 снизу — что случилось: строка осталась незакрытой
2 выше — где: файл, строка 1; стрелочка стоит под открывающей кавычкой — оттуда Python искал конец строки и не нашёл

Термины

Интерпретатор (interpreter) — читает код и сразу выполняет, строка за строкой. Скрипт (script) — программа, записанная в файл. Вывод (output) — то, что напечатал print.

Если что-то пошло не так

Красный текст — не поломка компьютера, а Python вежливо объясняет, что не понял, и говорит, где смотреть.

Не в той папке — pwd, чтобы посмотреть, и cd ~/code/junior_it, чтобы вернуться.
