JS · в браузере

Программировать ты уже умеешь. Меняется место, где это работает, — не то, как ты думаешь.
// термин · REPL

Интерпретатор (interpreter)

% python3 Python 3.12.0 >>> 2 + 2 4
Программа, которая читает твою строку и сразу её выполняет — что в браузере с JS, что здесь. Разница только в том, что тут этот процесс виден напрямую: окно называется REPL, а >>> — его способ сказать «жду следующую строку».
// такт 3 · REPL и файл — это разные режимы

Разговор против письма

>>>
REPL

строка → Enter → сразу ответ

.py
файл

пишешь всё → запускаешь → ответ в конце

В >>> ты разговариваешь с Python. В файле — ты пишешь ему письмо: он дочитывает всё целиком и только потом отвечает.
// такт 4 · ошибка нарочно

Traceback читается снизу вверх

File "hello.py", line 1 print("Привет! Меня зовут Аня) ^ SyntaxError: unterminated string literal (detected at line 1)
1 снизу — что случилось: строка осталась незакрытой
2 выше — где: файл, строка 1, стрелочка на месте пропажи
// что запомнить

Итог

REPL — для проб, файл — для программ. Ошибка — не поломка, а подсказка: читай снизу вверх. Это глава восьмого класса — школа дойдёт через год. А по соседству в учебнике та же программа есть и на Паскале: язык меняется, алгоритм — нет.
