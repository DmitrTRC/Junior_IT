# Живой код: программа выбирает

Ученик набирает `route.py` в знакомом редакторе и шарит экран. Преподаватель
даёт короткую опору, затем возвращает клавиатуру ученику. Команда запуска:
`python3 route.py` или уже работающая `python route.py` на Windows.

## 1. Знакомый ввод — 0–5 минут

```python
place = input('Куда идём: лес или море? ')
print(place)
```

Ученик создаёт файл, набирает, сохраняет и запускает с ответом `лес`.
«Где хранится ответ? Как дать совет только для леса?» Ответ вводится
в консоли без кавычек, затем Enter.

## 2. Две ветки — 5–10 минут

Заменить `print(place)`:

```python
if place == 'лес':
    print('Берём фонарик')
else:
    print('Выбран другой маршрут')
```

Прочитать: «Если ответ точно совпал с “лес”, берём фонарик. Иначе — другой
маршрут». Объяснение до 90 секунд, затем ученик набирает сам. Предсказывает
реплику, запускает с `лес`. Одна ветка выполняется, другая пропускается.

## 3. Знаки и отступы — 10–15 минут

Ученик показывает в своём файле `=` и `==`: сохранить ответ и сравнить ответ.
После условия и `else` — двоеточие; перед двумя вложенными `print` —
по 4 пробела. Редактор может добавить отступ сам, ученик находит его на экране.
Запуск с `море`: назвать ожидаемую ветку до Enter, найти её вывод.

## 4. Все прочие ответы — 15–20 минут

Три отдельных запуска одного файла: `лес`, `море`, `Лес`.
Перед каждым ученик предсказывает вывод. Код между запусками не меняется.
`else` — все прочие ответы, а не синоним «море». Регистр и пробелы значимы:
`лес ` с пробелом на конце тоже не совпадёт. Не вводить методы обработки строк.

## 5. После выбора — 20–25 минут

Добавить последнюю строку без отступа. Полный файл:

```python
place = input('Куда идём: лес или море? ')
if place == 'лес':
    print('Берём фонарик')
else:
    print('Выбран другой маршрут')
print('Маршрут готов')
```

Ученик запускает с `лес` и `море`, в обоих выводах находит общий финал.
Показывает, чем положение последнего `print` отличается от строк внутри веток.

## 6. Свой маршрут — 25–33 минуты

Убрать готовый код со слайда. Ученик сам выбирает другое слово для сравнения,
меняет вопрос и обе реплики. На 28-й минуте попросить показать изменённое
условие и предсказать ответ; затем продолжить набор. Реплика `else` должна
подходить для всех прочих ответов. Сохранить и запустить: точное совпадение,
другое слово, совпадающее слово с изменённой заглавной буквой.

## 7. Объяснение по своему файлу — 33–37 минут

Ученик показывает условие, две ветки, общий финал. Объясняет один из трёх
запусков. Если учеников несколько, каждый показывает свой файл и свой вывод.
Демонстрация преподавателя не заменяет запуск ученика.

Если времени мало, сократить обсуждение вариантов своего маршрута. Сохранить
набор учеником, три ответа и общий финал. Если быстро — ученик придумывает
неожиданный ответ и предсказывает ветку, новых конструкций не добавляем.
