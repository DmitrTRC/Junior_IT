Ветвление:
программа выбирает

Ты вводишь место. Программа выбирает одну из двух реплик.

Ветвление (branching) — разные действия в зависимости от условия.

Открой новый файл route.py. Код набираешь ты.

Сначала получим ответ

place = input('Куда идём: лес или море? ')
print(place)

Сохрани. Запусти. Введи лес и нажми Enter.

Покажи, где хранится ответ. Как выдать совет именно для леса?

Если лес — берём фонарик

if place == 'лес':
    print('Берём фонарик')
else:
    print('Выбран другой маршрут')

Замени print(place) этим фрагментом.

if — если условие верно; else — иначе.
Предскажи результат для лес, затем запусти.

Два знака и четыре пробела

place = input(...) — присваивание (assignment): сохранить ответ.

place == 'лес' — сравнение (comparison): совпадает ли текст?

После if и else — двоеточие. Перед их print — 4 пробела.

Найди в своём файле условие (condition) и отступ (indentation). Запусти с ответом море.

else — все прочие ответы

лес → Берём фонарик

море → Выбран другой маршрут

Лес → Выбран другой маршрут

Запусти один файл с каждым из трёх ответов. Перед Enter назови ожидаемую реплику.

Регистр и пробелы значимы: «Лес» и «лес » не совпадают с «лес».

А эта строка — после выбора

if place == 'лес':
    print('Берём фонарик')
else:
    print('Выбран другой маршрут')
print('Маршрут готов')

Добавь последнюю строку без отступа. Запусти с лес и море: она появляется в обоих случаях.

Теперь твой выбор

  • Сам выбери другое слово в условии и обнови вопрос.
  • Придумай обе реплики — для совпадения и всех прочих ответов.
  • Запусти с точным словом, другим словом и изменённой заглавной буквой.

Покажи, какая ветка сработала и какая строка выполняется после выбора.
