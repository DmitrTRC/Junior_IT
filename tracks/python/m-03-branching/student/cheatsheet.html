Программа выбирает

Ветвление (branching) · Junior_IT

Две ветки и общий финал

place = input('Куда идём: лес или море? ')
if place == 'лес':
    print('Берём фонарик')
else:
    print('Выбран другой маршрут')
print('Маршрут готов')

if выбирает первую ветку, когда условие (condition) верно. else выбирает вторую при любом другом ответе.

Последний print без отступа стоит после ветвления: «Маршрут готов» появляется в обоих случаях.

Не путай знаки

= — присваивание (assignment): сохранить значение в переменной.
== — сравнение (comparison): совпадают ли значения?

После условия if и слова else ставь :. Отступ (indentation) перед каждой командой внутри ветки — 4 пробела. if и else начинаются на одном уровне.

Три ответа одному файлу

  • лес → «Берём фонарик».
  • море → «Выбран другой маршрут».
  • Лес → «Выбран другой маршрут».

else означает все прочие ответы, а не только «море». Регистр и пробелы значимы: 'лес ' с пробелом в конце не совпадает с 'лес'.

Сохрани route.py и запусти python3 route.py или знакомой командой python route.py на Windows. Ответ вводи в консоли без кавычек, затем Enter.

Если результат удивил

  • Всегда вторая ветка → сравни ответ с текстом условия, включая буквы и пробелы.
  • Ошибка → прочитай последнюю строку сообщения и найди номер строки; сверь ==, двоеточия, кавычки и отступы.
  • Общий финал появляется только иногда → убери отступ у последнего print.
  • После правки старый результат → сохрани и запусти нужный файл заново.
Домашка: «Свой маршрут». Придумай своё условие и обе реплики; покажи три запуска.
