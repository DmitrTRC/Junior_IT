# Словарик: программа разговаривает

| Учебник (рус) | В проде (eng) | Что это одной строкой |
|---|---|---|
| Ввод | input | Человек сообщает программе данные; `input` ждёт текст и Enter. |
| Вывод | output | Программа показывает результат; `print` выводит текст и значения. |
| Переменная | variable | Имя, по которому программа обращается к сохранённому значению. |
| Строка | string | Текст; ответ `input` тоже является строкой. |
