Ввод (input) и вывод (output) · §5.2, 8 класс · Junior_IT

Один вопрос и ответ

name = input("Твой ник: ")
print("Привет,", name)

input показывает вопрос и ждёт. Напечатай ответ в консоли и нажми Enter.

Ответ сохранится в переменной (variable) name. Затем print выведет его вместе с приветствием.

Что писать в кавычках

"Твой ник: " — готовый текст вопроса. name без кавычек — значение переменной.

При вводе ответа кавычки не нужны: просто напечатай ник и Enter.

Ответ input — строка (string). Даже 42 здесь остаётся текстом; сегодня вычисления из ввода не нужны.

Сохранить → запустить → ответить

python3 dialogue.py

На Windows используй python dialogue.py, если так запускал на занятии. Команду запуска вводи в терминале, код — в редакторе.

Новый запуск с другими ответами меняет результат без изменения файла.

Если программа ждёт или ругается

  • Вопрос есть, дальше тишина → введи ответ и нажми Enter.
  • Старый вопрос → сохрани файл и запусти именно его.
  • Ошибка → последняя строка, затем номер строки; проверь кавычки и скобки.
  • Видишь >>> → exit(), затем команда запуска файла.
