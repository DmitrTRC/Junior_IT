# Живой код: программа разговаривает

Ученик набирает в знакомом редакторе, запускает в знакомом терминале.
Новый файл — `dialogue.py`. Рабочая команда с прошлого занятия:
`python3 dialogue.py` или `python dialogue.py` на Windows.
Не устанавливаем новый редактор и не меняем окружение.

## 1. Мост от знакомого — 2 минуты

```python
name = "Лис"
print("Привет,", name)
```

Сохрани, запусти. «Откуда программа взяла ник?» Ученик показывает строку
присваивания. «А если её запустит другой человек?»

## 2. Ник вводит человек — 6 минут

Замени только первую строку:

```python
name = input("Твой ник: ")
print("Привет,", name)
```

Сохрани и запусти. Ник вводится **в консоли работающей программы**,
без кавычек; затем нажми Enter. В редактор вводится код.
«Программа ждёт твой ответ. После Enter ответ окажется в `name`».

Запусти снова с другим ником, не изменяя файл. Ученик сначала предсказывает
приветствие, потом запускает. Ввод (input) → переменная (variable) → вывод (output).

## 3. Ещё один вопрос — 6 минут

Ученик сам выбирает текст вопроса. Пример занятия:

```python
favorite_game = input("Любимая игра: ")
print("Твоя игра:", favorite_game)
```

Добавь эти строки после приветствия. Сохрани. Запусти весь файл и ответь
на оба вопроса. Не использовать настоящее полное имя, адрес или пароль.
«В какой строке программа остановится во второй раз?»

## 4. Два запуска — 5 минут

- Первый запуск: ник `Лис`, игра `Minecraft`.
- Второй запуск: придумай другой ник и другую игру. Код остаётся тем же.
- Найди на экране оба новых ответа. Объясни, почему ответы поменялись.

`input` возвращает строку (string). Даже ответ `42` здесь — текст.
На этом занятии работаем с текстом; превращение в число — отдельная идея.

## 5. Самостоятельно — 6 минут

Убери подсказку со слайда. Попроси изменить второй вопрос на любимый жанр
и придумать свою подпись в `print`. Сохрани и запусти дважды.
Подсказывай вопросом: «Где сохраняется ответ? Где мы его выводим?»

Если залипли: Enter после ответа; парные прямые кавычки в коде;
сохранение файла; команда запуска в терминале, код в редакторе.
Если сейчас видно `>>>`, выйди через `exit()` перед командой запуска файла.
