## Если трудно

- Вопрос появился, дальше тишина: программа ждёт ответ **и Enter**.
- Набирает ответ в редакторе: покажи окно консоли, где программа ждёт ввод.
- После правки старый вопрос: файл сохранён? Запущен именно `dialogue.py`?
- Ошибка кавычек: прямые парные кавычки вокруг вопроса; вокруг имени переменной
  в `print` кавычки не нужны.
- Команда запуска попала после `>>>`: `exit()`, затем запуск из терминала.

Если темп низкий, оставь один вопрос до уверенного второго запуска; второй
вопрос добавьте вместе в конце. Не добавляй `int`, f-строки или ветвление
ради насыщенности. Если темп высокий, пусть ученик самостоятельно придумает
третий вопрос; числовой ввод оставь на отдельный блок.

Тесты — дополнительный локальный инструмент преподавателя, не часть занятия
и не свидетельство готовности автоматической обработки домашних работ.

```sh
DIALOGUE_PATH=/absolute/path/to/dialogue.py tools/.venv/bin/python -m pytest homework/python-02-input/tests/test_dialogue.py -q
```

Тесты запускают указанный файл с двумя ответами, проверяют завершение за
5 секунд и наличие введённых значений в выводе. Проверка разных ответов
отсекает захардкоженное приветствие; Unicode и цифры проверяют текстовый ввод.
Без `DIALOGUE_PATH` тесты пропускаются, а не оценивают отсутствующее решение.
