# Словарик

| Учебник (рус) | В проде (eng) | Что это одной строкой |
|---|---|---|
| терминал | terminal | окно, где ты печатаешь команды текстом вместо кликов мышкой |
| оболочка | shell | программа внутри терминала, которая читает твои команды и выполняет их — на маке по умолчанию это zsh |
| каталог | directory | то же самое, что «папка» в Finder, только слово, которое используют в терминале |
| путь | path | адрес файла или папки внутри компьютера, читается слева направо, как обычный адрес |
| домашний каталог | home directory | твоя личная папка, обозначается значком `~` — команда `cd ~` всегда возвращает сюда |
