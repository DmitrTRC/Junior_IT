OPS · 2

Git и GitHub

Git хранит версии на твоём компьютере.
GitHub — сайт для удалённых репозиториев.

Коммит сам не отправляет файл в интернет.

OPS · 3

Своя учебная папка

Создай git-lab, скопируй туда свой файл.
Открой терминал в этой папке.

git init
git status

Репозиторий (repository) — проект с историей.

OPS · 4

Первая версия

git add dialogue.py
git status
git commit -m "Add dialogue"
git log --oneline

Выбрать → сохранить версию → увидеть историю.

OPS · 5

Сделай вторую

Измени приветствие. Сохрани файл. Запусти его.

git add dialogue.py
git commit -m "Change greeting"
git log --oneline

Чем отличаются две версии?

Код на GitHub
