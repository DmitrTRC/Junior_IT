# Git и GitHub — первые сохранения

20 минут. Обязательный итог — две локальные версии своего файла и
объяснение: редактор сохраняет файл, Git сохраняет историю, GitHub хранит
удалённый репозиторий. Работа через сайт — при готовом доступе.

| Мин | Действие | Результат |
|---|---|---|
| 0–2 | Короткий вопрос: как вернуть вчерашний текст без `final-final`? Создать отдельную `git-lab`, скопировать свой `dialogue.py` | Терминал открыт именно в учебной папке |
| 2–5 | Каждый вводит `git init`, `git status`; один показывает экран | Отличают файл от репозитория |
| 5–9 | `add`, `status`, `commit`, `log`; второй показывает экран | Первый коммит с сообщением |
| 9–15 | Каждый меняет приветствие, запускает файл, снова `add`/`commit`/`log`; третий показывает экран | Два разных коммита |
| 15–19 | GitHub: открыть свой доступный закрытый репозиторий, сохранить файл через сайт, найти History | Сохранён файл в `hw/python-02-input/` либо обозначен блокер доступа |
| 19–20 | Каждый одной фразой: чем отличаются Save, commit и GitHub | Смысл усвоен; следующий шаг — связь локального и удалённого репозиториев |

Все набирают параллельно; экран меняется на чекпоинтах. Теория не дольше
минуты. GitHub не заменяет обязательную практику локального Git.

## До звонка

- Узнать, открывается ли `git --version` у каждого, и есть ли приглашение
  в закрытый репозиторий. Установка и регистрация — отдельное подключение.
- Подготовить отдельную временную папку для показа двух локальных коммитов.
  Не выполнять учебный `git init` внутри Junior_IT или ученического репо.
- Выбрать подпись для локальной учебной истории; пример в live-code
  вымышленный. Не просить пароли, токены или коды входа на общий экран.

## Где залипнут

- `git` не найден: за 60 секунд обозначить блокер. Ученик меняет файл
  и объясняет операции на показе; установка после занятия. Не засчитывать
  показ преподавателя как собственные выполненные коммиты ученика.
- `Author identity unknown`: задать `user.name` и `user.email` только в
  учебном репозитории (без `--global`), повторить commit.
- Подписывание коммита требует ключ: для отдельного учебного repo допускается
  `git config commit.gpgsign false`; настоящие настройки не менять глобально.
- `nothing to commit`: файл сохранён? Выполнен `git add` после изменения?
- Открылся редактор сообщения: использовать `git commit -m "Add dialogue"`.
- GitHub недоступен: не тратить урок на вход. Локальная история остаётся,
  сдача — после настройки с отдельным сроком. Не просить отправлять код
  вместо этого в мессенджер.

## Граница темы

Через сайт создаётся отдельная удалённая версия, не переносится локальная
история. `clone`, `remote`, `push`, аутентификация, ветки и PR ещё впереди.
Отдельный модуль `devops/m-03-github` не объявлять пройденным по одному
показу сайта. Общая домашка — `homework/python-02-input/task.md`.
