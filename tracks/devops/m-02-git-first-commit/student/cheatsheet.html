Git: две сохранённые версии

Git — история на компьютере. GitHub — сайт для удалённых репозиториев (remote repositories).

Первая версия

Терминал открыт в твоей отдельной папке git-lab с dialogue.py.

git init
git status
git add dialogue.py
git commit -m "Add dialogue"
git log --oneline

Коммит (commit) — версия выбранных файлов с сообщением. add подготавливает изменения (staging area).

Следующая версия

Измени приветствие → сохрани файл → запусти.

git status
git add dialogue.py
git commit -m "Change greeting"
git log --oneline

Обычное сохранение не создаёт коммит. История (history) появится после commit.

GitHub через сайт

В доступном закрытом репозитории сохрани hw/python-02-input/dialogue.py. Открой файл и History.

Это отдельное сохранение на сайте. Команда commit не отправляет локальную историю на GitHub.

Если застрял

nothing to commit — сохранил файл и сделал add после изменения?

Author identity unknown — попроси преподавателя помочь с локальной подписью. Пароли и токены на общий экран не показываем.

Нет доступа к GitHub — файл и история остаются на компьютере, настройку завершим отдельно.
