# Словарик Git

| Учебник (рус) | В проде (eng) | Что это одной строкой |
|---|---|---|
| Репозиторий | Repository | Папка проекта, где Git ведёт историю |
| Подготовленные изменения | Staging area | Выбранные изменения для следующего коммита |
| Коммит | Commit | Сохранённая версия выбранных файлов с сообщением |
| История | History | Последовательность сохранённых версий |
| Удалённый репозиторий | Remote repository | Репозиторий на другом компьютере, например на GitHub |
