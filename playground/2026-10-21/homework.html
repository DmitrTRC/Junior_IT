Программа выбирает маршрут

После занятия 21.10. 10–15 минут. Продолжай свой route.py: заново переписывать работающую программу не нужно.

Что сделать

  1. Придумай свой выбор: место путешествия, жанр игры или занятие на выходной.
  2. Спроси ответ через input и сохрани в переменной.
  3. Сравни ответ с одной выбранной строкой через ==. В ветке if выведи подходящее сообщение, в else — сообщение для любого другого ответа.
  4. После обеих веток добавь общий print без отступа: он должен срабатывать при любом ответе. Внутри веток используй четыре пробела.
  5. Сохрани файл и выполни три запуска: точное совпадение, другой ответ, тот же ответ с другой заглавной/строчной буквой. До запуска предскажи ветку.
  6. В runs.txt запиши три пары «ввёл → увидел» и одной фразой объясни, чем = отличается от ==. Если прогноз не совпал — укажи, что выяснил.

Например, для условия place == "лес": лес включает первую ветку, море и Лес — вторую. Точное сравнение различает регистр и пробелы. Не пиши во второй ветке «Ты выбрал море»: человек мог ввести что угодно.

Запуск: python3 route.py или знакомая python route.py на Windows. Для готовой программы с урока достаточно своего изменения и трёх запусков.

Если застрял

Сначала оставь input и print с ответом и запусти. Потом верни ветвление (branching). Посмотри двоеточия после if и else, одинаковые отступы и прямые кавычки. else стоит на одном уровне с if.

Шпаргалка по ветвлению.
