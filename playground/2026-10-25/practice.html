Одинаковые цифры — разные действия

Создай отдельный types_lab.py. Прежде чем набирать, предскажи оба ответа:

print("5" + "2")
print(5 + 2)

Запусти python3 types_lab.py или python types_lab.py. Затем выбери свою пару чисел и повтори опыт. Что меняют кавычки?

Сверить результат

52 и 7. Для строк + соединяет текст, для чисел — складывает значения.

Спроси Python о типе значения

print(type("5"))
print(type(5))
print(type(2.5))
print(type(5 == 2))

type() показывает тип (type). В выводе <class 'int'> нам пока нужно только имя int.

ТипЧто хранитПример
strСтрока (string)"5", "лес"
intЦелое число (integer)5, -2
floatЧисло с плавающей точкой (floating-point number)2.5
boolЛогическое значение (boolean)True, False

В дробном числе — точка. True без кавычек — логическое значение, "True" — строка. Предскажи тип каждого, затем убедись через type().

Ветвление (branching)

Вернись в route.py. Сначала замени вывод ответа на print(place == "лес"): какое логическое значение получится? = присваивает, == сравнивает.

Теперь вместо временного вывода сравнения набери:

if place == "лес":
    print("Берём фонарик")
else:
    print("Выбран другой маршрут")

Внутри каждой ветки четыре пробела. else на одном уровне с if; после обоих — двоеточие. Запусти с лес → море → Лес. Сначала назови ожидаемую ветку.

Почему «Лес» — другой маршрут?

Сравнение строк точное: заглавная буква отличается от строчной. else срабатывает при любом несовпадении, даже если введено не «море».

5 · 7 МИНУТ

Ввёл 5. Почему это строка?

В конец types_lab.py допиши две строки, запусти и введи 5:

answer = input("Введи целое число: ")
print(type(answer))

input возвращает строку (string), даже если ты ввёл цифры. Добавь преобразование (conversion) отдельным шагом:

number = int(answer)
print(type(number))
print(number + 1)

Запусти с 5 и 12: получатся 6 и 13. В answer остаётся строка; в number — целое число.

В этом опыте вводи целое число. Слово, пустой ввод или 2.5 вызовут ValueError: такую строку int не преобразует. Повтори запуск с целым числом.

Когда два шага понятны: короткая запись
number = int(input("Введи целое число: "))
print(number + 1)

Сначала работает внутренний input, затем int. Две отдельные строки тоже правильны.

if number >= 10:
