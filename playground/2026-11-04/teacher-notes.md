## Исправление в начале

«На прошлом занятии я по привычке перенёс конструкцию из C в Python. В Python нет синтаксиса do…while, и убирать его оттуда не собираются. Есть while с условием перед телом. Если сначала нужно выполнить действие, а потом решить, повторять ли его, используем while True и условный break после действия».

Не просить переписывать ошибочный do…while. Показать рабочий Python. Уточнить: while True сам по себе не плох; важен понятный выход. В примере с exit break срабатывает при условии выхода, то есть противоположном условию продолжения do…while в C. Обычный while может выполнить тело ноль раз. for получает элементы по очереди; знание количества заранее не требуется. Строка — последовательность символов, не объявляем её массивом.

## Резерв, только по вопросу

continue переходит к следующей итерации; код ниже него в текущей итерации пропускается. while…else выполняет else при нормальном завершении по ложному условию, в том числе при нуле итераций; при break не выполняет. Не превращать это в обязательное упражнение сегодня. Для остановки зависшего учебного цикла — Ctrl+C в терминале.
