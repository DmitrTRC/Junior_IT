Занятие 01.11 · Знак числа

Воскресенье, 20:00–21:15 МСК. Пульт · Практика · Домашка · Анонс · Основание.

28.10 числовые ветки запускал один ученик с подсказками; личный результат остальных не подтверждён. Сегодня главная цель: каждый сам сохраняет и запускает sign.py, показывает две ветки и общий финал на вводах −3, 0, 5. Третья ветка не обязательна. Циклов и новых числовых границ нет.

Перед встречей

  • Открыть практику и редактор, включить запись Zoom; уточнить, что ученики видят нужное окно.
  • Рабочая папка преподавателя: ~/code/junior-it/2026-11-01/. types_lab.py — точная копия фактического файла 28.10; sign.py — новая заготовка; runs.txt — место для наблюдений. Пустой route.py сегодня не нужен. Прошлые даты и существующие ученические файлы не перезаписывать.
  • В копии types_lab.py используются age, int_age и множитель 10. Для опыта заменить age * 10 на age * 3, добавить print(int_age * 3). Не вставлять строки с answer/number поверх существующих имён. Ученики сохраняют свои имена; в новом sign.py вводим answer и number.
  • Менять показывающего экран каждые 3–5 минут. Пока один показывает, остальные набирают у себя и предсказывают вывод. Теория — максимум 2 минуты. При трёх участниках выделить каждому около трёх минут личного показа.
  • Аккаунты, приглашения и установку инструментов вынести за общую встречу. На неполадку Git — максимум 60 секунд, затем локальное сохранение.

Режиссура

Время Действие преподавателя и ученика
20:00–20:08 Каждый открывает прошлый файл, меняет одну реплику, сохраняет и запускает. Остальные предсказывают изменение вывода. Если файла нет — короткий input и print с нуля. Код пишем в файле; терминалом запускаем сохранённый файл.
20:08–20:18 Ввод 12: прогноз для строки × 3 и числа × 3, затем личный запуск. Получить 121212 и 36. Спросить: «Какой тип у результата input? Что сделал int?». type() возвращает объект типа, который print показывает на экране; тему возвращаемого None отдельно не разворачивать.
20:18–20:30 В новом sign.py дети набирают answer = input(...), number = int(answer), затем if number < 0 и else. Реплики: «Отрицательное число» / «Неотрицательное число». Двоеточия, четыре пробела, одинаковый уровень if и else. Запустить −3 и 5.
20:30–20:33 Пауза без экрана. Встать, потянуться, посмотреть вдаль.
20:33–20:48 Добавить общий print("Готово") без отступа после веток. Каждый предсказывает и запускает −3, 0, 5. Общий финал появляется трижды. Спросить: «Почему ноль попал в else?». Ноль ни положительный, ни отрицательный; он не меньше нуля.
20:48–20:58 Каждый показывает обе ветки и общий финал, партнёр предсказывает ответ. Только когда результат показали все, желающие повторяют elif number == 0 перед else; последний ответ теперь «Положительное число». Те же три запуска. Иначе всё время — на личные запуски и исправления.
20:58–21:05 Сохранить файлы. При готовом Git и результате всех: git status, git add sign.py types_lab.py, git commit -m "Add number sign program", git log --oneline. Подставить свои имена файлов. Save, локальный commit и передача на GitHub — разные действия.
21:05–21:15 Открыть домашку. Каждый начинает runs.txt: «ввёл → ожидал → увидел», фиксирует собственный результат и общий финал. Назвать срок: среда, 04.11, 20:00 МСК. Закончить в 21:15.

Если темп ниже

  1. В 20:18 закончить единственный опыт с 12; не расширять разговор о типах и других языках.
  2. Если к паузе ветки не готовы — после неё продолжить минимальный пример. Убрать elif.
  3. Если к 20:58 не каждый показал результат — убрать Git, завершить личные запуски.
  4. Сохранить паузу, последние десять минут на начало домашки и финиш в 21:15.

В int пока вводим только целые числа. Слово, пустой ввод и 2.5 вызовут ValueError: повторить запуск с целым числом, обработку ошибок не вводить. Если ученик сохранил свой пример с elif, не удалять его: отдельный sign.py позволяет самостоятельно повторить базу и сравнить поведение на нуле.
