Списки и циклы: while → for

ПультПрактикаДомашкаСценарий

От разбора — к своему запуску

На занятии 8 ноября разбирали счётчик, выход и пропуск в цикле, а затем список месяцев. Здесь можно повторить примеры. Для домашки достаточно разделов 3–5; остальные — для повторения по желанию.

Создай свой months.py, сохрани и запускай python3 months.py или знакомой командой python months.py на Windows. Если программа не останавливается — Ctrl+C в терминале.

1. Вспомнить while: шаг, чётность и выход

В отдельном counter.py повтори пример. += 1 увеличивает счётчик на единицу; % 2 даёт остаток от деления на 2. Ветвление (branching) выбирает, что печатать.

Пример после своей попытки
counter = 0
while counter <= 20:
    if counter == 10:
        break
    if counter % 2 == 0:
        print(counter)
    else:
        print("Пропущено")
    counter += 1
print("Готово")

Ожидаются числа 0, 2, 4, 6, 8, после каждого — строка «Пропущено», затем «Готово». Значение 10 не печатается: break завершает ближайший цикл до этой строки. Если убрать условие с break, цикл дойдёт до 20 включительно.

2. Почему continue может остановить счётчик?

На занятии получился бесконечный цикл: при значении 6 команда continue пропускала увеличение счётчика в конце тела. Значение оставалось 6.

continue пропускает остаток текущей итерации (iteration); у while снова проверяется условие. Поэтому изменение счётчика нельзя пропускать. Вот исправленный вариант для отдельного опыта:

Пример после своей попытки
counter = 0
while counter <= 10:
    if counter == 6:
        counter += 1
        continue
    print(counter)
    counter += 1
print("Готово")

Ожидаются 0–5, затем 7–10 и один финал. Исправленный вариант здесь дан для повторения; намеренно запускать зависание не нужно.

3. Список, индекс и длина

Список (list) хранит несколько элементов. Индекс (index) — номер элемента от нуля. len(months) возвращает количество элементов. Скопируй список в months.py, а три строки вывода набери сам.

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun",
          "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"]
Пример после своей попытки
print(months[0])
print(months[3])
print(len(months))

Результат: Jan, Apr, 12. Последний индекс — 11; months[12] уже за границей списка.

Строка (string) тоже позволяет обращаться по индексу, но это другой тип: у "Demo string" символ с индексом 4 — пробел.

4. Перебрать месяцы через while

Ниже списка и трёх строк вывода набери цикл. Сначала назови первый и последний месяц.

Пример после своей попытки
index = 0
while index < len(months):
    print(months[index])
    index += 1
print("Готово")

Цикл выводит 12 месяцев от Jan до Dec, затем один финал. Индекс меняется от 0 до 11; при значении 12 условие становится ложным.

Дополнительно: обратный обход, как на занятии
index = len(months) - 1
while index >= 0:
    print(months[index])
    index -= 1
print("Готово")

Замени предыдущий цикл этим: сначала Dec, в конце Jan и «Готово». Для 12 месяцев начальный индекс равен 11.

5. Те же месяцы через for

Замени цикл while вместе со строками индекса на этот вариант. Список и три строки из раздела 3 оставь.

Пример после своей попытки
for month in months:
    print(month)
print("Готово")

Вывод совпадает с прямым обходом через while. month — сам элемент, например "Jan"; index был его номером. for получает элементы последовательно — вручную задавать индекс и заранее знать число повторений не нужно.

Сохрани результаты обоих запусков в runs.txt: «способ → ожидал → увидел».

6. По желанию: пропустить или закончить

Вместо простого for попробуй вариант с пропуском июня:

Пример после своей попытки
for month in months:
    if month == "Jun":
        continue
    print(month)
print("Готово")

Ожидаются 11 месяцев без Jun, затем «Готово». Здесь for сам получает следующий элемент — увеличивать индекс вручную не нужно.

Теперь замени только continue на break. Выведутся Jan, Feb, Mar, Apr, May и финал. Оба оператора стоят перед выводом: июнь не печатается в обоих опытах, но оставшиеся месяцы появляются только с continue.
