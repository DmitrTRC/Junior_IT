## 20:28–20:53 · Python: программа спрашивает

[Пошаговый код](../../tracks/python/m-02-variables/shared/live-code.md),
[сценарий](../../tracks/python/m-02-variables/teacher/scenario.md).

Каждый создаёт `hw/python-02-input/dialogue.py` и набирает сам.
Сначала один вопрос, сохранение и запуск:

```python
name = input("Твой ник: ")
print("Привет,", name)
```

На втором запуске — другой ник; **код менять не нужно**. Затем второй
вопрос про любимую игру или занятие и вывод ответа. Цель — два `input`
и зависимый от ответов вывод. Не начинать одновременно `int`, f-строки,
условия и циклы. `input()` возвращает текст — числовой ввод следующий шаг.

Ротация экрана на трёх чекпоинтах: первый ответ → второй вопрос → повторный
запуск с другими ответами. Остальные всё время пишут у себя.

Если программа «стоит»: она ждёт ответ и Enter. Если не поменялся текст:
сохранён ли файл? Если `>>>`: команда запуска файла вводится в оболочке,
сначала `exit()`. Вопрос задаётся программой, ответ печатает человек.

## 20:53–21:13 · Git, затем GitHub

[Живые команды](../../tracks/devops/m-02-git-first-commit/shared/live-code.md),
[сценарий](../../tracks/devops/m-02-git-first-commit/teacher/scenario.md).

15 минут — локально. Скопировать свой `dialogue.py` в отдельную `git-lab`,
открыть там терминал. Все вводят по одной команде:

```sh
git init
git status
git add dialogue.py
git commit -m "Add dialogue"
git log --oneline
```

Изменить приветствие, сохранить и запустить. Снова `add`, `commit` с другим
сообщением, `log`. Две версии должны появиться у каждого с рабочим Git.
Не путать сохранение в редакторе, выбор изменений (`add`) и снимок (`commit`).

Если нужна подпись автора, готовые локальные команды есть в live-code.
Глобальные настройки не меняем. Установка, ключи, токены — за пределами
общего урока; на один технический блокер не больше минуты.

Последние пять минут — GitHub через сайт при готовом доступе: сохранить
код в `hw/python-02-input/dialogue.py`, открыть файл и History.
Сказать явно: локальный `commit` не отправляет код в интернет, а загрузка
через сайт не переносит два локальных коммита. `clone` и `push` связывают
эти две истории; их практику подготовим следующим отдельным шагом.
