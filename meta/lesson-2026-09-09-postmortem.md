- [ ] **Практики самой ученицы не зафиксировано вообще.** Весь live-coding (JS
      playground, Python `Hello World`, цикл `for`) печатал сам преподаватель на своём
      экране — ученица наблюдала. Это прямое расхождение с методологией курса
      («ребёнок пишет код и шарит экран, а не смотрит запись»).
- [ ] **Где буксовали не ученица, а тайминг педагога:** несколько монологов подряд

      контентно-необязательные фрагменты — 15–20 минут при лимите методологии
      «не дольше 2 минут подряд». Реплики ученицы в эти отрезки короткие и редкие
      (одна-две фразы на несколько предложений преподавателя).

## 💡 Решения, которые приняли по ходу

| Решение | Причина |
|---|---|
| Переход на собственную программу курса с опережением школьного учебника | Школьная программа идёт медленнее и почти без практики программирования — курс дополняет её кодом |
| Домашку присылать фото тетради на личную почту преподавателя | Другой канал (MAX/облако) для этой ученицы ещё не настроен |
| Полный запрет ИИ-инструментов при решении задач по программированию | Чтобы не мешать наработке навыка писать код руками |
| Следующее занятие (воскресенье) — быстро пройти на Python то же, что показано на JS | Провести параллель, не терять темп между языками |
