🛠️ Что уточнить в объяснениях

  • В 43:08–43:32 тройные кавычки названы большим комментарием. Точная формулировка: комментарий начинается с #; тройные кавычки создают строковый литерал. Для временного отключения кода здесь достаточно #. Python: lexical analysis.
  • В 48:00–48:16 аннотация типа может прозвучать как автоматическое ограничение выполнения. Она помогает редактору и анализаторам; сам Python не обеспечивает такую проверку при выполнении. Python: typing.
  • В 58:21–58:59 совет о возрасте при регистрации нужно исправить: базовый минимум GitHub — 13 лет, в отдельных странах может быть выше. Указывать вымышленный возраст не нужно. Для младших — локальный Git, а публикацию выполняет преподаватель; личный аккаунт не является условием участия. GitHub Terms, B.3. Это исправление не отправлено участникам.
