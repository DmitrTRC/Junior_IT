# Домашка: hello.py на переменных

К модулю «Первый запуск Python» (python-01), шаг 6 — переменные.

> На Windows везде ниже: `python` вместо `python3`, `notepad` вместо `nano`.

## Что делать

Открой свой `hello.py` из папки `~/code/junior_it/hw/01/` и перепиши его
так, чтобы весь текст жил в переменных, а `print` их только печатал:

```python
name = "Аня"
hobby = "рисовать комиксы"
dream = "написать свою игру"
print("Меня зовут", name)
print("Я люблю", hobby)
print("Через год хочу", dream)
```

Имена переменных — английские, значения — про тебя. Запусти
`python3 hello.py` — те же три строки, что были, только теперь текст
собирается из коробок с именами.

Потом добавь в конец файла четвёртую строку: сколько тебе лет и сколько
будет через год. Число кладём в переменную без кавычек:

```python
age = 13
print("Мне", age, "а через год будет", age + 1)
```

Запусти ещё раз. Четыре строки и ни одной красной — готово.

## Если что-то не так

- `NameError: name 'nmae' is not defined` — Python не нашёл коробку с таким
  именем: опечатка либо там, где коробку заводишь, либо там, где берёшь из
  неё. Читай снизу вверх, как на занятии.
- Кавычки нужны тексту и не нужны числу. `age = "13"` — это текст, и
  `age + 1` упадёт с `TypeError`. Убери кавычки.
