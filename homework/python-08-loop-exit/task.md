# Цикл с понятным выходом

После занятия **8 ноября**. **10–15 минут**, до **среды, 11 ноября, 20:00 МСК**.

[Практика занятия: while и break](../../docs/practice-2026-11-08.html).

## Если на занятии заработал commands.py

1. Продолжи свой `commands.py`: `while True` повторяет вопрос, `input` получает команду, условный `break` завершает цикл по точному слову `exit`.
2. Для другой команды выведи «Получено:» и саму команду. После цикла без отступа выведи «Готово».
3. Сделай два запуска: сразу `exit`; затем отдельным запуском `read`, `exit`.
4. Перед каждым запуском предскажи число вопросов и весь вывод. В `runs.txt` запиши «ввод → ожидал → увидел». В первом опыте один вопрос и финал; во втором — два вопроса, «Получено: read» и финал. Строки «Получено: exit» быть не должно.
5. Одной фразой объясни, куда переходит программа после `break`.

Сохраняй файл перед запуском. Команда — `python3 commands.py` или знакомая `python commands.py` на Windows. Отвечай в терминале. Если цикл не останавливается — `Ctrl+C`.

## Если break на занятии не успели

Продолжи свой `counter.py`: начало 1, условие `< 6`, увеличение на 1 — вывод 1–5. Измени условие на `< 3`: ожидаются 1, 2. Если вместе пробовали начало 3 при `< 3`, повтори и этот опыт: тело не выполняется. Во всех случаях общий финал стоит без отступа. Сохрани работающий код, результаты и вопрос преподавателю. Новую конструкцию самостоятельно достраивать не нужно.

## Что сохранить

`commands.py` **или** запасной `counter.py`, а также `runs.txt`. Обязательного коммита нет. При уже готовом доступе и знакомом способе передачи используй свой закрытый учебный репозиторий, `hw/python-08-loop-exit/`; иначе сохрани локально и покажи на следующей встрече.

Дополнительно, только если вместе делали на уроке: команда `skip` с `continue`. Опыт `skip → read → exit`: три вопроса, только «Получено: read», один общий финал. `for` и `while…else` в этой домашке не нужны.
