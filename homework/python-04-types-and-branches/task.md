## Четыре типа

Создай `types_lab.py` в своей учебной папке. Если уже есть свой файл
с опытом по типам, продолжай его — имя менять не нужно.

Перед запуском предскажи тип каждого значения, затем набери и выполни:

```python
print(type(10))
print(type(5.7))
print(type("Привет"))
print(type(True))
```

Сверь названия: `int` — целое число (integer),
`float` — число с плавающей точкой (floating-point number),
`str` — строка (string), `bool` — логическое значение (boolean).
В дробном числе нужна точка. У `True` нет кавычек.
Замени число и текст своими примерами, а `True` — на `False`. Запусти снова:
изменились значения или типы?

## Ввёл цифры — получил строку

В тот же файл добавь:

```python
answer = input("Введи целое число: ")
print(type(answer))
number = int(answer)
print(type(number))
print(answer * 3)
print(number * 3)
```

Сохрани и запусти `python3 types_lab.py` или знакомую `python types_lab.py`
на Windows. Если твой файл называется иначе, подставь его имя.
Ответ вводи в терминале, затем нажми Enter.

Сделай два запуска: введи `5`, затем `12`. Перед каждым запуском предскажи
две последние строки вывода. Объясни: где повторяется текст, а где
умножается число? `input` возвращает строку даже при вводе цифр;
`int(answer)` создаёт целое число, сам `answer` остаётся строкой.

В `runs.txt` запиши два наблюдения: «ввёл → тип до преобразования → тип после
преобразования → повтор текста → числовой результат». Добавь одну фразу:
зачем здесь нужен `int`?

## Если застрял

Сначала оставь только `input` и `print(answer)`, сохрани и запусти.
Потом добавь `type`, преобразование и умножение по одному шагу.
