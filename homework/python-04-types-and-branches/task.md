## Твой маршрут

1. В `route.py` оставь вопрос через `input`, сравнение через `==` и две ветки `if/else`.
2. Измени вопрос и ответы под свой сюжет. В `else` нужен ответ для любого другого ввода.
3. Добавь общий `print` без отступа после веток.
4. Запусти с точным ответом, другим ответом и тем же словом с другой заглавной буквой.
   Перед каждым запуском предскажи ветку. Общий финал должен появляться каждый раз.

## Опыт с типами

В `types_lab.py` придумай свою пару цифр и выполни сложение сначала строк,
потом целых чисел. Образец для другой пары:

```python
print("5" + "2")
print(5 + 2)
print(type("5"))
print(type(5))
print(type(2.5))
print(type(5 == 2))
```

В `runs.txt` запиши три пары «ввёл → увидел» для маршрута и объясни одной фразой,
почему сложение строк отличается от сложения чисел. Подпиши типы:
`str` — строка (string), `int` — целое число (integer),
`float` — число с плавающей точкой (floating-point number),
`bool` — логическое значение (boolean): `True` или `False`.
В дробном числе Python использует точку: `2.5`.

## Если застрял

Сначала запусти только `input` и вывод ответа. Затем добавь ветки:
двоеточия после `if` и `else`, по четыре пробела перед командами внутри веток.
`=` присваивает значение, `==` сравнивает. Сравнение строк различает регистр.

[Шпаргалка по ветвлению](../../tracks/python/m-03-branching/student/cheatsheet.html).

## Если числовой ввод уже получился на уроке

Необязательно: в конце `types_lab.py` спроси целое число через `input`,
отдельной строкой преобразуй его через `int`, выведи число на единицу больше.
Запусти с `5` и `12`: должны получиться `6` и `13`.
`input` возвращает строку даже при вводе цифр. Для этого опыта вводи целое число:
слово и `2.5` не подходят для `int` и вызовут `ValueError`.
Если эту часть не успели вместе — оставь её до следующего занятия.
