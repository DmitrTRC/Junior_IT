# Счётчик: где заканчивается while

После занятия **4 ноября**. 10–15 минут, к встрече **8 ноября, 20:00 МСК**. Задание уточнено по фактическому занятию: продолжаем `while`. Если ты уже сделал прежний вариант с `for`, сохрани его и покажи преподавателю — переделывать не нужно.

1. Продолжи свой `counter.py`: начальное значение 1, условие `counter < 6`, внутри — печать числа и `counter = counter + 1`.
2. После цикла без отступа оставь `print("Готово")`. Сохрани и запусти: ожидаются 1, 2, 3, 4, 5 и общий финал.
3. Попробуй заменить условие на `< 3`. Сначала предскажи вывод, потом запусти: ожидаются 1, 2 и финал. Если непонятно, запиши вопрос — этот опыт разберём вместе 8 ноября.
4. В `runs.txt` запиши «начало и условие → ожидал → увидел». Объясни, какая строка изменяет счётчик.

Ноль повторений (начало 3 при `< 3`) — дополнительный опыт вместе на следующем занятии. `break`, `continue` и `for` самостоятельно изучать не требуется.

Запуск: `python3 counter.py` или знакомый `python counter.py`. При бесконечном повторении нажми `Ctrl+C` в терминале.
