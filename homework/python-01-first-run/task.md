# Домашка: первая программа и первая починка

К модулю «Первый запуск Python» (python-01).

## Что делать

### 1. `hello.py` — три строки о себе

В папке `~/code/junior_it/hw/01/` создай файл `hello.py` — папку и файл
собери сама командами `mkdir -p` и `nano`, теми же, что были на занятии.
Программа должна печатать ровно три строки, командой `print` каждая:

- как тебя зовут;
- твоё любимое занятие;
- что хочешь уметь через год.

Запусти `python3 hello.py` — все три строки должны появиться в терминале
без единой ошибки.

### 2. `broken.py` — почини чужую программу

Файл `broken.py` придёт отдельным сообщением в MAX сразу после занятия —
сохрани его туда же, в `~/code/junior_it/hw/01/broken.py` (репозитория и
`git` у тебя пока нет, поэтому не через них). Внутри — программа с тремя
ошибками. Запусти её первый раз как есть, чтобы увидеть первую.

Чини по одной, запуская `python3 broken.py` заново после каждого
исправления, — программа сама покажет, где смотреть дальше. Финальный
запуск должен пройти без единой красной строки.

Подсказка, если совсем запуталась: читай ошибку снизу вверх, как на
занятии — сначала что случилось (последняя строка), потом где (строка
выше).

## Сдача

Сделай два скриншота — вывод `python3 hello.py` и вывод `python3
broken.py` — и пришли в MAX **до среды 16.09**.
