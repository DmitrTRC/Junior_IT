# Программа выбирает маршрут

После занятия 21.10. **10–15 минут**. Продолжай свой `route.py`:
заново переписывать работающую программу не нужно.

## Что сделать

1. Придумай свой выбор: место путешествия, жанр игры или занятие на выходной.
2. Спроси ответ через `input` и сохрани в переменной.
3. Сравни ответ с одной выбранной строкой через `==`. В ветке `if` выведи
   подходящее сообщение, в `else` — сообщение для **любого другого ответа**.
4. После обеих веток добавь общий `print` без отступа: он должен срабатывать
   при любом ответе. Внутри веток используй четыре пробела.
5. Сохрани файл и выполни три запуска: точное совпадение, другой ответ,
   тот же ответ с другой заглавной/строчной буквой. До запуска предскажи ветку.
6. В `runs.txt` запиши три пары «ввёл → увидел» и одной фразой объясни,
   чем `=` отличается от `==`. Если прогноз не совпал — укажи, что выяснил.

Например, для условия `place == "лес"`: `лес` включает первую ветку,
`море` и `Лес` — вторую. Точное сравнение различает регистр и пробелы.
Не пиши во второй ветке «Ты выбрал море»: человек мог ввести что угодно.

Запуск: `python3 route.py` или знакомая `python route.py` на Windows.
Для готовой программы с урока достаточно своего изменения и трёх запусков.

## Если застрял

Сначала оставь `input` и `print` с ответом и запусти. Потом верни ветвление
(branching). Посмотри двоеточия после `if` и `else`, одинаковые отступы
и прямые кавычки. `else` стоит на одном уровне с `if`.

[Шпаргалка по ветвлению](../../tracks/python/m-03-branching/student/cheatsheet.html).

## Сдача

До **воскресенья, 25.10.2026, 20:00 МСК** подготовь `route.py` и `runs.txt`
в своей знакомой папке `git-lab`. При рабочем Git сохрани версию после
запуска: из этой же папки выполни `git add route.py runs.txt`, затем
`git commit -m "Add route choice"`. Уже сохранённая версия не требует
лишнего коммита.

Если доступ к выделенному тебе **закрытому репозиторию преподавателя** готов,
передай оба файла через знакомый интерфейс сайта в `hw/python-03-branching/`.
После сохранения открой `route.py` заново и найди своё условие.
Локальный commit сам по себе не отправляет файл на GitHub.

Если доступа нет — оставь оба файла в `git-lab` к тому же сроку и сообщи
преподавателю. Путь `hw/python-03-branching/` понадобится при загрузке
на сайт; локальные файлы перемещать не нужно. Срок загрузки согласуем после подключения. Если Git не готов,
достаточно файлов; настройки наугад не меняй. Нужен код, скриншот его не заменяет.
