# Диалог с программой

К модулю «Ввод: программа разговаривает (input)». **10–15 минут**.

## Что сделать

Создай `dialogue.py` в знакомом редакторе. Программа должна:

1. Спросить ник с помощью `input` и сохранить ответ в переменной.
2. Спросить любимый жанр игры, книги или фильма ещё одним `input`.
3. Вывести приветствие с введённым ником через `print`.
4. Вывести сообщение с выбранным жанром ещё одним `print`.

Тексты вопросов и ответов придумай сам. Все данные сегодня — текст;
числовое преобразование не требуется. Пользуйся вымышленным ником.

Сохрани файл и запусти `python3 dialogue.py` — или `python dialogue.py`,
если это твоя рабочая команда на Windows. После каждого ответа нажимай Enter.

Запусти **дважды с разными ником и жанром**, не меняя программу между
запусками. В выводе должны появляться именно ответы этого запуска.

## Если застрял

- Программа ждёт: введи ответ в консоли и нажми Enter.
- Показывает старый текст: сохрани файл и запусти его снова.
- Python ругается: посмотри последнюю строку ошибки, проверь парные
  прямые кавычки и скобки в указанной строке.

Подсказки: [шпаргалка по вводу](../../tracks/python/m-02-variables/student/cheatsheet.html).
