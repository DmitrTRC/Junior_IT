# Знак числа и общий финал

После занятия **1 ноября**. **10–15 минут**, до **среды, 4 ноября, 20:00 МСК**.
Продолжай свою работающую версию `sign.py`. Двух веток достаточно.

## Что сделать

1. Получи целое число: `answer = input(...)`, затем `number = int(answer)`.
2. При `number < 0` выведи «Отрицательное число», иначе — «Неотрицательное число».
3. После веток оставь общий `print("Готово")` без отступа.
4. Сохрани и запусти с `-3`, `0`, `5`. Перед каждым запуском предскажи весь вывод.
5. В `runs.txt` запиши три строки «ввёл → ожидал → увидел». Отметь общий финал
   и ответь: почему в версии с двумя ветками ноль попадает в `else`?

Ноль ни положительный, ни отрицательный. «Неотрицательный» означает ноль или
положительное число. Если на занятии уже выделил ноль через `elif number == 0`,
сохрани свою версию с тремя ветками; в последнем `else` будет «Положительное число».
Добавлять `elif` самостоятельно не требуется.

## Если застрял

Сохрани файл перед запуском. Посмотри двоеточия и четыре пробела внутри веток.
Общий финал стоит без отступа. Запуск: `python3 sign.py` или знакомый `python sign.py`.
Для `int` вводи целые числа, без десятичной точки; после ошибки ввода запусти снова.

Если на занятии обе ветки не заработали, оставь работающие `input`, `int` и
`print(number)`, запусти с `12` и запиши вопрос преподавателю. Новую конструкцию
без совместного разбора достраивать не нужно.
