# Провижининг учебной машины

Скрипты для подготовки Mac ученику: тулчейн C/C++/Python/JS/TS, приложения,
настройки macOS. Идемпотентно — гонять можно сколько угодно раз.

```
setup-mac.sh          ставит всё
check-mac.sh          отчёт: что стоит, что настроено, что реально работает
vscode-stage.sh       расширения VS Code по этапам курса
vscode-settings.json  дефолтные настройки редактора
jsonc.py              разбор JSONC (settings.json с комментариями)
merge-json.py         мерж настроек без затирания чужих
test-jsonc.py         тесты парсера
```

---

## Порядок передачи машины

Порядок важен: стирание убивает всё, что настроено до него.

### 1. Стереть (на своей стороне)

> Настройки → Основные → Перенос или сброс → **Стереть контент и настройки**

Erase Assistant разлогинит Apple Account, снимет Find My и Activation Lock.
Пароль от Apple ID он спросит — ввести обязательно, иначе замок останется.

Проверить: [appleid.apple.com](https://appleid.apple.com) → Устройства → машины нет в списке.

### 2. Первое включение — делаешь ты, не родитель

Причина: настройку надо прогнать, пока машина в твоей сети.

- Регион Россия, Wi-Fi.
- Учётная запись **на имя ученика**, администратор, временный пароль.
- **Apple ID на этом шаге НЕ вводить.** Иначе Activation Lock вернётся на тебя.
  Apple ID заводит родитель уже дома.

### 3. Прогнать провижининг

```bash
git clone https://github.com/DmitrTRC/Junior_IT.git ~/Junior_IT
cd ~/Junior_IT

DRY_RUN=1 bash provisioning/setup-mac.sh   # посмотреть, что будет сделано
bash provisioning/setup-mac.sh             # сделать
bash provisioning/check-mac.sh             # проверить
```

Первый запуск попросит Xcode Command Line Tools и выйдет — дождаться установки
и запустить снова. Homebrew попросит пароль администратора.

`check-mac.sh` не просто перечисляет пакеты: он реально компилирует C и C++,
запускает Python и Node, гоняет `tsc`. Если отчёт зелёный — языки работают.

### 4. Удалённый доступ (Tailscale + SSH)

Ставится скриптом, но включается руками — программе аккаунт не отдать.

1. Открыть Tailscale, войти **своим** аккаунтом, назвать устройство понятно
   (например `student-imac`).
2. Включить SSH: Настройки → Основные → Общий доступ → **Удалённый вход**,
   разрешить только учётке ученика.
3. Со своего Mac закинуть ключ:
   ```bash
   ssh-copy-id student-imac
   ssh student-imac 'sw_vers -productVersion'   # проверка
   ```
4. Дальше донастройка на расстоянии:
   ```bash
   rsync -a ~/Projects/Junior_IT/provisioning/ student-imac:~/provisioning/
   ssh student-imac 'bash ~/provisioning/check-mac.sh'
   ```

Скрипты гоняются через `~/provisioning/` целиком, а не через `ssh bash -s` —
им нужны соседние файлы (`jsonc.py`, `vscode-settings.json`).

### 5. Разрешения, которые кликаются только руками

macOS не даёт выдать их скриптом — это TCC, обходится только через MDM.
Прокликать до передачи, иначе всплывёт посреди занятия:

- **Zoom** → запустить, войти, разрешить **Камеру**, **Микрофон**,
  **Запись экрана** (последнее — самое частое, без него не работает
  демонстрация).
- **Терминал** → Полный доступ к диску, если планируется работа с системными
  папками. Для курса не нужен.

### 6. Отдать

Родителю остаётся два действия: сменить пароль учётки и завести детский
Apple ID в своей семейной группе. Памятка — `TO_PARENTS/mac-setup.md`.

## Расширения VS Code — по этапам, не сразу

По методике курса (см. `lessons/lesson-02g-vscode`) редактор на старте —
«умный блокнот»: ноль расширений, ни терминала, ни git. Системный тулчейн этому
не мешает — он в редакторе не виден. А расширения видны сразу, поэтому открываем
слоями:

| Этап | Что | Когда |
|---|---|---|
| — | ничего | уроки 1 … 2g |
| 1 | Code Runner, Error Lens | когда программы начинают запускаться из редактора |
| 2 | Live Server, Prettier | веб-разработка |
| 3 | Python, Pylance, C++, ESLint | когда проекты подрастут |

```bash
bash provisioning/vscode-stage.sh 1
bash provisioning/vscode-stage.sh list
```

Code Runner на этапе 1 — осознанный выбор: одна кнопка запускает и `.c`, и
`.py`, и `.js`. Для ребёнка, который прыгает между языками, это снимает
необходимость помнить три разные команды в терминале.

## Что ставится

**Тулчейн:** Xcode CLT (clang, clang++, lldb, make), Homebrew, python@3.13, uv,
node + npm, typescript + tsx, cmake, ninja, git.

**Приложения:** VS Code, Google Chrome, Zoom, Tailscale.

**Настройки macOS:**

| Настройка | Зачем |
|---|---|
| смарт-кавычки и тире выкл | macOS меняет `"` на «ёлочки» — код ломается, ошибка выглядит необъяснимо |
| автозаглавные и автозамена выкл | правит имена переменных |
| расширения файлов видны | без них разваливается урок про `.js` |
| путь в Finder | ребёнок должен видеть, где находится |
| удержание клавиши = повтор | вместо меню с ударениями |
| быстрый автоповтор | навигация стрелками по коду |

**Настройки VS Code:** шрифт 17, табы 2, автосохранение **выключено** (`⌘S`
учится осознанно), миникарта выключена, телеметрия выключена.

## Заметки

- **Не** ставится полный Xcode: 12+ ГБ, для курса не нужен. Компиляторы даёт
  Command Line Tools, это отдельная вещь и ~2 ГБ.
- `merge-json.py` при битом `settings.json` **ничего не пишет** и выходит с
  ошибкой — молча затирать чужие настройки нельзя даже с бэкапом.
- Приложения, поставленные мимо brew, распознаются по наличию `.app`
  и не переустанавливаются.
- Проверено на macOS 26.6.2, Apple Silicon.
