# Как запустить установщик на Mac

Пошагово, для Нелли. Делай по одному шагу и смотри, что отвечает компьютер.
Если ответ не похож на описанный — дальше не иди, напиши мне.

Понадобится: интернет и пароль от твоей учётной записи на Mac.
По времени — 15–30 минут, большая часть уходит на ожидание загрузки.

## 1. Открой Терминал

Нажми `⌘ + пробел`, набери `Терминал`, нажми `Enter`.

Откроется окно, в котором написано что-то вроде:

```
nelli@iMac ~ %
```

Знак `%` — приглашение: после него ты пишешь команду и нажимаешь `Enter`.
Пока команда работает, нового `%` нет. Появился — компьютер ждёт следующую.

(Терминал можно найти и через Finder: Программы → Утилиты → Терминал.)

## 2. Убедись, что ты «дома»

```
cd ~
pwd
```

`~` — твоя домашняя папка. `pwd` печатает, где ты сейчас. Должно быть:

```
/Users/nelli
```

(вместо `nelli` — имя твоей учётной записи, оно же в приглашении перед `@`).

## 3. Посмотри, что лежит дома

```
ls
```

Увидишь список папок: `Desktop`, `Documents`, `Downloads` и другие.
Если среди них уже есть `Junior_IT` — шаг 4 пропусти, иди сразу на шаг 5.

## 4. Скачай папку курса

```
git clone https://github.com/DmitrTRC/Junior_IT.git
```

Побегут строки `Cloning into 'Junior_IT'...`, в конце `Receiving objects: 100%`.
Проверь:

```
ls
```

Теперь `Junior_IT` в списке есть.

> Если вместо этого выскочило окно про «инструменты командной строки
> разработчика» — нажми «Установить», дождись, пока окно установки исчезнет
> (10–15 минут), и повтори `git clone`.

## 5. Зайди в папку курса

```
cd Junior_IT
ls
```

Ты внутри `Junior_IT`. Среди прочего в списке есть папка `provisioning`.

Если папка `Junior_IT` была у тебя раньше — обнови её до свежей версии:

```
git pull
```

## 6. Зайди в папку с установщиком

```
cd provisioning
ls
```

В списке есть `setup-mac.sh` — это и есть установщик. Проверь, где ты:

```
pwd
```

```
/Users/nelli/Junior_IT/provisioning
```

(Быстро, одной командой из любого места: `cd ~/Junior_IT/provisioning`.
А имя папки можно не дописывать: набери `cd Jun` и нажми `Tab` — терминал
допишет сам.)

## 7. Запусти установщик

```
bash setup-mac.sh
```

Скрипт проходит 8 шагов и по каждому пишет, что делает. Что он спросит:

- **`Продолжить? [y/N]`** — набери `y`, нажми `Enter`.
- **`Password:`** — пароль от твоей учётной записи Mac. Пока набираешь, на экране
  ничего не появляется, ни точек, ни звёздочек — так задумано. Набери и нажми
  `Enter`. Если пароль не принимает — не гадай, напиши мне.
- **Окно про «инструменты командной строки»** на шаге `[2/8]` — нажми
  «Установить». Скрипт при этом сам закончит работу. Дождись, пока окно
  установки исчезнет, и запусти `bash setup-mac.sh` ещё раз — он продолжит
  с того места, где остановился.

Слово `sudo` перед командой писать не надо: скрипт сам спросит пароль там,
где нужно.

Окно Терминала не закрывай, пока не появится строка **`Готово.`**
Сколько ждать — зависит от интернета, обычно 10–20 минут.

Запускать скрипт можно сколько угодно раз: что уже сделано, он пропускает
(строки с точкой `·` — «уже стоит»).

(Если интересно заранее посмотреть, что скрипт собирается делать, ничего
не меняя: `DRY_RUN=1 bash setup-mac.sh`.)

## 8. Проверь

```
bash check-mac.sh
```

Это отчёт: зелёные `✓` — работает, красные `✗` — нет. Если есть красные —
сфотографируй экран и пришли мне.

(Скрипт в конце подсказывает `bash provisioning/check-mac.sh` — это путь
из папки `Junior_IT`. Ты уже внутри `provisioning`, поэтому короче.)

## 9. Закрой Терминал и открой заново

Новые программы Терминал видит только в новом окне. Закрой его (`⌘ + Q`),
открой снова и проверь:

```
python3 --version
```

Появилась версия, например `Python 3.13.7` — всё на месте.

## Что скрипт не умеет — сделай руками

Открой **Zoom**, войди и разреши ему **камеру**, **микрофон** и **запись
экрана** — macOS спросит сама при первом запуске. Без записи экрана не
работает демонстрация экрана на занятии.
