20:18–20:30 · ПЕРВЫЕ ВЕТКИ

Ветвление (branching): два пути

Создай отдельный route.py. Начни с вопроса и сравнения (comparison):

place = input("Куда идём: лес или море? ")
print(place == "лес")

Запусти python3 route.py или python route.py. Предскажи результат для лес, затем для море. Один знак = присваивает значение; два знака == сравнивают. Результат сравнения — True или False, логическое значение (boolean).

Теперь вместо временного print(place == "лес") набери:

if place == "лес":
    print("Берём карту")
else:
    print("Берём воду")

Условие (condition) стоит после if. После if и else — двоеточие. У команд внутри веток отступ (indentation) — четыре пробела; сами if и else на одном уровне.

Три запуска: лес → море → Лес. Перед каждым назови выбранную ветку, затем сравни с выводом.

Почему «Лес» попал в else?

Сравнение строк точное: "Лес" и "лес" различаются. else выполняется при любом несовпадении с "лес": это не отдельное условие «ответ равен море».
