Ветвление (branching): два пути

Создай новый sign.py. Если такой файл уже есть, сохрани прежнюю версию. Набери ввод и преобразование:

answer = input("Введи целое число: ")
number = int(answer)

Добавь print(number < 0). Предскажи и посмотри результат для -3 и 5: это логические значения (boolean) True и False.

Вместо временного print(number < 0) набери условие (condition):

if number < 0:
    print("Отрицательное число")
else:
    print("Неотрицательное число")

После if и else — двоеточие. Внутри веток отступ (indentation) — четыре пробела. if и else стоят на одном уровне. Каждый сохраняет и запускает -3 и 5.

Ноль — куда?

Ноль не положительный и не отрицательный. Для условия number < 0 ветка else включает и ноль, и положительные числа: это неотрицательные числа.

После обеих веток, без отступа, добавь:

print("Готово")

Перед каждым запуском предскажи весь вывод. Запусти с -3, 0, 5. Общий финал должен появиться каждый раз.

Сдвинь общий print внутрь else. Предскажи, при каком вводе «Готово» исчезнет, проверь на -3. Верни строку без отступа и снова запусти. Смена экрана каждые 3–5 минут.

Твоя программа, твой запуск

Покажи код и оба исхода. Другой участник сначала предсказывает вывод. Объясни: почему ноль попал в else и почему финал общий?

Сверить две ветки после своих попыток
answer = input("Введи целое число: ")
number = int(answer)
if number < 0:
    print("Отрицательное число")
else:
    print("Неотрицательное число")
print("Готово")
У всех работают две ветки? Выдели ноль отдельно

В той же программе между if и else добавь elif number == 0: с выводом «Ноль». В последнем else теперь можно написать «Положительное число».

if number < 0:
    print("Отрицательное число")
elif number == 0:
    print("Ноль")
else:
    print("Положительное число")
print("Готово")

= присваивает, == сравнивает. Python выбирает первую подходящую ветку. Повтори −3 / 0 / 5. Этот шаг необязательный; если времени мало, сохрани две работающие ветки.
