Справочный материал к плану 4 ноября. На встрече успели разобрать while-счётчик; следующие упражнения выполняем вместе на последующих занятиях.

1. while: пока условие истинно

Создай counter.py. Выведи 0, 1, 2 через while. Перед запуском предскажи вывод. Что произойдёт, если начальное значение сразу 3?

Подсказка после своей попытки
counter = 0
while counter < 3:
    print(counter)
    counter += 1
print("Готово")

Условие проверяется до тела: при counter = 3 останется только «Готово». При зависании — Ctrl+C.

2. Сначала спросить, потом решить

В Python нет do…while. В commands.py сначала получаем команду, затем выходим по exit. Попробуй exit сразу, затем отдельным запуском read → exit. Сколько раз выполнится input?

Рабочий Python
while True:
    command = input("Команда (exit — выход): ")
    if command == "exit":
        break
    print("Получено:", command)
print("Готово")

while True здесь уместен: у программы есть понятное условие выхода. «Готово» без отступа выполняется после цикла.

3. for: по одному символу

В letters.py запроси слово и выведи каждый символ на своей строке. Попробуй «кот», «Я», пустой ввод (сразу Enter). Сначала назови количество строк от цикла.

Подсказка
word = input("Слово: ")
for letter in word:
    print(letter)
print("Готово")

Получится 3, 1 и 0 строк от тела цикла. Финальное «Готово» появится во всех трёх случаях. letter получает очередной символ автоматически.

Если основное готово у всех

Посчитай символы переменной count. Для пустой строки должно быть 0. Пробел тоже символ.

Свериться после запуска
word = input("Слово: ")
count = 0
for letter in word:
    print(letter)
    count += 1
print("Символов:", count)
