while: границы и выход через break

КурсДомашка

Перед стартом

Открой свою папку в VS Code. Сохрани файл и запусти python3 counter.py или знакомой командой python counter.py на Windows. Вводи ответы в терминале; панель Output для input() не подходит. Если программа повторяется бесконечно — Ctrl+C в терминале.

1. Пять чисел — своими руками

В counter.py начни с 1, повторяй, пока число меньше 6. Напечатай число и увеличь его на 1. Общий финал «Готово» — после цикла без отступа. Сначала назови ожидаемый вывод, затем набери и запусти.

Подсказка после своей попытки
counter = 1
while counter < 6:
    print(counter)
    counter = counter + 1
print("Готово")

Покажи экран: 1, 2, 3, 4, 5 и один общий финал. Объясни, какая строка меняет счётчик.

2. Где заканчивается повторение?

Замени только условие на counter < 3. Затем отдельным опытом поставь начальное значение 3. Перед каждым запуском сохрани файл и предскажи результат.

Начало / условиеЧисла от тела циклаОбщий финал
1 / < 61, 2, 3, 4, 5Готово
1 / < 31, 2Готово
3 / < 3Ни одногоГотово

Условие проверяется до тела. Запиши в runs.txt: «начало и условие → ожидал → увидел». Затем верни рабочую версию 1–5.

3. Команда для выхода

Создай commands.py. Программа повторяет вопрос. Если введено точно exit, break завершает цикл (loop). Любую другую команду программа печатает и спрашивает снова.

Подсказка после своей попытки
while True:
    command = input("Команда (exit — выход): ")
    if command == "exit":
        break
    print("Получено:", command)
print("Готово")
  1. Первый запуск: сразу введи exit. Ожидается один вопрос и «Готово»; строки «Получено: exit» нет.
  2. Второй запуск: read, затем exit. Ожидаются два вопроса, «Получено: read» и один финал.
  3. Покажи оба опыта. Объясни, почему input находится внутри цикла и зачем print("Готово") вынесен за него.

while True уместен, когда предусмотрен понятный выход. Сравнение учитывает регистр: Exit не равно exit.

Дополнительно вместе: пропустить команду

Только когда основное заработало у всех. Перед строкой «Получено» добавь:

Подсказка после своей попытки
    if command == "skip":
        continue

continue начинает следующую итерацию (iteration), а break выходит из цикла. Попробуй skip → read → exit: три вопроса, только «Получено: read» и финал. В домашке этот шаг не обязателен.
