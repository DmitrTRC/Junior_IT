# Блок «Компьютер изнутри»: уроки cs-01 и cs-02 — дизайн

Дата: 2026-08-18. Статус: утверждён по секциям, ждёт финального ревью.

## Контекст и задача

12.08 и 16.08 проведены два спонтанных занятия вне плана курса (один на один,
Zoom, рисование на whiteboard): устройство компьютера и слои «железо → ОС →
приложение» с системами счисления. Записи расшифрованы локально
(`recordings/transcripts/`, вне гита — голоса и имена детей).

Задача: оформить оба занятия как полноценные уроки курса со всеми атрибутами
анатомии урока. Главный артефакт — слайды: ученице обещаны «наглядные слайды
по шагам», а Zoom-доска в записях заметно тормозила занятие.

## Принятые решения

1. **Отдельный блок «Компьютер изнутри»** со своей нумерацией:
   `lessons/lesson-cs-01-computer/`, `lessons/lesson-cs-02-layers/`.
   Анонсированный третий урок про языки программирования станет `cs-03`
   (вне скоупа этой задачи). Буквенная линейка 02e–02g не трогается.
2. **Формат — полноценные публичные уроки курса**: обезличенные, под
   вебинар (60 мин, потолок 75, пинги в чат каждые 3–5 минут, теория
   кусками не дольше 2 минут). Записи — сырьё, не эталон: структуру улучшаем.
3. **Границы перекроены**: cs-01 = железо + загрузка + история ОС;
   cs-02 = пирамида слоёв + системы счисления, доведённые до практики +
   мост к языкам. Оба урока добиты до полных 60 минут.

## Анатомия cs-урока (отступления от эталона lesson-01)

Набор файлов стандартный: `README.md`, `scenario.md`, `live-code.md`,
`glossary.md`, `cheatsheet.html`, `homework.html`, `slides.html`,
`index-final.html`, `demos/`. Два осознанных отступления:

1. **`live-code.md` — «живая схема», не живой кодинг**: пошаговая режиссура
   сборки картинки на слайдах. Каждый шаг = слайд + что сказать + пинг детям.
   Имя файла сохранено ради единообразия анатомии и команд.
2. **Одна интерактивная демка на урок вместо трёх эстетик**
   (геймер/спорт/арт работают для «сделай свой сайт», для теории про железо
   сильнее интерактив):
   - cs-01: `demos/boot.html` — симулятор включения компьютера:
     Power → POST → BIOS/UEFI → загрузчик → ОС, с подписями шагов;
     бонус «вытащи планку RAM» — POST ругается.
   - cs-02: `demos/bits.html` — 8 переключателей-битов, живое десятичное и
     16-ричное значение; вкладка «собери цвет» раскладывает hex-цвет вида
     `#ffd60a` на три числа.

`index-final.html` — резервный конспект ведущего (по образцу 02f/02g).
Слайды — формат `lesson-01/slides.html` (листание ← / →), но ~12–14 слайдов:
одна схема собирается послойно. Вся графика — SVG в бренд-палитре, без
стоковых картинок. Оба отступления фиксируются в CLAUDE.md как норма
cs-блока, чтобы brand-guardian не считал их нарушением.

## cs-01 «Компьютер изнутри» (`lesson-cs-01-computer/`)

Источник — запись 12.08 (57 мин). Авторские метафоры сохраняются дословно:
такты-«часики» = частота, адреса «как дома на улице, только с нуля»,
«0/1 = есть напряжение / нет напряжения».

Тайминг:

| Мин | Блок |
|---|---|
| 0–5 | Зачем заглядывать внутрь: без понимания «что под капотом» программист остаётся слабым |
| 5–15 | Материнка → CPU: команда за командой, «часики» = ГГц, регистры |
| 15–22 | Память: RAM vs SSD/HDD (быстрая-дорогая vs медленная-дешёвая), VRAM + байка про майнинг |
| 22–30 | Как CPU берёт команды: адреса, Instruction Pointer, шина данных, разрядность — 64 «проводочка» |
| 30–35 | Ввод-вывод: USB, клавиатура, монитор — на схеме появляется пользователь |
| 35–47 | Включаем: POST → BIOS/UEFI → загрузочная запись → загрузчик → ОС; демка-симулятор |
| 47–56 | Карта ОС: MS-DOS → Windows; Unix → Linux, macOS, Android; «85% устройств мира»; слайд «даже Windows встроил себе Linux» |
| 56–60 | Итог по полной схеме, шпаргалка и домашка в чат |

Пинги: «сколько ГГц у твоего компьютера?», «у кого сколько RAM?», «кто видел
чёрный экран BIOS?», «какая ОС на твоём телефоне?»

Слайды (~14): титул → зачем → материнка (пустая схема-основа) → CPU и часики
→ 0/1-напряжение → RAM-полка с адресами → SSD vs RAM → шина и 64 бита →
полная схема с вводом-выводом → POST → эстафета BIOS → загрузчик → ОС →
семейное дерево ОС → пирог «85% мира» → итог + анонс cs-02.

Домашка — «паспорт моего компьютера»: найти в настройках (инструкции для
Windows и Mac) процессор с частотой, объём RAM и диска, ОС телефона; вписать
в мини-анкету. Кода нет — осознанно. Шпаргалка — «карта компьютера»: схема +
путь загрузки + мини-словарик.

Глоссарий: процессор/CPU, частота, регистр, RAM/ОЗУ, ROM/ПЗУ, SSD/HDD, VRAM,
шина, разрядность, бит, ввод-вывод, POST, BIOS, UEFI, загрузчик, ОС, WSL.

Убрано из записи: хвост про хард/софт-скиллы (в README и сценарии — ссылка
на `docs/soft-vs-hard-skills.html`); IBM PC XT 16/8 — одной строкой в
сценарии как байка для ведущего.

## cs-02 «Слои: от железа до твоей программы» (`lesson-cs-02-layers/`)

Источник — запись 16.08 (36 мин), добитая до полного урока: системы
счисления доведены до практики, которую запись оборвала.

Тайминг:

| Мин | Блок |
|---|---|
| 0–5 | Повтор cs-01: эстафета включения, опрос по чату |
| 5–15 | Пирамида слоёв: железо → BIOS/UEFI → ОС → приложение; ОС «берёт нули-единицы на себя»; почему ОС не встанет на любое железо; программа vs приложение |
| 15–20 | Как говорит машина: только 0/1; перфокарты — «есть дырочка / нет дырочки» |
| 20–32 | Двоичная система на демке-лампочках: 8 бит = байт, счёт до 255, перенос разряда «точно как в десятичной» |
| 32–42 | Шестнадцатеричная: зачем (нули-единицы «расплываются» в голове), цифры A–F, 16₁₀ = 10₁₆; практика: `#ffd60a` из их собственного CSS — это три числа |
| 42–52 | Лестница языков: машинный код → ассемблер → C → выше; слайд-шок Hello World на ассемблере vs одна строка JS; драйверы — «программки-переводчики» между ОС и устройством |
| 52–58 | Мост к cs-03: «языков больше двухсот — в следующий раз возьмём 5–7 главных» |
| 58–60 | Шпаргалка + домашка в чат |

Пинги: «что на дне пирамиды?», «сколько влезет в 8 лампочек?», «что больше —
FF или 100?», «какого цвета `#ff0000`?»

Слайды (~13): титул → эстафета-повтор → пирамида (собирается снизу вверх) →
программа vs приложение → перфокарта → лампочки-биты → счёт в двоичной →
A–F и перенос → hex-цвета из CSS → лестница языков → Hello World: ассемблер
vs JS → драйвер-переводчик → итог + анонс cs-03.

Домашка — без компьютера, на листочке: перевести три маленьких числа по
лампочкам, угадать оттенки трёх hex-цветов, записать свой возраст в двоичной;
проверка — в демке. Шпаргалка — пирамида слоёв + таблица 0–15 в трёх
системах + разбор одного hex-цвета.

Глоссарий: слой/уровень, приложение vs программа, бит, байт, двоичная /
десятичная / шестнадцатеричная системы, перфокарта, машинный код, ассемблер,
драйвер.

Примечания:
- Байка про троичный компьютер «Сетунь» — только в сценарии для ведущего,
  нейтральная формулировка «в 1950-е в московском университете построили…»,
  без советской атрибутики на детских слайдах (жёсткие запреты проекта).
- Байт добавлен сверх записи (в записи только биты): ложится на 8 лампочек
  и нужен для hex-цветов.
- Hello World на ассемблере в cs-02 — один слайд-затравка; полный парад
  языков — в будущем cs-03.

## Обвязка

1. `index.html`: новый раздел «Компьютер изнутри» с карточками cs-01 и cs-02
   и заглушкой «cs-03 скоро». Встраивается поверх текущих незакоммиченных
   правок, ничего вокруг не переписывая.
2. `CLAUDE.md`: короткая запись про блок cs — своя нумерация, «живая схема»
   вместо живого кодинга, одна интерактивная демка вместо трёх эстетик.
3. Черновики 02e–02g не трогаются.
4. `recordings/` остаётся вне гита (уже в `.gitignore`).
5. `meta/lesson-cs-postmortem.md`: Zoom-доска тормозила занятие (слайды
   решают), 36 минут — реальный потолок теории один на один, ученице обещаны
   слайды. База для разговора о следующем уроке и курсе в целом.

## Проверки и критерий готовности

- brand-guardian по всем новым материалам до коммита.
- Локальный предпросмотр (`python3 -m http.server 8000`): слайды листаются,
  обе демки работают, шпаргалки и домашки открываются.
- Тексты: русский, на «ты», без запрещённой лексики; термины из первых
  уроков не всплывают раньше времени (в cs-блоке нет DOM, «семантики» и пр.).
- Коммит без пуша; деплой позже через `/deploy` по явной команде.
