# Урок cs-03 «Языки программирования: кто переводит твой код» — дизайн

Дата: 2026-08-19. Статус: утверждён в чате по секциям, ждёт ревью спеки.

## Контекст и задача

cs-02 закончился лестницей языков, слайдом-контрастом «NASM x86-64 vs
`console.log`» и обещанием: «языков больше двухсот — в следующий раз возьмём
главные». Обещание закрывает cs-03.

Тема, как её сформулировал Димас: **среда исполнения** и виды языков —
интерпретаторы, компиляторы, JIT. Сравнение идёт всегда на одной связке
языков: **asm (x86-64), C, C++, Python, JS**. Отдельный блок — разница между
JS в консоли и JS в браузере.

Сквозной вопрос урока — не «какой язык лучше», а «что происходит между тем,
как ты нажал Enter, и тем, как что-то появилось на экране».

## Принятые решения

1. Папка `lessons/lesson-cs-03-languages/`, длительность 60 минут (потолок 75).
   Третий и последний урок cs-блока в этой итерации: после него курс
   возвращается в JS-линейку.
2. **Одна задача — пять языков**, а не разные задачи по языкам. Ребёнок должен
   видеть, что результат одинаковый, а цена разная.
3. **Связка ровно из пяти языков.** Java, Go, Rust, C# упоминаются одной
   строкой на слайде «языков больше двухсот» и в глоссарий не идут.
4. **Код в тренажёре не исполняется по-настоящему.** Вывод предзаписан и
   печатается по символам; имя и два числа ребёнок вводит сам, и они
   подставляются в вывод всех пяти языков одинаково. Причина: офлайн-надёжность
   на вебинаре и равноправие языков (иначе JS «живой», а остальные — картинки).
   Pyodide/wasm — вне скоупа.
5. **Ассемблер честный (NASM x86-64), но с обрезкой.** «Привет, мир» и «счёт
   до 5» — полный листинг, как на слайде cs-02. Задачи с вводом и арифметикой —
   первые ~15 строк плюс плашка «и ещё около 30 строк: число с клавиатуры
   приходит текстом, его надо вручную превратить в число». Посыл «вот почему
   придумали C» доходит, стены из 60 строк нет.
6. Анатомия — как у всего cs-блока: `live-code.md` — живая схема, не живой
   кодинг; одна интерактивная демка вместо трёх эстетик.

## Тренажёр `demos/languages.html`

Одна страница, три вкладки — в бренд-палитре, консольные блоки в Dracula,
как в `demos/bits.html`.

### Вкладка 1 «Одна задача — пять языков»

Слева список задач, сверху табы языков, в центре код, снизу вывод.

| Задача | Что показывает |
|---|---|
| Привет, мир! | голый вывод строки |
| Спроси имя и поздоровайся | переменная + ввод-вывод |
| Сложи два числа | арифметика, и почему на асме это больно |
| Посчитай до 5 | цикл |

Языки-табы: `asm` · `C` · `C++` · `Python` · `JS`.

Под кодом — строка-метрика, три поля:

```
строк: 12  ·  перевод: ассемблер + линкер  ·  чтобы запустить: nasm, ld, Linux x86-64
строк: 5   ·  перевод: компилятор          ·  чтобы запустить: gcc — один раз, дальше только файл
строк: 2   ·  перевод: интерпретатор       ·  чтобы запустить: установленный Python
строк: 2   ·  перевод: JIT                 ·  чтобы запустить: браузер или Node
```

Числа в примере выше иллюстративные: в демке счётчик строк считается по
реальному листингу каждой задачи.

Поля ввода «твоё имя» и два числа — общие для всех языков: меняешь имя, и
вывод меняется во всех пяти вкладках. Вывод печатается по символам, чтобы
читалось как работа программы.

### Вкладка 2 «Как это запускается»

Четыре дорожки, анимация проходит по выбранной:

```
asm     исходник → ассемблер → линкер → машинный код → CPU
C/C++   исходник → компилятор → линкер → машинный код → CPU     (один раз)
Python  исходник → интерпретатор, строка за строкой → CPU        (каждый запуск)
JS      исходник → движок: сначала интерпретирует, горячие куски компилирует → CPU
```

Ключевая подпись: у компилятора перевод происходит **до** запуска, у
интерпретатора — **во время**, у JIT — и так, и так.

### Вкладка 3 «JS: консоль vs браузер»

Два окна с одним и тем же кодом. Слева браузер, справа консоль (Node).
Кнопка «перенести код» показывает, что ломается:

| Работает в браузере | Работает в консоли | Работает везде |
|---|---|---|
| `alert`, `prompt` | чтение файлов, `readline` | переменные, циклы, функции |
| страница и её элементы | аргументы командной строки | `console.log`, числа, строки |

Вывод: язык один, движок один — разные «руки», которые ему выдала среда.
Слово «DOM» на страницу не выносится: говорим «дотягивается до страницы».

## Слайды (13, S1–S13)

титул → лестница из cs-02 (повтор) → код — просто текст → среда исполнения
(рецепт и повар) → три способа перевода, общая схема → компилятор →
ассемблер и линкер → интерпретатор → JIT → таблица пяти языков (кто переводит,
что нужно установить, что на нём пишут) → «Привет» впятером → JS: браузер vs
консоль → итог + анонс возврата в JS-линейку.

Вся графика — SVG в бренд-палитре. С S6 по S9 схема «исходник → перевод → CPU»
собирается послойно, как пирамида в cs-02.

## Домашка и шпаргалка

Домашка — без установки софта:

1. Бумажная часть: соотнести пять языков и три способа перевода; для каждого
   написать, что нужно, чтобы программа запустилась.
2. Практическая: открыть консоль браузера (F12), набрать три строки —
   переменная, сумма, `console.log` — и записать, что вывелось.
3. Бонус: пройти в тренажёре все четыре задачи на всех пяти языках и найти,
   где разница в количестве строк самая большая.

Шпаргалка — одна страница в печатной light-палитре: таблица пяти языков,
три схемы перевода, табличка «браузер vs консоль», мини-словарь.

## Проверки и критерий готовности

- brand-guardian по всем новым материалам до коммита.
- Локальный предпросмотр (`python3 -m http.server 8000`): слайды листаются
  стрелками, все три вкладки тренажёра работают, шпаргалка и домашка
  открываются, ничего не переносится и не уезжает по горизонтали.
- Тексты: русский, на «ты», без запрещённой лексики; «DOM», «семантика»,
  «парсинг» не всплывают.
- Код примеров проверен на смысл: NASM x86-64 собирается логически (syscall
  write/exit как в cs-02), C/C++ — компилируемый код, Python и JS — рабочий.

## Вне скоупа

- Настоящее исполнение кода в браузере (Pyodide, wasm, JS-eval).
- Java, Go, Rust, C# — только упоминание строкой.
- Развитие `demos/bits.html` в отдельный самостоятельный тренажёр: идея
  Димаса, отдельная задача после cs-03.
- Печатная книжка `print/` и черновики 02e–02g.
