# Коммуникации курса (comms) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Объявления и домашки уходят ученикам в Telegram одной кнопкой Димаса, сдачи приходят из GitHub в журнал с результатом тестов, домашки живут на сайте курса.

**Architecture:** «Почтальон и мозг»: `courier/` — отдельный пакет для HP (aiogram 3, long-polling через SOCKS5, файловые очереди `outbox/sending/sent/inbox/failed`, реестр `telegram_id ↔ comms_id`, сторожок). `tools/comms/` — brain на Mac: тик launchd раз в минуту забирает входящее по rsync/ssh, пишет в журнал (`journal.ops`), собирает черновики (`claude -p`), расписание и опрос GitHub, кладёт исходящее. Сайт получает генератор страниц домашек.

**Tech Stack:** Python 3.12; courier — aiogram 3.13+, aiohttp-socks, pytest-asyncio; brain — pyyaml, pytest, `gh`, `git`, `rsync`, `ssh`, `claude -p`; сайт — Python-Markdown; HP — Debian 12, systemd, shadowsocks-rust (`sslocal`).

**Spec:** `docs/superpowers/specs/2026-09-28-comms-design.md`

**Отклонение от буквы спеки (та же суть):** поля идентификации (`comms_id`, `telegram_id`, код регистрации, репо GitHub) живут не внутри `students/roster.yml` (PyYAML при перезаписи теряет комментарии, а ядро журнала отбрасывает незнакомые ключи), а в соседнем приватном `students/comms.yml`, которым владеет brain. Зона приватности та же — `students/` в `.gitignore`.

## Global Constraints

- Python 3.12 (`tools/.venv`, Python 3.12.7); courier — тоже 3.12 (Debian 12 даёт 3.11 — ставить через `uv python install 3.12` или deadsnakes; см. Task 8).
- Тесты Mac-части — `cd tools && .venv/bin/python -m pytest -q` (`pytest.ini`: `testpaths = tests`, `pythonpath = .`, `asyncio_mode = auto`); courier — `cd courier && .venv/bin/python -m pytest -q`.
- Ни имён детей, ни telegram_id, ни кодов в коде и тестах — только вымышленные (alice/bob/carol, как в `tools/tests/conftest.py`).
- Секреты — только в `~/.junior_it/*.env` (Mac) и `/srv/courier/courier.env` (HP), примеры с плейсхолдерами в `provisioning/`.
- Детям и в группу ничего не уходит без нажатия кнопки Димасом (callback `send:<id>`); исключение — служебные ответы бота «привязал», «получил, передал Димасу», «принято».
- Все `subprocess` — через `runner(cmd, *, timeout, stdin_text=None)`, как в `zoom_pipeline.phases.default_runner`; сетевые команды с таймаутом (rsync/ssh 120 с, gh 60 с, pytest 30 с, claude 900 с).
- Материалы — русский, идентификаторы — английские, без эмодзи в коде и коммитах; коммиты в стиле `feat(comms): …`, `feat(courier): …`, `feat(site): …`.
- Время — Europe/Moscow; `now` всегда передаётся аргументом (тестируемость), `date.today()` только в CLI-обёртках.
- Callback data ≤ 64 байт: `<действие>:<id>`; id элемента — `YYYYMMDDTHHMMSSffffff-xxxxxxxx` (30 символов), действия — `send discard accept rework claude remind`.
- Telegram-HTML: экранировать `& < >` во всём пользовательском тексте (`html.escape`), лимит сообщения 4096 → режем на 3500 и добавляем ссылку.
- Публичный сайт: `homework/<id>/tests/` и `task.md` не публикуются, страницы — через brand-check до коммита.

## Review Focus

1. Ребёнок шлёт боту голосовое, стикер или видео — courier должен положить элемент `kind: text` с пустым текстом и пометкой `unsupported: "voice"`, а brain переслать Димасу «прислал голосовое», не падать (Task 5, тест `test_unsupported_content_becomes_note`).
2. Два ученика сдали одну домашку одновременно, а Mac был в отключке час — brain обязан обработать оба элемента по порядку id и ни один не потерять при падении посередине (Task 17, тест `test_tick_survives_apply_error_and_keeps_item`).
3. Коммит ученика трогает две домашки сразу или файлы вне `hw/` — опрос должен создать две сдачи или ни одной, не смешивать (Task 14, тест `test_commit_touching_two_homeworks`).
4. `task.md` длиннее 3500 символов или с таблицей — Telegram-HTML не должен превысить лимит и не должен содержать незакрытых тегов (Task 12, тест `test_long_task_is_truncated_with_link`).
5. Димас нажал «принято» дважды или после «доработать» — второй callback отвечает «уже сделано», журнал не меняется, баллы не удваиваются (Task 16, тест `test_accept_twice_is_idempotent`).

```python
"""Страницы домашек для сайта: homework/<id>/task.md -> <out>/homework/<id>/index.html.

Публикуются страница и вложения (стартовые файлы); task.md и tests/ — нет.
Запуск: build_homework_pages.py <repo_root> <out_dir>

import html
import re

import sys

import markdown

SKIP_FILES = {"task.md", "index.html"}
SKIP_DIRS = {"tests"}

PAGE = """<!DOCTYPE html>

            padding: 8px 14px; border-radius: 10px; text-decoration: none; margin: 6px 8px 0 0; }}
  a.file:hover {{ background: #0f3460; }}
  footer {{ margin-top: 40px; font-size: 14px; color: #666; }}
  footer a {{ color: #2b4fa8; }}
</style>
</head>
<body>
<div class="container">
<header>
  <div class="kicker">ДОМАШКА · {hw_id}</div>
  <h1>{title}</h1>
</header>

{body}
</main>
{files}
<footer>Материалы курса — <a href="{site}">{site}</a></footer>
</div>
</body>

FILES = """<section class="files">
  <h2>Вложения</h2>
  {links}
</section>"""


def split_title(md_text: str) -> tuple[str, str]:
    """Первый заголовок первого уровня — в шапку; из тела он убирается."""
    match = re.search(r"^# (.+)$", md_text, flags=re.MULTILINE)
    if not match:
        return "Домашка", md_text
    body = md_text[:match.start()] + md_text[match.end():]
    return match.group(1).strip(), body.lstrip("\n")


def render_task(md_text: str, hw_id: str, attachments: list[str]) -> str:
    title, body_md = split_title(md_text)
    body = markdown.markdown(body_md, extensions=["fenced_code", "tables"])
    links = "\n  ".join(
        f'<a class="file" href="{html.escape(name, quote=True)}" download>{html.escape(name)}</a>'
        for name in attachments)
    files = FILES.format(links=links) if attachments else ""
    return PAGE.format(title=html.escape(title), hw_id=html.escape(hw_id), body=body, files=files, site=SITE_URL)


def attachments_for(hw_dir: Path) -> list[Path]:
    return sorted(p for p in hw_dir.iterdir()
                  if p.is_file() and p.name not in SKIP_FILES and not p.name.startswith("."))


def build(repo_root: Path, out_dir: Path) -> list[Path]:
    homework = Path(repo_root) / "homework"
    written: list[Path] = []
    if not homework.is_dir():
        return written
    for task in sorted(homework.glob("*/task.md")):
        hw_dir = task.parent
        target = Path(out_dir) / "homework" / hw_dir.name
        target.mkdir(parents=True, exist_ok=True)
        files = attachments_for(hw_dir)
        for src in files:
            shutil.copy2(src, target / src.name)
        page = target / "index.html"
        page.write_text(render_task(task.read_text(encoding="utf-8"), hw_dir.name, [p.name for p in files]),
                        encoding="utf-8")
        written.append(page)
    return written


def main(argv=None) -> int:
    args = argv if argv is not None else sys.argv[1:]
    if len(args) != 2:
        print("usage: build_homework_pages.py <repo_root> <out_dir>", file=sys.stderr)
        return 2
    pages = build(Path(args[0]), Path(args[1]))
    print(f"домашки: {len(pages)} страниц")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
# courier/courier/queue.py
"""Файловые очереди: элемент — <id>.json плюс каталог <id>/ с вложениями.

Порядок записи: сначала каталог с файлами, потом JSON — читатель берёт
элемент только по JSON, поэтому недописанных элементов не видит.
Переходы между каталогами — rename, атомарно.
"""
from __future__ import annotations
import json
import os
import secrets
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path

BOXES = ("outbox", "sending", "sent", "inbox", "failed")
PULL_MARKER = ".last_pull"


def new_id() -> str:
    return datetime.utcnow().strftime("%Y%m%dT%H%M%S%f") + "-" + secrets.token_hex(4)


@dataclass
class Item:
    id: str
    data: dict
    files_dir: Path


class Queue:
    def __init__(self, root: Path):
        self.root = Path(root)
        for box in BOXES:
            (self.root / box).mkdir(parents=True, exist_ok=True)

    def _box(self, box: str) -> Path:
        if box not in BOXES:
            raise ValueError(f"неизвестный каталог очереди {box!r}")
        return self.root / box

    def put(self, box: str, data: dict, files: dict[str, bytes] | None = None) -> str:
        directory = self._box(box)
        item_id = data.get("id") or new_id()
        data = {**data, "id": item_id, "files": sorted((files or {}).keys())}
        if files:
            files_dir = directory / item_id
            files_dir.mkdir(exist_ok=True)
            for name, payload in files.items():
                (files_dir / name).write_bytes(payload)
        self._write_json(directory / f"{item_id}.json", data)
        return item_id

    def items(self, box: str) -> list[Item]:
        directory = self._box(box)
        return [self.load(box, path.stem) for path in sorted(directory.glob("*.json"))]

    def load(self, box: str, item_id: str) -> Item:
        directory = self._box(box)
        data = json.loads((directory / f"{item_id}.json").read_text(encoding="utf-8"))
        return Item(id=item_id, data=data, files_dir=directory / item_id)

    def save(self, item: Item, box: str) -> None:
        self._write_json(self._box(box) / f"{item.id}.json", item.data)

    def move(self, item_id: str, src: str, dst: str) -> None:
        src_dir, dst_dir = self._box(src), self._box(dst)
        files = src_dir / item_id
        if files.is_dir():
            os.rename(files, dst_dir / item_id)
        os.rename(src_dir / f"{item_id}.json", dst_dir / f"{item_id}.json")

    def find_sent_by_message(self, message_id: int) -> Item | None:
        for item in self.items("sent"):
            if item.data.get("message_id") == message_id:
                return item
        return None

    def touch_pull(self) -> None:
        (self.root / PULL_MARKER).touch()

    def last_pull_age(self, now: datetime) -> float | None:
        marker = self.root / PULL_MARKER
        if not marker.exists():
            return None
        return now.timestamp() - marker.stat().st_mtime

    def sizes(self) -> dict[str, int]:
        return {box: len(list((self.root / box).glob("*.json"))) for box in BOXES}

    @staticmethod
    def _write_json(path: Path, data: dict) -> None:
        tmp = path.with_suffix(".json.tmp")
        tmp.write_text(json.dumps(data, ensure_ascii=False, indent=1), encoding="utf-8")
        os.replace(tmp, path)
```

```python
# courier/courier/registry.py
"""Реестр: код регистрации -> comms_id, telegram_id -> comms_id. Имён здесь нет."""
from __future__ import annotations
import json
import os
from pathlib import Path


class Registry:
    def __init__(self, path: Path):
        self.path = Path(path)
        self.codes: dict[str, str] = {}
        self.ids: dict[str, str] = {}
        if self.path.is_file():
            data = json.loads(self.path.read_text(encoding="utf-8"))
            self.codes = dict(data.get("codes") or {})
            self.ids = {str(k): v for k, v in (data.get("ids") or {}).items()}

    def add_code(self, code: str, comms_id: str) -> None:
        self.codes[code] = comms_id
        self.save()

    def bind(self, code: str, telegram_id: int) -> str | None:
        comms_id = self.codes.pop(code, None)
        if comms_id is None:
            return None
        self.ids = {k: v for k, v in self.ids.items() if v != comms_id}
        self.ids[str(telegram_id)] = comms_id
        self.save()
        return comms_id

    def who(self, telegram_id: int) -> str | None:
        return self.ids.get(str(telegram_id))

    def telegram_id_of(self, comms_id: str) -> int | None:
        for key, value in self.ids.items():
            if value == comms_id:
                return int(key)
        return None

    def save(self) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self.path.with_suffix(".json.tmp")
        tmp.write_text(json.dumps({"codes": self.codes, "ids": self.ids}, ensure_ascii=False, indent=1),
                       encoding="utf-8")
        os.replace(tmp, self.path)
```

```python
# courier/courier/config.py
from __future__ import annotations
import tomllib
from dataclasses import dataclass
from pathlib import Path


class ConfigError(Exception):
    pass


@dataclass(frozen=True)
class Config:
    bot_token: str
    queue_dir: Path
    registry_path: Path
    group_chat_id: int
    teacher_telegram_id: int
    proxy: str | None = None
    outbox_poll_seconds: int = 5
    brain_silent_minutes: int = 30
    heartbeat_hour: int = 9
    reconnect_notice_minutes: int = 2
    max_attempts: int = 5


def _read_env(env_path: Path) -> dict[str, str]:
    if not env_path.is_file():
        raise ConfigError(f"нет файла секретов: {env_path}")
    values: dict[str, str] = {}
    for line in env_path.read_text(encoding="utf-8").splitlines():
        line = line.strip()
        if line and not line.startswith("#") and "=" in line:
            key, _, value = line.partition("=")
            values[key.strip()] = value.strip()
    if not values.get("BOT_TOKEN"):
        raise ConfigError(f"в {env_path} нет BOT_TOKEN")
    return values


def load_config(toml_path: Path, env_path: Path) -> Config:
    toml_path, env_path = Path(toml_path), Path(env_path)
    if not toml_path.is_file():
        raise ConfigError(f"нет конфига: {toml_path}")
    with open(toml_path, "rb") as fh:
        data = tomllib.load(fh)
    try:
        return Config(
            bot_token=_read_env(env_path)["BOT_TOKEN"],
            queue_dir=Path(data["queue_dir"]),
            registry_path=Path(data["registry_path"]),
            group_chat_id=int(data["group_chat_id"]),
            teacher_telegram_id=int(data["teacher_telegram_id"]),
            proxy=data.get("proxy") or None,
            outbox_poll_seconds=int(data.get("outbox_poll_seconds", 5)),
            brain_silent_minutes=int(data.get("brain_silent_minutes", 30)),
            heartbeat_hour=int(data.get("heartbeat_hour", 9)),
            reconnect_notice_minutes=int(data.get("reconnect_notice_minutes", 2)),
            max_attempts=int(data.get("max_attempts", 5)),
        )
    except KeyError as exc:
        raise ConfigError(f"в {toml_path} нет ключа {exc}") from exc
```

```python
# courier/courier/handlers.py
"""Входящие из Telegram -> элементы inbox. Чистые сборщики отдельно от aiogram-обвязки."""
from __future__ import annotations
from datetime import datetime, timezone
from pathlib import Path

from aiogram import F, Router
from aiogram.types import CallbackQuery, Message

from courier.config import Config
from courier.queue import Queue
from courier.registry import Registry

UNSUPPORTED = (("voice", "voice"), ("sticker", "sticker"), ("video", "video"), ("video_note", "video"))


def parse_start(text: str | None) -> str | None:
    if not text or not text.startswith("/start"):
        return None
    parts = text.split(maxsplit=1)
    return parts[1].strip() if len(parts) == 2 and parts[1].strip() else None


def classify_sender(user_id: int, registry: Registry, cfg: Config) -> str:
    if user_id == cfg.teacher_telegram_id:
        return "teacher"
    return registry.who(user_id) or f"unknown:{user_id}"


def attachment_of(msg) -> tuple[str, str] | None:
    if getattr(msg, "photo", None):
        return msg.photo[-1].file_id, "photo.jpg"
    doc = getattr(msg, "document", None)
    if doc:
        return doc.file_id, (doc.file_name or "file.bin")
    return None


def _unsupported(msg) -> str | None:
    for attr, label in UNSUPPORTED:
        if getattr(msg, attr, None):
            return label
    return None


def _addressed_to_bot(msg, bot_username: str) -> bool:
    text = msg.text or msg.caption or ""
    if f"@{bot_username}" in text:
        return True
    reply = getattr(msg, "reply_to_message", None)
    return bool(reply and getattr(reply.from_user, "is_bot", False) and reply.from_user.username == bot_username)


def inbox_from_message(msg, registry: Registry, cfg: Config, bot_username: str, queue: Queue | None = None) -> dict | None:
    sender = classify_sender(msg.from_user.id, registry, cfg)
    chat = "private" if msg.chat.type == "private" else "group"
    code = parse_start(msg.text)
    if chat == "private" and code:
        comms_id = registry.bind(code, msg.from_user.id)
        if comms_id:
            item = _item(comms_id, chat, "registered", "", msg)
            item["telegram_id"] = msg.from_user.id
            return item
    if chat == "private" and sender.startswith("unknown:"):
        return None
    if chat == "group" and not _addressed_to_bot(msg, bot_username):
        return None
    attachment = attachment_of(msg)
    kind = "photo" if getattr(msg, "photo", None) else "document" if getattr(msg, "document", None) else "text"
    text = msg.text or msg.caption or ""
    item = _item(sender, chat, kind, text, msg)
    item["unsupported"] = _unsupported(msg)
    reply = getattr(msg, "reply_to_message", None)
    if reply is not None:
        item["reply_to_message_id"] = reply.message_id
        if sender == "teacher" and queue is not None:
            sent = queue.find_sent_by_message(reply.message_id)
            if sent is not None:
                item["kind"] = "reply"
                item["reply_to_item"] = sent.id
    return item


def inbox_from_callback(cb, registry: Registry, cfg: Config) -> dict:
    sender = classify_sender(cb.from_user.id, registry, cfg)
    chat = "private" if cb.message.chat.type == "private" else "group"
    item = _item(sender, chat, "callback", "", cb.message)
    item["callback"] = cb.data
    return item


def _item(sender: str, chat: str, kind: str, text: str, msg) -> dict:
    return {"from": sender, "chat": chat, "kind": kind, "text": text, "message_id": msg.message_id,
            "reply_to_message_id": None, "reply_to_item": None, "callback": None, "unsupported": None,
            "ts": datetime.now(timezone.utc).isoformat(timespec="seconds")}


def build_router(queue: Queue, registry: Registry, cfg: Config, bot_username: str) -> Router:
    router = Router()

    @router.message()
    async def on_message(message: Message):
        item = inbox_from_message(message, registry, cfg, bot_username, queue=queue)
        if item is None:
            return
        files: dict[str, bytes] = {}
        attachment = attachment_of(message)
        if attachment:
            file_id, name = attachment
            tmp = Path(cfg.queue_dir) / ".download" / name
            tmp.parent.mkdir(parents=True, exist_ok=True)
            await message.bot.download(file_id, destination=tmp)
            files[name] = tmp.read_bytes()
            tmp.unlink()
        queue.put("inbox", item, files)
        if item["kind"] == "registered":
            await message.answer("Привязал. Теперь сюда можно присылать домашки и вопросы.")
        elif item["chat"] == "private" and item["from"] != "teacher":
            await message.answer("Получил, передал Димасу.")

    @router.callback_query(F.data)
    async def on_callback(callback: CallbackQuery):
        if callback.from_user.id != cfg.teacher_telegram_id:
            await callback.answer("Кнопки — только для преподавателя.")
            return
        queue.put("inbox", inbox_from_callback(callback, registry, cfg))
        await callback.answer("Принято.")

    return router
```

```python
# courier/courier/delivery.py
"""outbox -> Telegram. Элемент уходит текстом с кнопками, вложения следом документами."""
from __future__ import annotations
import asyncio
import logging

from aiogram.types import FSInputFile, InlineKeyboardButton, InlineKeyboardMarkup

from courier.config import Config
from courier.queue import Item, Queue
from courier.registry import Registry

log = logging.getLogger("courier.delivery")


def resolve_chat(to: str, cfg: Config, registry: Registry) -> int | None:
    if to == "group":
        return cfg.group_chat_id
    if to == "teacher":
        return cfg.teacher_telegram_id
    return registry.telegram_id_of(to)


def keyboard(buttons: list[dict] | None) -> InlineKeyboardMarkup | None:
    if not buttons:
        return None
    row = [InlineKeyboardButton(text=b["label"], callback_data=b["data"]) for b in buttons]
    return InlineKeyboardMarkup(inline_keyboard=[row])


def apply_control(data: dict, registry: Registry) -> str:
    if data.get("action") == "add_code":
        registry.add_code(str(data["code"]), str(data["comms_id"]))
        return "код добавлен"
    return f"неизвестное control-действие {data.get('action')!r}"


async def _send(item: Item, chat_id: int, bot) -> int:
    message = await bot.send_message(
        chat_id, item.data.get("text") or "", parse_mode=item.data.get("parse_mode") or "HTML",
        reply_markup=keyboard(item.data.get("buttons")), reply_to_message_id=item.data.get("reply_to"))
    for name in item.data.get("files") or []:
        await bot.send_document(chat_id, FSInputFile(item.files_dir / name), caption=None)
    return message.message_id


async def _notify_teacher(bot, cfg: Config, text: str) -> None:
    try:
        await bot.send_message(cfg.teacher_telegram_id, text, parse_mode="HTML", reply_markup=None,
                               reply_to_message_id=None)
    except Exception as exc:
        log.warning("не смог уведомить преподавателя: %s", exc)


async def deliver_once(queue: Queue, bot, cfg: Config, registry: Registry) -> int:
    delivered = 0
    for item in queue.items("outbox"):
        to = item.data.get("to", "")
        if to == "courier":
            log.info("control %s: %s", item.id, apply_control(item.data, registry))
            queue.move(item.id, "outbox", "sent")
            continue
        chat_id = resolve_chat(to, cfg, registry)
        if chat_id is None:
            queue.move(item.id, "outbox", "failed")
            await _notify_teacher(bot, cfg, f"Не доставлено {item.id}: адресат {to} не зарегистрирован.")
            continue
        queue.move(item.id, "outbox", "sending")
        try:
            item.data["message_id"] = await _send(item, chat_id, bot)
        except Exception as exc:
            item.data["attempts"] = int(item.data.get("attempts", 0)) + 1
            item.data["last_error"] = str(exc)[:200]
            queue.save(item, "sending")
            if item.data["attempts"] >= cfg.max_attempts:
                queue.move(item.id, "sending", "failed")
                await _notify_teacher(bot, cfg, f"Не доставлено {item.id} после {cfg.max_attempts} попыток: {exc}")
            else:
                queue.move(item.id, "sending", "outbox")
            log.warning("доставка %s не удалась: %s", item.id, exc)
            continue
        queue.save(item, "sending")
        queue.move(item.id, "sending", "sent")
        delivered += 1
    return delivered


async def deliver_loop(queue: Queue, bot, cfg: Config, registry: Registry, stop: asyncio.Event) -> None:
    for item in queue.items("sending"):                    # хвост после падения процесса
        queue.move(item.id, "sending", "outbox")
    while not stop.is_set():
        try:
            await deliver_once(queue, bot, cfg, registry)
        except Exception as exc:
            log.exception("цикл доставки: %s", exc)
        try:
            await asyncio.wait_for(stop.wait(), timeout=cfg.outbox_poll_seconds)
        except asyncio.TimeoutError:
            pass
```

```python
# courier/courier/watchdog.py
"""Сторожок: heartbeat раз в день, «был в отключке», «мозг молчит», status.json для info-панели."""
from __future__ import annotations
import asyncio
import json
import logging
import os
from datetime import date, datetime
from pathlib import Path

from courier.config import Config
from courier.queue import Queue

log = logging.getLogger("courier.watchdog")


def write_status(queue: Queue, cfg: Config, now: datetime, online: bool, outage_since: datetime | None) -> Path:
    path = queue.root / "status.json"
    data = {"ts": now.isoformat(timespec="seconds"), "online": online,
            "outage_since": outage_since.isoformat(timespec="seconds") if outage_since else None,
            "sizes": queue.sizes(), "last_pull_age_s": queue.last_pull_age(now)}
    tmp = path.with_suffix(".json.tmp")
    tmp.write_text(json.dumps(data, ensure_ascii=False), encoding="utf-8")
    os.replace(tmp, path)
    return path


class Watchdog:
    def __init__(self, cfg: Config, queue: Queue, bot):
        self.cfg, self.queue, self.bot = cfg, queue, bot
        self.outage_since: datetime | None = None
        self.last_heartbeat_day: date | None = None
        self.brain_silent_notified = False

    async def _say(self, text: str, notices: list[str]) -> None:
        try:
            await self.bot.send_message(self.cfg.teacher_telegram_id, text)
            notices.append(text)
        except Exception as exc:
            log.warning("сторожок не дозвонился: %s", exc)

    async def tick(self, now: datetime) -> list[str]:
        notices: list[str] = []
        try:
            await self.bot.get_me()
            online = True
        except Exception:
            online = False
        if not online:
            if self.outage_since is None:
                self.outage_since = now
            write_status(self.queue, self.cfg, now, False, self.outage_since)
            return notices
        if self.outage_since is not None:
            minutes = int((now - self.outage_since).total_seconds() // 60)
            self.outage_since = None
            if minutes >= self.cfg.reconnect_notice_minutes:
                sizes = self.queue.sizes()
                await self._say(f"Был в отключке {minutes} мин. В очереди: исходящих {sizes['outbox']}, "
                                f"входящих {sizes['inbox']}.", notices)
        if now.hour >= self.cfg.heartbeat_hour and self.last_heartbeat_day != now.date():
            self.last_heartbeat_day = now.date()
            sizes = self.queue.sizes()
            await self._say(f"Почтальон жив. Очередь: исходящих {sizes['outbox']}, входящих {sizes['inbox']}, "
                            f"не доставлено {sizes['failed']}.", notices)
        age = self.queue.last_pull_age(now)
        silent = age is not None and age > self.cfg.brain_silent_minutes * 60
        if silent and not self.brain_silent_notified:
            self.brain_silent_notified = True
            await self._say(f"Мозг молчит {int(age // 60)} мин: Mac не забирал очередь.", notices)
        elif not silent:
            self.brain_silent_notified = False
        write_status(self.queue, self.cfg, now, True, None)
        return notices


async def watchdog_loop(wd: Watchdog, stop: asyncio.Event, interval_s: int = 60) -> None:
    while not stop.is_set():
        try:
            await wd.tick(datetime.now())
        except Exception as exc:
            log.exception("сторожок: %s", exc)
        try:
            await asyncio.wait_for(stop.wait(), timeout=interval_s)
        except asyncio.TimeoutError:
            pass
```

```python
# courier/courier/main.py
from __future__ import annotations
import argparse
import asyncio
import logging
import signal
from pathlib import Path

from aiogram import Bot, Dispatcher
from aiogram.client.session.aiohttp import AiohttpSession

from courier.config import Config, load_config
from courier.delivery import deliver_loop
from courier.handlers import build_router
from courier.queue import Queue
from courier.registry import Registry
from courier.watchdog import Watchdog, watchdog_loop

log = logging.getLogger("courier")


def parse_args(argv=None) -> argparse.Namespace:
    ap = argparse.ArgumentParser(prog="courier", description="Почтальон: Telegram <-> файловые очереди")
    ap.add_argument("--config", type=Path, default=Path("/srv/courier/courier.toml"))
    ap.add_argument("--env", type=Path, default=Path("/srv/courier/courier.env"))
    return ap.parse_args(argv)


def make_bot(cfg: Config) -> Bot:
    session = AiohttpSession(proxy=cfg.proxy) if cfg.proxy else AiohttpSession()
    return Bot(cfg.bot_token, session=session)


async def run(cfg: Config) -> None:
    queue, registry, bot = Queue(cfg.queue_dir), Registry(cfg.registry_path), make_bot(cfg)
    me = await bot.get_me()
    dp = Dispatcher()
    dp.include_router(build_router(queue, registry, cfg, me.username))
    stop = asyncio.Event()
    loop = asyncio.get_running_loop()
    for sig in (signal.SIGINT, signal.SIGTERM):
        loop.add_signal_handler(sig, stop.set)
    polling = asyncio.create_task(dp.start_polling(bot, handle_signals=False))
    delivery = asyncio.create_task(deliver_loop(queue, bot, cfg, registry, stop))
    guard = asyncio.create_task(watchdog_loop(Watchdog(cfg, queue, bot), stop))
    await stop.wait()
    await dp.stop_polling()
    await asyncio.gather(polling, delivery, guard, return_exceptions=True)
    await bot.session.close()


def main(argv=None) -> int:
    logging.basicConfig(level=logging.INFO, format="%(asctime)s %(name)s %(levelname)s %(message)s")
    args = parse_args(argv)
    cfg = load_config(args.config, args.env)
    asyncio.run(run(cfg))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
from __future__ import annotations
import json
import os
from datetime import datetime, timedelta
from pathlib import Path


class State:
    def __init__(self, path: Path):
        self.path = Path(path)
        self.data: dict = {"processed": {}, "pending": {}, "github": {}, "tick": 0,
                           "reminder_sent_for": None, "digest_sent_on": None, "drafts_seen": []}
        if self.path.is_file():
            self.data.update(json.loads(self.path.read_text(encoding="utf-8")))

    @property
    def pending(self) -> dict:
        return self.data["pending"]

    @property
    def github(self) -> dict:
        return self.data["github"]

    @property
    def tick(self) -> int:
        return int(self.data["tick"])

    @tick.setter
    def tick(self, value: int) -> None:
        self.data["tick"] = int(value)

    def processed(self, item_id: str) -> bool:
        return item_id in self.data["processed"]

    def mark_processed(self, item_id: str, now: datetime) -> None:
        self.data["processed"][item_id] = now.isoformat(timespec="seconds")

    def prune(self, now: datetime, days: int = 30) -> None:
        edge = (now - timedelta(days=days)).isoformat(timespec="seconds")
        self.data["processed"] = {k: v for k, v in self.data["processed"].items() if v >= edge}

    def save(self) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self.path.with_suffix(".json.tmp")
        tmp.write_text(json.dumps(self.data, ensure_ascii=False, indent=1), encoding="utf-8")
        os.replace(tmp, self.path)
```

```python
# tools/comms/queue.py
"""Элементы очередей в формате courier: <id>.json + каталог <id>/ с вложениями. Без импорта из courier."""
from __future__ import annotations
import json
import os
import secrets
import shutil
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path


def new_id() -> str:
    return datetime.utcnow().strftime("%Y%m%dT%H%M%S%f") + "-" + secrets.token_hex(4)


@dataclass
class Item:
    id: str
    data: dict
    files_dir: Path


def write_item(box_dir: Path, data: dict, files: dict[str, bytes] | None = None) -> str:
    box_dir = Path(box_dir)
    box_dir.mkdir(parents=True, exist_ok=True)
    item_id = data.get("id") or new_id()
    payload = {**data, "id": item_id, "files": sorted((files or {}).keys())}
    if files:
        (box_dir / item_id).mkdir(exist_ok=True)
        for name, content in files.items():
            (box_dir / item_id / name).write_bytes(content)
    tmp = box_dir / f"{item_id}.json.tmp"
    tmp.write_text(json.dumps(payload, ensure_ascii=False, indent=1), encoding="utf-8")
    os.replace(tmp, box_dir / f"{item_id}.json")
    return item_id


def read_items(box_dir: Path) -> list[Item]:
    box_dir = Path(box_dir)
    if not box_dir.is_dir():
        return []
    items = []
    for path in sorted(box_dir.glob("*.json")):
        data = json.loads(path.read_text(encoding="utf-8"))
        items.append(Item(id=path.stem, data=data, files_dir=box_dir / path.stem))
    return items


def remove_item(box_dir: Path, item_id: str) -> None:
    box_dir = Path(box_dir)
    (box_dir / f"{item_id}.json").unlink(missing_ok=True)
    shutil.rmtree(box_dir / item_id, ignore_errors=True)
```

```python
# tools/comms/identity.py
"""students/comms.yml — кто есть кто для courier: comms_id, код, telegram_id, репо GitHub. Приватно."""
from __future__ import annotations
import os
import secrets
from dataclasses import asdict, dataclass
from pathlib import Path

import yaml

ALPHABET = "ABCDEFGHJKLMNPQRSTUVWXYZ23456789"   # без 0/O, 1/I


@dataclass
class Person:
    role: str
    student: str
    comms_id: str
    code: str | None = None
    telegram_id: int | None = None
    github: str | None = None


class Identity:
    def __init__(self, path: Path):
        self.path = Path(path)
        self.people: list[Person] = []
        if self.path.is_file():
            data = yaml.safe_load(self.path.read_text(encoding="utf-8")) or {}
            self.people = [Person(**{k: v for k, v in raw.items() if k in Person.__dataclass_fields__})
                           for raw in data.get("people") or []]

    def by_student(self, student_id: str, role: str = "student") -> Person | None:
        return next((p for p in self.people if p.student == student_id and p.role == role), None)

    def by_comms_id(self, comms_id: str) -> Person | None:
        return next((p for p in self.people if p.comms_id == comms_id), None)

    def ensure(self, student_id: str, role: str = "student") -> Person:
        person = self.by_student(student_id, role)
        if person is None:
            prefix = "s-" if role == "student" else "p-"
            taken = {p.comms_id for p in self.people}
            comms_id = prefix + secrets.token_hex(2)
            while comms_id in taken:
                comms_id = prefix + secrets.token_hex(2)
            person = Person(role=role, student=student_id, comms_id=comms_id)
            self.people.append(person)
            self.save()
        return person

    def new_code(self, person: Person) -> str:
        chars = [secrets.choice(ALPHABET) for _ in range(5)]
        person.code = "".join(chars[:3]) + "-" + "".join(chars[3:])
        self.save()
        return person.code

    def bind(self, comms_id: str, telegram_id: int) -> Person | None:
        person = self.by_comms_id(comms_id)
        if person is None:
            return None
        person.telegram_id, person.code = int(telegram_id), None
        self.save()
        return person

    def set_github(self, student_id: str, repo: str) -> None:
        self.ensure(student_id).github = repo
        self.save()

    def save(self) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self.path.with_suffix(".yml.tmp")
        tmp.write_text(yaml.safe_dump({"people": [asdict(p) for p in self.people]},
                                      allow_unicode=True, sort_keys=False), encoding="utf-8")
        os.replace(tmp, self.path)
```

```python
# tools/comms/outbox.py
"""Исходящие элементы brain -> outbox-staging/ (на HP их переносит transport.push)."""
from __future__ import annotations
import html
from pathlib import Path

from comms.queue import write_item


def esc(text: str) -> str:
    return html.escape(str(text), quote=False)


class Outbox:
    def __init__(self, staging: Path):
        self.staging = Path(staging)

    def _put(self, to: str, text: str, buttons=None, files=None, **extra) -> str:
        data = {"to": to, "text": text, "parse_mode": "HTML", "reply_to": None, "attempts": 0,
                "buttons": [{"label": label, "data": data} for label, data in (buttons or [])], **extra}
        return write_item(self.staging, data, files)

    def teacher(self, text: str, buttons=None, files=None) -> str:
        return self._put("teacher", text, buttons, files)

    def group(self, text: str, files=None) -> str:
        return self._put("group", text, None, files)

    def person(self, comms_id: str, text: str, buttons=None, files=None) -> str:
        return self._put(comms_id, text, buttons, files)

    def control_add_code(self, code: str, comms_id: str) -> str:
        return self._put("courier", "", action="add_code", code=code, comms_id=comms_id)
```

```python
# tools/comms/transport.py
"""Mac <-> HP: rsync по ssh. Ключ только в сторону Mac -> HP."""
from __future__ import annotations
import shutil

from comms.config import Config
from comms.queue import read_items

SSH = ["ssh", "-o", "BatchMode=yes", "-o", "ConnectTimeout=10"]
RSYNC_TIMEOUT = 120


class TransportError(Exception):
    pass


def _ok(result, what: str) -> None:
    if result.returncode != 0:
        raise TransportError(f"{what}: код {result.returncode}: {(result.stderr or '').strip()[:200]}")


def pull(cfg: Config, runner) -> int:
    local_inbox = cfg.local_dir / "inbox"
    local_inbox.mkdir(parents=True, exist_ok=True)
    before = {i.id for i in read_items(local_inbox)}
    remote = f"{cfg.hp_host}:{cfg.hp_queue_dir}"
    _ok(runner(["rsync", "-a", "--remove-source-files", "-e", " ".join(SSH),
                f"{remote}/inbox/", f"{local_inbox}/"], timeout=RSYNC_TIMEOUT), "rsync inbox")
    _ok(runner([*SSH, cfg.hp_host,
                f"find {cfg.hp_queue_dir}/inbox -mindepth 1 -type d -empty -delete; touch {cfg.hp_queue_dir}/.last_pull"],
               timeout=RSYNC_TIMEOUT), "ssh cleanup")
    runner(["rsync", "-a", "-e", " ".join(SSH), f"{remote}/status.json", str(cfg.local_dir / "status.json")],
           timeout=RSYNC_TIMEOUT)                      # статус — best effort
    return len({i.id for i in read_items(local_inbox)} - before)


def push(cfg: Config, runner) -> int:
    staging = cfg.local_dir / "outbox-staging"
    items = read_items(staging)
    if not items:
        return 0
    remote = f"{cfg.hp_host}:{cfg.hp_queue_dir}/outbox/"
    _ok(runner(["rsync", "-a", "--exclude", "*.json", "-e", " ".join(SSH), f"{staging}/", remote],
               timeout=RSYNC_TIMEOUT), "rsync вложений")
    _ok(runner(["rsync", "-a", "--include", "*.json", "--exclude", "*", "-e", " ".join(SSH), f"{staging}/", remote],
               timeout=RSYNC_TIMEOUT), "rsync json")
    for child in staging.iterdir():
        shutil.rmtree(child) if child.is_dir() else child.unlink()
    return len(items)
```

"""Markdown задания -> Telegram-HTML (подмножество: b, code, pre, a)."""
from __future__ import annotations
import html
import re
from datetime import date

WEEKDAYS = ("пн", "вт", "ср", "чт", "пт", "сб", "вс")


def _inline(line: str) -> str:
    line = re.sub(r"`([^`]+)`", r"<code>\1</code>", line)
    line = re.sub(r"\*\*([^*]+)\*\*", r"<b>\1</b>", line)
    line = re.sub(r"\[([^\]]+)\]\((https?://[^)\s]+)\)", r'<a href="\2">\1</a>', line)
    return line


def _blocks(md: str) -> list[str]:
    """Список блоков: обычные строки по одной, fenced-код — одним блоком <pre>."""
    out: list[str] = []
    lines = html.escape(md, quote=False).splitlines()
    i = 0
    while i < len(lines):
        line = lines[i]
        if line.startswith("```"):
            j = i + 1
            code: list[str] = []
            while j < len(lines) and not lines[j].startswith("```"):
                code.append(lines[j])
                j += 1
            out.append("<pre>" + "\n".join(code) + "</pre>")
            i = j + 1
            continue
        heading = re.match(r"^#{1,6}\s+(.*)$", line)
        if heading:
            out.append(f"<b>{_inline(heading.group(1).strip())}</b>")
        elif line.startswith("&gt; "):
            out.append(_inline(line[5:]))
        else:
            out.append(_inline(line))
        i += 1
    return out


def telegram_html(md: str, limit: int = 3500, more_url: str | None = None) -> str:
    text = "\n".join(_blocks(md)).strip()
    text = re.sub(r"\n{3,}", "\n\n", text)
    if len(text) <= limit:
        return text
    tail = f"…\nПолностью: {more_url}" if more_url else "…"
    budget = limit - len(tail)
    cut = text.rfind("\n", 0, budget)
    head = text[:cut if cut > 0 else budget]
    if head.count("<pre>") != head.count("</pre>"):
        head = head[:head.rfind("<pre>")].rstrip()
    return head.rstrip() + tail


def homework_block(task_md: str, hw_id: str, due: date | None, url: str) -> str:
    title = f"<b>Домашка до {WEEKDAYS[due.weekday()]} {due.strftime('%d.%m')}</b>" if due else "<b>Домашка</b>"
    return f"{title}\n{telegram_html(task_md, more_url=url)}\n\nСтраница: {url}"

```python
"""Черновики Zoom-пайплайна (meta/drafts/lesson-<дата>-<HHMM>-analysis.md) -> раздел для поста."""
from __future__ import annotations
import re
from datetime import date
from pathlib import Path

NAME_RE = re.compile(r"^lesson-(\d{4}-\d{2}-\d{2})-\d{4}-analysis\.md$")
SECTION = "## Сообщение в MAX"


def new_drafts(drafts_dir: Path, seen: list[str]) -> list[Path]:
    drafts_dir = Path(drafts_dir)
    if not drafts_dir.is_dir():
        return []
    return sorted(p for p in drafts_dir.iterdir() if NAME_RE.match(p.name) and p.name not in seen)


def max_section(text: str) -> str | None:
    start = text.find(SECTION)
    if start < 0:
        return None
    body = text[start + len(SECTION):]
    nxt = re.search(r"^## ", body, flags=re.MULTILINE)
    return (body[:nxt.start()] if nxt else body).strip() or None


def lesson_date(path: Path) -> date | None:
    match = NAME_RE.match(Path(path).name)
    return date.fromisoformat(match.group(1)) if match else None
```

```python
# tools/comms/schedule.py
"""Что brain делает по часам: напоминание накануне, пост после занятия, сводка хвостов."""
from __future__ import annotations
import re
from datetime import date, datetime, timedelta
from pathlib import Path

from comms import course
from comms.config import Config
from comms.drafts import lesson_date, max_section, new_drafts
from comms.homework_text import homework_block
from comms.outbox import Outbox, esc
from comms.state import State
from info.common import next_session, weekday_ru
from journal import stats as journal_stats

TAIL_RE = re.compile(r"^(?P<hw>[^:]+): просрочена с (?P<since>\d{4}-\d{2}-\d{2})$")
SEND_BUTTONS = [("отправить в группу", "send:{id}"), ("отбросить", "discard:{id}")]


def _stage_post(state: State, outbox: Outbox, cfg: Config, text: str, files: dict[str, bytes], max_copy: bool) -> str:
    preview = text if len(text) < 3900 else text[:3900] + "…"
    item_id = outbox.teacher_with_self_buttons(preview, SEND_BUTTONS, files=files or None)
    pending_dir = cfg.local_dir / "pending" / item_id
    if files:
        pending_dir.mkdir(parents=True, exist_ok=True)
        for name, content in files.items():
            (pending_dir / name).write_bytes(content)
    state.pending[item_id] = {"kind": "post", "target": "group", "text": text,
                              "files": sorted(files.keys()), "max_copy": max_copy}
    return item_id


def reminder_text(session: dict, pages_url: str) -> str:
    day = session["date"]
    when = f"{weekday_ru(day)} {day.strftime('%d.%m')} в {session.get('time', '20:00')}"
    theme = esc(session.get("theme") or "занятие")
    return f"Напоминаю: завтра, {when} — занятие Junior_IT.\nТема: {theme}.\nМатериалы: {pages_url}"


def post_text(max_text: str, hw_blocks: list[str]) -> str:
    return "\n\n".join([esc(max_text), *hw_blocks]).strip()


def digest_text(tails: list[dict]) -> str:
    lines = [f"Хвосты по домашкам на сегодня ({len(tails)}):"]
    for t in tails:
        lines.append(f"• {esc(t['name'])} — {esc(t['hw_id'])}, срок был {t['since']}")
    lines.append("Кнопка — напомнить ученику в личку.")
    return "\n".join(lines)


def collect_tails(students_root, repo_root, today: date) -> list[dict]:
    group = journal_stats.collect(students_root, repo_root, today)
    out = []
    for s in group.students:
        for tail in s.tails:
            m = TAIL_RE.match(tail)
            if m:
                out.append({"student": s.id, "name": s.name, "hw_id": m.group("hw"), "since": m.group("since")})
    return out


def _reminder(cfg: Config, state: State, outbox: Outbox, now: datetime) -> bool:
    session, stale = next_session(course.sessions(cfg.repo_root), now.date())
    if not session or stale or session["date"] != now.date() + timedelta(days=1):
        return False
    if now.hour < cfg.reminder_hour or state.data.get("reminder_sent_for") == session["date"].isoformat():
        return False
    text = reminder_text(session, cfg.pages_url)
    _stage_post(state, outbox, cfg, text, {}, max_copy=False)
    state.data["reminder_sent_for"] = session["date"].isoformat()
    return True


def _posts(cfg: Config, state: State, outbox: Outbox) -> list[str]:
    done = []
    for path in new_drafts(course.drafts_dir(cfg.repo_root), state.data["drafts_seen"]):
        state.data["drafts_seen"].append(path.name)
        section = max_section(path.read_text(encoding="utf-8"))
        if not section:
            continue
        day = lesson_date(path)
        plan = course.plan_for(cfg.repo_root, day) if day else None
        blocks, files = [], {}
        for hw_id in (course.homework_ids(plan) if plan else []):
            url = course.page_url(cfg.pages_url, hw_id)
            blocks.append(homework_block(course.task_text(cfg.repo_root, hw_id), hw_id, course.due(plan), url))
            files.update(course.attachments(cfg.repo_root, hw_id))
        _stage_post(state, outbox, cfg, post_text(section, blocks), files, max_copy=True)
        done.append(f"post:{path.name}")
    return done


def _digest(cfg: Config, state: State, outbox: Outbox, now: datetime, tails_fn) -> bool:
    today = now.date().isoformat()
    if now.hour < cfg.digest_hour or state.data.get("digest_sent_on") == today:
        return False
    state.data["digest_sent_on"] = today
    tails = tails_fn()
    if not tails:
        return False
    spec = [(f"напомнить: {t['name']}", f"remind:{n}:{{id}}") for n, t in enumerate(tails)]
    item_id = outbox.teacher_with_self_buttons(digest_text(tails), spec)
    state.pending[item_id] = {"kind": "digest", "tails": tails}
    return True


def run(cfg: Config, state: State, outbox: Outbox, now: datetime, tails_fn) -> list[str]:
    done: list[str] = []
    if _reminder(cfg, state, outbox, now):
        done.append("reminder")
    done.extend(_posts(cfg, state, outbox))
    if _digest(cfg, state, outbox, now, tails_fn):
        done.append("digest")
    return done
```

```python
# tools/comms/github_poll.py
"""Репозитории учеников: новые коммиты в hw/<id>/ -> тесты домашки -> Submission."""
from __future__ import annotations
import logging
import re
import shutil
import subprocess
import sys
import tempfile
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path

from comms.config import Config
from comms.identity import Identity
from comms.state import State

log = logging.getLogger("comms.github")
GIT_TIMEOUT = 60
HW_PATH_RE = re.compile(r"^hw/([^/]+)/")


@dataclass
class Submission:
    student: str
    comms_id: str
    hw_id: str
    sha: str
    passed: int
    failed: int
    log: str


def _run(cmd, runner, timeout=GIT_TIMEOUT) -> str:
    result = runner(cmd, timeout=timeout)
    if result.returncode != 0:
        raise RuntimeError(f"{' '.join(cmd[:3])}: код {result.returncode}: {(result.stderr or '').strip()[:200]}")
    return result.stdout or ""


def ensure_clone(repo: str, dest: Path, runner) -> None:
    if dest.is_dir():
        _run(["git", "-C", str(dest), "fetch", "-q", "origin", "+refs/heads/*:refs/heads/*"], runner)
        return
    dest.parent.mkdir(parents=True, exist_ok=True)
    _run(["gh", "repo", "clone", repo, str(dest), "--", "--bare"], runner)


def head_sha(dest: Path, runner) -> str:
    return _run(["git", "-C", str(dest), "rev-parse", "HEAD"], runner).strip()


def commits_since(dest: Path, since: str | None, runner) -> list[str]:
    span = f"{since}..HEAD" if since else "HEAD"
    return _run(["git", "-C", str(dest), "rev-list", "--reverse", span], runner).split()


def changed_hw_ids(dest: Path, sha: str, runner) -> list[str]:
    out: list[str] = []
    for path in _run(["git", "-C", str(dest), "show", "--name-only", "--format=", sha], runner).splitlines():
        m = HW_PATH_RE.match(path.strip())
        if m and m.group(1) not in out:
            out.append(m.group(1))
    return out


def export_subtree(dest: Path, sha: str, hw_id: str, target: Path, runner) -> Path:
    """git archive отдаёт tar байтами — единственное место, где brain зовёт git не через runner."""
    target.mkdir(parents=True, exist_ok=True)
    archive = subprocess.run(["git", "-C", str(dest), "archive", "--format=tar", sha, f"hw/{hw_id}"],
                             capture_output=True, check=True, timeout=GIT_TIMEOUT)
    subprocess.run(["tar", "-x", "-C", str(target)], input=archive.stdout, check=True, timeout=GIT_TIMEOUT)
    return target / "hw" / hw_id


def parse_summary(text: str) -> tuple[int, int]:
    passed = re.search(r"(\d+) passed", text)
    failed = re.search(r"(\d+) failed", text)
    return (int(passed.group(1)) if passed else 0, int(failed.group(1)) if failed else 0)


def run_tests(repo_root: Path, hw_id: str, workdir: Path, runner, timeout_s: int) -> tuple[int, int, str]:
    """pytest ученика — с cwd в его подпапке; у runner нет cwd, поэтому subprocess напрямую."""
    tests_src = Path(repo_root) / "homework" / hw_id / "tests"
    if not tests_src.is_dir():
        return 0, 0, "тестов нет"
    shutil.copytree(tests_src, workdir / "tests", dirs_exist_ok=True)
    try:
        result = subprocess.run([sys.executable, "-m", "pytest", "-q", "-p", "no:cacheprovider", "tests"],
                                cwd=workdir, capture_output=True, text=True, timeout=timeout_s)
    except subprocess.TimeoutExpired:
        return 0, 1, f"тесты не уложились в {timeout_s} с"
    output = (result.stdout or "") + (result.stderr or "")
    passed, failed = parse_summary(output)
    return passed, failed, output[-2000:]


def poll(cfg: Config, identity: Identity, state: State, runner, now: datetime) -> list[Submission]:
    submissions: list[Submission] = []
    for person in identity.people:
        if person.role != "student" or not person.github:
            continue
        dest = cfg.local_dir / "hw-repos" / person.comms_id
        try:
            ensure_clone(person.github, dest, runner)
            since = (state.github.get(person.comms_id) or {}).get("sha")
            commits = commits_since(dest, since, runner)
            for sha in commits:
                for hw_id in changed_hw_ids(dest, sha, runner):
                    with tempfile.TemporaryDirectory(prefix="jit-hw-") as tmp:
                        subtree = export_subtree(dest, sha, hw_id, Path(tmp), runner)
                        passed, failed, output = run_tests(cfg.repo_root, hw_id, subtree, runner, cfg.tests_timeout_s)
                    submissions.append(Submission(person.student, person.comms_id, hw_id, sha, passed, failed, output))
            state.github[person.comms_id] = {"sha": head_sha(dest, runner), "polled": now.isoformat(timespec="seconds")}
        except (RuntimeError, subprocess.TimeoutExpired, subprocess.CalledProcessError) as exc:
            log.warning("github %s: %s", person.student, exc)
    return submissions
```

```python
"""Черновики текста через `claude -p` под сессией Димаса. Ответ — только текст, детям не уходит сам."""
from __future__ import annotations
import logging
from pathlib import Path

from comms.config import Config

log = logging.getLogger("comms.claude")
CLAUDE_TIMEOUT = 900
PROMPTS = Path(__file__).resolve().parent / "prompts"
KINDS = ("answer", "review", "task")


class SafeDict(dict):
    def __missing__(self, key):
        return ""


def render_prompt(kind: str, fields: dict) -> str:
    if kind not in KINDS:
        raise ValueError(f"неизвестный вид черновика {kind!r}")
    template = (PROMPTS / f"{kind}.md").read_text(encoding="utf-8")
    rules = (PROMPTS / "_rules.md").read_text(encoding="utf-8")
    return template.format_map(SafeDict({**fields, "rules": rules}))


def draft(kind: str, fields: dict, cfg: Config, runner) -> str | None:
    prompt = render_prompt(kind, fields)
    result = runner(list(cfg.claude_cmd), timeout=CLAUDE_TIMEOUT, stdin_text=prompt)
    text = (result.stdout or "").strip()
    if result.returncode != 0 or not text:
        log.warning("claude -p %s: код %s, %s", kind, result.returncode, (result.stderr or "").strip()[:200])
        return None
    return text
```

```python
# tools/comms/apply.py
"""Входящие из очереди -> журнал, черновики, исходящие. Детям — только после кнопки Димаса."""
from __future__ import annotations
import html
import logging
import re
import shutil
from dataclasses import dataclass, field
from datetime import date, datetime
from pathlib import Path

from comms import course
from comms.claude_draft import draft
from comms.config import Config
from comms.github_poll import Submission
from comms.identity import Identity
from comms.outbox import Outbox, esc
from comms.queue import Item
from comms.state import State
from journal import ops, store
from journal.model import JournalError

log = logging.getLogger("comms.apply")
SUBMISSION_BUTTONS = [("принято", "accept:{id}"), ("доработать", "rework:{id}"), ("Claude, разбери", "claude:{id}")]
QUESTION_BUTTONS = [("Claude, черновик", "claude:{id}")]
POST_BUTTONS = [("отправить", "send:{id}"), ("отбросить", "discard:{id}")]
UNSUPPORTED_RU = {"voice": "голосовое", "sticker": "стикер", "video": "видео", "other": "что-то нечитаемое"}
TEXT_EXT = {".py", ".txt", ".md", ".html", ".css", ".js"}


@dataclass
class Context:
    cfg: Config
    state: State
    identity: Identity
    outbox: Outbox
    runner: object
    now: datetime
    names: dict[str, str] = field(default_factory=dict)

    @property
    def today(self) -> date:
        return self.now.date()

    def name(self, student_id: str) -> str:
        return self.names.get(student_id, student_id)

    def pending_dir(self, item_id: str) -> Path:
        return self.cfg.local_dir / "pending" / item_id


def plain(html_text: str) -> str:
    return html.unescape(re.sub(r"<[^>]+>", "", html_text))


def open_homework(students_root, student_id: str) -> tuple[date, str] | None:
    for rec in sorted(store.load_lessons(students_root), key=lambda r: r.date, reverse=True):
        for hw_id, marks in rec.homework.items():
            m = marks.get(student_id)
            if m and m.status in ("issued", "rework"):
                return rec.date, hw_id
    return None


def ensure_issued(ctx: Context, student_id: str, hw_id: str) -> date:
    for rec in sorted(store.load_lessons(ctx.cfg.students_root), key=lambda r: r.date, reverse=True):
        if student_id in (rec.homework.get(hw_id) or {}):
            return rec.date
    found = course.latest_plan_with_homework(ctx.cfg.repo_root, ctx.today)
    if not found:
        raise JournalError(f"нет плана с домашкой для {hw_id}")
    day, _ = found
    ops.issue_homework(day, hw_id, [student_id], ctx.cfg.students_root, ctx.cfg.repo_root)
    return day


def record_submission(ctx: Context, student_id: str, hw_id: str, note: str, by: str) -> date:
    day = ensure_issued(ctx, student_id, hw_id)
    ops.set_homework(day, hw_id, student_id, "submitted", note, ctx.cfg.students_root, ctx.today, by)
    return day


def _stash_files(ctx: Context, item_id: str, files: dict[str, bytes]) -> None:
    if not files:
        return
    target = ctx.pending_dir(item_id)
    target.mkdir(parents=True, exist_ok=True)
    for name, content in files.items():
        (target / name).write_bytes(content)


def _pending_files(ctx: Context, item_id: str) -> dict[str, bytes]:
    d = ctx.pending_dir(item_id)
    return {p.name: p.read_bytes() for p in sorted(d.iterdir())} if d.is_dir() else {}


def _drop_pending(ctx: Context, item_id: str) -> dict | None:
    meta = ctx.state.pending.pop(item_id, None)
    shutil.rmtree(ctx.pending_dir(item_id), ignore_errors=True)
    return meta


def _notify_submission(ctx: Context, student_id: str, hw_id: str, day: date, summary: str,
                       files: dict[str, bytes]) -> str:
    person = ctx.identity.by_student(student_id)
    text = f"<b>{esc(ctx.name(student_id))}</b> сдал(а) {esc(hw_id)}: {esc(summary)}"
    item_id = ctx.outbox.teacher_with_self_buttons(text, SUBMISSION_BUTTONS, files=files or None)
    _stash_files(ctx, item_id, files)
    ctx.state.pending[item_id] = {"kind": "submission", "student": student_id, "comms_id": person.comms_id,
                                  "hw_id": hw_id, "day": day.isoformat(), "summary": summary, "await_reply": False}
    return item_id


def _stage_draft(ctx: Context, text: str, target: str, max_copy: bool, files: dict[str, bytes] | None = None) -> str:
    item_id = ctx.outbox.teacher_with_self_buttons(esc(text), POST_BUTTONS, files=files)
    _stash_files(ctx, item_id, files or {})
    ctx.state.pending[item_id] = {"kind": "post", "target": target, "text": esc(text),
                                  "files": sorted((files or {}).keys()), "max_copy": max_copy}
    return item_id


def handle_github(ctx: Context, submissions: list[Submission]) -> None:
    for sub in submissions:
        total = sub.passed + sub.failed
        summary = f"github {sub.sha[:7]}: тесты {sub.passed}/{total}" if total else f"github {sub.sha[:7]}: тестов нет"
        try:
            day = record_submission(ctx, sub.student, sub.hw_id, summary, "github")
        except JournalError as exc:
            ctx.outbox.teacher(f"Сдача {esc(sub.student)} {esc(sub.hw_id)} не записана: {esc(str(exc))}")
            continue
        _notify_submission(ctx, sub.student, sub.hw_id, day, summary + ("\n" + esc(sub.log[-600:]) if sub.failed else ""), {})


def _handle_registered(ctx: Context, item: Item) -> None:
    person = ctx.identity.bind(item.data["from"], int(item.data.get("telegram_id") or 0))
    if person is None:
        ctx.outbox.teacher(f"Зарегистрирован неизвестный comms_id {esc(item.data['from'])}")
        return
    role = "ученик" if person.role == "student" else "родитель"
    ctx.outbox.teacher(f"{esc(ctx.name(person.student))} ({role}) зарегистрирован(а) в Telegram.")


def _handle_person(ctx: Context, item: Item) -> None:
    person = ctx.identity.by_comms_id(item.data["from"])
    if person is None:
        log.warning("сообщение от незнакомого %s", item.data["from"])
        return
    name = ctx.name(person.student)
    if item.data.get("unsupported"):
        ctx.outbox.teacher(f"{esc(name)} прислал(а) {UNSUPPORTED_RU.get(item.data['unsupported'], 'что-то нечитаемое')} — "
                           f"бот такое не читает, ответь в Telegram сам.")
        return
    files = {n: (item.files_dir / n).read_bytes() for n in item.data.get("files") or [] if (item.files_dir / n).is_file()}
    is_submission = (person.role == "student" and ctx.cfg.telegram_fallback
                     and item.data["kind"] in ("photo", "document"))
    if is_submission:
        found = open_homework(ctx.cfg.students_root, person.student)
        if found:
            _, hw_id = found
        else:
            plan = course.latest_plan_with_homework(ctx.cfg.repo_root, ctx.today)
            if not plan:
                ctx.outbox.teacher(f"{esc(name)} прислал(а) файл, но домашки в планах нет — разбери сам.")
                return
            hw_id = course.homework_ids(plan[1])[0]
        keep = ctx.cfg.students_root / "submissions" / person.student / hw_id / item.id
        keep.mkdir(parents=True, exist_ok=True)
        for n, content in files.items():
            (keep / n).write_bytes(content)
        summary = f"telegram: {', '.join(files) or 'без файлов'}"
        try:
            day = record_submission(ctx, person.student, hw_id, summary, "telegram")
        except JournalError as exc:
            ctx.outbox.teacher(f"Сдача {esc(name)} не записана: {esc(str(exc))}")
            return
        _notify_submission(ctx, person.student, hw_id, day, summary + (f" — «{item.data['text']}»" if item.data.get("text") else ""), files)
        return
    who = "родитель" if person.role == "parent" else "ученик"
    text = (f"<b>{esc(name)}</b> ({who}, {'группа' if item.data['chat'] == 'group' else 'личка'}): "
            f"{esc(item.data.get('text') or '')}\nОтветь reply — уйдёт человеку от бота.")
    item_id = ctx.outbox.teacher_with_self_buttons(text, QUESTION_BUTTONS, files=files or None)
    ctx.state.pending[item_id] = {"kind": "question", "student": person.student, "comms_id": person.comms_id,
                                  "text": item.data.get("text") or ""}


def _send_post(ctx: Context, item_id: str, meta: dict) -> None:
    files = _pending_files(ctx, item_id)
    if meta["target"] == "group":
        ctx.outbox.group(meta["text"], files=files or None)
    else:
        ctx.outbox.person(meta["target"], meta["text"], files=files or None)
    if meta.get("max_copy"):
        ctx.outbox.teacher("Дубль для MAX (скопируй):\n\n" + esc(plain(meta["text"])))
    else:
        ctx.outbox.teacher("Отправлено.")


def _handle_callback(ctx: Context, item: Item) -> None:
    action, _, rest = (item.data.get("callback") or "").partition(":")
    if action == "remind":
        index, _, item_id = rest.partition(":")
        meta = ctx.state.pending.get(item_id)
        if not meta or meta.get("kind") != "digest":
            ctx.outbox.teacher("Уже сделано.")
            return
        tail = meta["tails"][int(index)]
        person = ctx.identity.by_student(tail["student"])
        url = course.page_url(ctx.cfg.pages_url, tail["hw_id"])
        ctx.outbox.person(person.comms_id, f"Напоминаю: домашка {esc(tail['hw_id'])} ждёт, срок был {tail['since']}. "
                                           f"Страница: {url}")
        ctx.outbox.teacher(f"Напомнил(а) {esc(tail['name'])}.")
        return
    item_id = rest
    meta = ctx.state.pending.get(item_id)
    if meta is None:
        ctx.outbox.teacher("Уже сделано.")
        return
    if action == "send" and meta["kind"] == "post":
        _drop_pending(ctx, item_id)
        _send_post(ctx, item_id, meta)
    elif action == "discard":
        _drop_pending(ctx, item_id)
        ctx.outbox.teacher("Отброшено.")
    elif action == "accept" and meta["kind"] == "submission":
        _drop_pending(ctx, item_id)
        try:
            ops.set_homework(date.fromisoformat(meta["day"]), meta["hw_id"], meta["student"], "accepted",
                             None, ctx.cfg.students_root, ctx.today, "teacher")
        except JournalError as exc:
            ctx.outbox.teacher(f"Не принято: {esc(str(exc))}")
            return
        ctx.outbox.person(meta["comms_id"], f"Домашка {esc(meta['hw_id'])} принята. Молодец!")
        ctx.outbox.teacher(f"Принято: {esc(ctx.name(meta['student']))}, {esc(meta['hw_id'])}.")
    elif action == "rework" and meta["kind"] == "submission":
        meta["await_reply"] = True
        ctx.outbox.teacher(f"Ответь reply на сообщение о сдаче {esc(ctx.name(meta['student']))} текстом для ученика — "
                           f"уйдёт ему, статус станет «доработать».")
    elif action == "claude":
        _claude_for(ctx, item_id, meta)
    else:
        ctx.outbox.teacher("Уже сделано.")


def _claude_for(ctx: Context, item_id: str, meta: dict) -> None:
    task_text = course.task_text(ctx.cfg.repo_root, meta.get("hw_id", "")) if meta.get("hw_id") else ""
    if meta["kind"] == "submission":
        files = _pending_files(ctx, item_id)
        files_text = "\n\n".join(f"--- {n} ---\n{c.decode('utf-8', 'replace')[:4000]}"
                                 for n, c in files.items() if Path(n).suffix in TEXT_EXT) or "(файлов с кодом нет)"
        text = draft("review", {"student_name": ctx.name(meta["student"]), "hw_id": meta["hw_id"],
                                "task_text": task_text, "files_text": files_text, "tests_summary": meta["summary"]},
                     ctx.cfg, ctx.runner)
    elif meta["kind"] == "question":
        found = open_homework(ctx.cfg.students_root, meta["student"])
        task_text = course.task_text(ctx.cfg.repo_root, found[1]) if found else ""
        text = draft("answer", {"student_name": ctx.name(meta["student"]), "question": meta["text"],
                                "task_text": task_text}, ctx.cfg, ctx.runner)
    else:
        ctx.outbox.teacher("К этому черновик не нужен.")
        return
    if not text:
        ctx.outbox.teacher("Черновик не получился — claude -p не ответил.")
        return
    _stage_draft(ctx, text, meta["comms_id"], max_copy=False)


def _handle_reply(ctx: Context, item: Item) -> None:
    meta = ctx.state.pending.get(item.data.get("reply_to_item") or "")
    text = item.data.get("text") or ""
    if meta is None:
        ctx.outbox.teacher("Не нашёл, к чему этот ответ — сообщение уже обработано.")
        return
    if meta["kind"] == "submission" and meta.get("await_reply"):
        _drop_pending(ctx, item.data["reply_to_item"])
        try:
            ops.set_homework(date.fromisoformat(meta["day"]), meta["hw_id"], meta["student"], "rework",
                             text, ctx.cfg.students_root, ctx.today, "teacher")
        except JournalError as exc:
            ctx.outbox.teacher(f"Статус не изменён: {esc(str(exc))}")
            return
        ctx.outbox.person(meta["comms_id"], f"Домашка {esc(meta['hw_id'])} — доработать:\n{esc(text)}\n— Димас")
        ctx.outbox.teacher(f"Отправлено {esc(ctx.name(meta['student']))}, статус «доработать».")
    elif meta["kind"] == "question":
        _drop_pending(ctx, item.data["reply_to_item"])
        ctx.outbox.person(meta["comms_id"], f"{esc(text)}\n— Димас")
        ctx.outbox.teacher(f"Отправлено {esc(ctx.name(meta['student']))}.")
    else:
        ctx.outbox.teacher("К этому сообщению reply не нужен — есть кнопки.")


def _handle_teacher_text(ctx: Context, item: Item) -> None:
    text = (item.data.get("text") or "").strip()
    if text.startswith("/claude"):
        task = text[len("/claude"):].strip() or "сводка по группе"
        context = _context_text(ctx)
        result = draft("task", {"task": task, "context": context}, ctx.cfg, ctx.runner)
        if not result:
            ctx.outbox.teacher("Черновик не получился — claude -p не ответил.")
            return
        _stage_draft(ctx, result, "group", max_copy=True)
    elif text.startswith("/status"):
        ctx.outbox.teacher(_status_text(ctx))


def _context_text(ctx: Context) -> str:
    from journal import stats as journal_stats
    from journal.cli import format_report
    try:
        return format_report(journal_stats.collect(ctx.cfg.students_root, ctx.cfg.repo_root, ctx.today))
    except JournalError as exc:
        return f"(журнал не прочитан: {exc})"


def _status_text(ctx: Context) -> str:
    return (f"Ожидают кнопок: {len(ctx.state.pending)}. Тик № {ctx.state.tick}. "
            f"Людей без Telegram: {sum(1 for p in ctx.identity.people if p.telegram_id is None)}.")


def apply_item(item: Item, ctx: Context) -> None:
    kind, sender = item.data.get("kind"), item.data.get("from", "")
    if kind == "registered":
        _handle_registered(ctx, item)
    elif kind == "callback":
        _handle_callback(ctx, item)
    elif kind == "reply" and sender == "teacher":
        _handle_reply(ctx, item)
    elif sender == "teacher":
        _handle_teacher_text(ctx, item)
    elif kind in ("text", "photo", "document"):
        _handle_person(ctx, item)
    else:
        log.info("пропущен элемент %s kind=%s from=%s", item.id, kind, sender)
```

```python
# tools/comms/tick.py
"""Один тик brain: pull -> apply -> schedule -> github -> push. Запускается launchd раз в минуту."""
from __future__ import annotations
import argparse
import json
import os
import subprocess
import sys
from datetime import datetime
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))  # tools/

from comms import apply, course, github_poll, schedule, transport  # noqa: E402
from comms.config import Config, load_config  # noqa: E402
from comms.identity import Identity  # noqa: E402
from comms.outbox import Outbox  # noqa: E402
from comms.queue import read_items, remove_item  # noqa: E402
from comms.state import State  # noqa: E402
from journal.model import JournalError  # noqa: E402

DEFAULT_CONFIG = Path.home() / ".junior_it" / "comms.toml"


def default_runner(cmd, *, timeout, stdin_text=None):
    return subprocess.run(cmd, input=stdin_text, capture_output=True, text=True, timeout=timeout)


def _names(cfg: Config) -> dict[str, str]:
    try:
        return course.student_names(cfg.students_root)
    except (JournalError, FileNotFoundError):
        return {}


def _write_last_tick(cfg: Config, now: datetime, counts: dict, pending: int, inbox_left: int) -> None:
    path = cfg.local_dir / "last_tick.json"
    tmp = path.with_suffix(".json.tmp")
    tmp.write_text(json.dumps({"ts": now.isoformat(timespec="seconds"), "counts": counts,
                               "pending": pending, "inbox_left": inbox_left}, ensure_ascii=False), encoding="utf-8")
    os.replace(tmp, path)


def run_tick(cfg: Config, now: datetime, runner, log=print) -> dict:
    for sub in ("inbox", "outbox-staging", "pending"):
        (cfg.local_dir / sub).mkdir(parents=True, exist_ok=True)
    counts = {"pulled": 0, "applied": 0, "errors": 0, "scheduled": [], "github": 0, "pushed": 0}
    try:
        counts["pulled"] = transport.pull(cfg, runner)
    except transport.TransportError as exc:
        log(f"pull: {exc}")
    state = State(cfg.state_path)
    ctx = apply.Context(cfg=cfg, state=state, identity=Identity(cfg.students_root / "comms.yml"),
                        outbox=Outbox(cfg.local_dir / "outbox-staging"), runner=runner, now=now, names=_names(cfg))
    inbox = cfg.local_dir / "inbox"
    for item in read_items(inbox):
        if state.processed(item.id):
            remove_item(inbox, item.id)
            continue
        try:
            apply.apply_item(item, ctx)
        except Exception as exc:
            counts["errors"] += 1
            log(f"элемент {item.id}: {exc}")
            continue
        state.mark_processed(item.id, now)
        remove_item(inbox, item.id)
        counts["applied"] += 1
    roster_exists = (cfg.students_root / "roster.yml").is_file()
    tails_fn = (lambda: schedule.collect_tails(cfg.students_root, cfg.repo_root, now.date())) if roster_exists else (lambda: [])
    try:
        counts["scheduled"] = schedule.run(cfg, state, ctx.outbox, now, tails_fn)
    except (JournalError, OSError) as exc:
        log(f"расписание: {exc}")
    state.tick += 1
    if state.tick % cfg.github_poll_every == 0:
        submissions = github_poll.poll(cfg, ctx.identity, state, runner, now)
        apply.handle_github(ctx, submissions)
        counts["github"] = len(submissions)
    try:
        counts["pushed"] = transport.push(cfg, runner)
    except transport.TransportError as exc:
        log(f"push: {exc}")
    state.prune(now)
    state.save()
    _write_last_tick(cfg, now, counts, len(state.pending), len(read_items(inbox)))
    return counts


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(prog="comms.tick", description="Тик brain: очереди, журнал, черновики")
    ap.add_argument("--config", type=Path, default=DEFAULT_CONFIG)
    ap.add_argument("--once", action="store_true", help="один тик (по умолчанию)")
    ap.add_argument("--dry-run", action="store_true", help="показать состояние, ничего не делая")
    args = ap.parse_args(argv)
    cfg = load_config(args.config)
    if args.dry_run:
        state = State(cfg.state_path)
        last = cfg.local_dir / "last_tick.json"
        print(f"входящих локально: {len(read_items(cfg.local_dir / 'inbox'))}, "
              f"исходящих в staging: {len(read_items(cfg.local_dir / 'outbox-staging'))}, "
              f"ожидают кнопок: {len(state.pending)}, тик № {state.tick}")
        print(f"последний тик: {json.loads(last.read_text(encoding='utf-8'))['ts'] if last.is_file() else 'не было'}")
        return 0
    counts = run_tick(cfg, datetime.now(), default_runner, log=lambda m: print(m, file=sys.stderr))
    if counts["applied"] or counts["errors"] or counts["scheduled"] or counts["github"] or counts["pushed"]:
        print(f"тик: {counts}", file=sys.stderr)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
# tools/info/comms.py
from __future__ import annotations
from datetime import datetime

from info.common import Line

STALE_MIN = 5


def _age_min(ts: str | None, now: datetime) -> int | None:
    if not ts:
        return None
    return max(0, int((now - datetime.fromisoformat(ts)).total_seconds() // 60))


def lines(status: dict | None, last_tick: dict | None, now: datetime) -> list[Line]:
    if status is None:
        courier = Line("почтальон: статус не забирали", style="warn")
    else:
        sizes = status.get("sizes") or {}
        age = _age_min(status.get("ts"), now)
        online = bool(status.get("online"))
        text = (f"почтальон: {'онлайн' if online else 'офлайн'} · исходящих {sizes.get('outbox', 0)} · "
                f"входящих {sizes.get('inbox', 0)} · не доставлено {sizes.get('failed', 0)}")
        if age is not None and age > STALE_MIN:
            text += f" · статус {age} мин назад"
        style = "err" if (not online or sizes.get("failed", 0)) else ("warn" if age is not None and age > STALE_MIN else "ok")
        courier = Line(text, style=style)
    if last_tick is None:
        brain = Line("мозг: тик не запускался", style="warn")
    else:
        age = _age_min(last_tick.get("ts"), now) or 0
        errors = (last_tick.get("counts") or {}).get("errors", 0)
        brain = Line(f"мозг: тик {age} мин назад · ждут кнопок {last_tick.get('pending', 0)} · ошибок {errors}",
                     style="warn" if (age > 3 or errors) else "ok")
    return [courier, brain]
```
